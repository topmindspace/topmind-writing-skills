# topmind-format 原创示例（纯文本零改字排版）

这三组示例演示段落、分行和保真排版。核对结果时逐句比较文字、顺序、表达性标点和链接。

- [`01-原文.txt`](./01-原文.txt) → [`01-格式化成短文.txt`](./01-格式化成短文.txt)：将挤成一团的长段拆分为「首句结论 + `·` 分点 + 结尾总结 + 来源行」，**不增删改任何一个原文字词**，默认保留末尾来源链接（若用户显式要求链接另发，可加 `--separate-links`）。
- [`02-原文.txt`](./02-原文.txt) → [`02-转段子.txt`](./02-转段子.txt)：按呼吸节奏切分句子并拉开空行，完全保留作者原本的口吻与用词（「听着雨声特别香」）。
- [`03-原文.txt`](./03-原文.txt) → [`03-有表达符号的排版.txt`](./03-有表达符号的排版.txt) 演示保留「？？？」、🙂 和正文 URL，只增加段落空行。

在 `topmind-format/` 目录运行：

```sh
python3 scripts/format_text.py examples/03-原文.txt --mode duanzi
```
