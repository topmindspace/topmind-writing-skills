# topmind-cover · 封面配图生成

为 X 长文和公众号文章生成封面图。目标：**美观优雅的醒目**——
震撼标题 + MD3 设计基础，优雅美观，不是靠丑陋扭曲来醒目。

**设计哲学**：MD3 配色角色 + 字体层级 + 形状语言为底，
再叠加 22 种风格的设计手法。详见 [`references/md3-foundation.md`](references/md3-foundation.md)。

```
标题提炼 → 七层场景配方 → 2–3 个方案（风格组合 + 骨架 + 配色）→ 分层 prompt → 生成（或场景图 + 脚本叠字）→ 六维评分 + 冲击力自检 → 裁剪双尺寸 → 落盘命名
```

## 意图判断 → 直出 / 讨论（生成前必做）

默认按意图直出；意图模糊/多解/缺关键信息时先与用户确认（三问以内）。

| # | 检查项 | 通过标准 | 不通过→追问（给选项，不给问答题） |
|---|--------|----------|----------------------------------|
| 1 | 标题确定 | 有明确标题文案（≤10 字），或用户给了原文可直接提炼 | 给 2 个备选标题让用户挑："用 A 还是 B？" |
| 2 | 主题明确 | 能说清文章讲什么（3 个主题关键词） | 追问："这篇的核心主题是？"附 2~3 个关键词备选 |
| 3 | 风格明确 | 题材对上某风格首选题材，或用户点名了风格 | 给 2~3 个候选风格 + 各一句话差异，让用户选 |
| 4 | 关键信息有出处 | 数字/品牌/人物/署名等真实可查 | 缺→问；问不到→删掉该元素，**绝不编造** |

- **四项全过 → 直接生成**，不问。
- **任一项模糊/多解 → 先确认再生成**，问题总数 ≤3（风格、标题、内容各至多一问）。
- 讨论时每个问题附 2~3 个具体备选，用户只做选择题。

| 平台 | 尺寸 | 比例 | 备注 |

| X Article 封面 | 1500×600 | 5:2 | 主尺寸，先按这个生成 |
| 公众号封面大图 | 900×383 | 2.35:1 | 从 5:2 主图中央裁剪（左右各裁约 3%） |

长文封面：prompt 写明"横构图 5:2"；公众号版用 `scripts/crop-cover.py` 从主图中央裁出，不重新生成（保系列一致）。
X 短文封面：prompt 写明"横构图 16:9"，用 `scripts/crop-cover.py <主图> --preset x-post --out-dir <目录>` 落盘为 `00-封面-X短文.png`。

## X 短文封面（场景）

X 短文、X 短帖**原图优先**：有官方截图、基准图、后台截图时不另配封面；没有原图、且用户要或需要一张首图时，由 `topmind-briefs`、`topmind-viral-posts`、`topmind-format` 发起本场景，也可单独触发（「X 短文封面」「短帖封面」）。

- **画幅**：16:9，1200×675；X 时间线单图预览接近完整显示，标题放中央 80% 宽度内。
- **标题**：取帖子的核心判断或最关键的数字，≤10 字；可加 1 行 ≤14 字的副标题或胶囊标签。
- **信息诚实**：封面数字必须在正文里出现并有来源；资讯类封面不画假的产品界面、假截图、假 logo。
- **风格**：按上方「场景 → 风格 → 标题花式」选；纯运营段子（互关、打卡）用 viral-posts 的图库方向（宠物、风景、标语），可以不放标题。
- **自检**：冲击力自检里 #1–#6、#9、#11 照做；#7 的安全区改为「标题在中央 80% 宽度、上下各留 10%」；不做 900×383 裁剪。

## 工作流

0. **意图判断**（必做）：先过上方"意图判断 → 直出 / 讨论"决策流；意图明确→直接生成，模糊→三问以内确认。
   **风格转译器**（用户输入简单时自动触发）：提炼短标题 + 核心数字（如"DeepSeek 部署实测 / 万字"）→
   按题材推荐风格（极客硬核 → `dark-saas` / `hard-core-type`；新手向 → `chao-wan-3d` / `anime-desk`；
   宏大体系 → `diorama-book`；严肃研究 → `academic-print`；
   清新震撼 → `white-clean`（纯白底 + 超大标题 + 撞色关键词 + 场景插图））→ 注入 10% 安全区约束。
   **选风格（三步，必做）**：① 按题材从 `references/cover-styles.md` 选 1 种（22 选 1，浅色优先）→ ② 看 `assets/examples/<style>.png` 确认视觉语言（本地没有该图时看 `overview.png` 对应格子）→ ③ 看该风格章节的标题写法规范，心里有标题雏形。
   **选骨架**：从 `cover-styles.md` 的 10 种构图骨架选 1 种（L1–L4 基础：左文右图 / 公式流 / 场景嵌字 / 报刊网格；L5–L10 场景互动：左字右角色互动 / 中字两侧道具 / 上字下场景 / 流程卡片铺陈 / 举牌 / 掀纸破框）。
   **风格组合**：主风格 + 辅风格各取一个层（主角、背景、标题处理），组合表见 `references/scene-builder.md` 第四节；只用单一风格时也要满足下面的丰富度底线。
1. **标题提炼**（先定文案，不画图）：用所选风格在 `cover-styles.md` 对应章节的标题写法规范提炼标题（一般 ≤10 字）；不满意就重写，满意再进下一步。
   - 坏："关于 Manus 2.0 的一些思考与体验"（长、没钩子）→ 好："Manus 2.0 实测"（短、有断言）
2. **场景配方（必做，替代过去的一句话 brief）**：按 `references/scene-builder.md` 七层填写：主题 → 隐喻 / 冲突 → 主角 → 与标题互动的动作 → 道具 → 背景 → 光线。
   - 丰富度底线：1 个主角 + 1 个与标题互动的动作 + 2–4 个主题道具 + 1–3 处装饰 + 背景 ≥3 层 + 标题 1 主 1 辅花式；上限：主角 ≤2、强调色 ≤2、焦点只有一个。
   - 主角可选 TopMind IP（小鸡 / 小猫 / 小植物，3D 黏土、毛绒、像素或手绘）；不画可识别的真实人物长相；资讯与事实类原图优先。
3. **出 2–3 个方案（默认）**：每个方案一张方案卡 `方案 A｜隐喻｜风格：主 + 辅｜骨架：L?｜配色`，四项里至少换三项；用户说「直接出」就各出一张。相邻封面不重复主风格。
4. **组 prompt**：用 `scene-builder.md` 第三节的中文 / 英文分层模板，槽位全部填满；标题逐字写明（防 AI 自造错别字），再加 `cover-prompts.md` 第五章的负面词。平台（`x` / `wechat` / `both`，默认 both）只影响画幅与安全区。
5. **生成**：`media.generate_image`，`name` 用 `<slug>-cover`。
   **双路径**：A 让模型直接出字；标题长、有生僻字、要精确多行花式，或 A 路径错字 2 次时走 B：prompt 里留干净标题区、禁止生成文字，出图后用 `scripts/overlay-title.py <底图> <spec.json> --out <成图>` 叠字（支持多行字号、关键词变色、描边、投影、手绘底线、胶囊标签）。
   **多样性**：同一系列或同一天连发的封面，相邻两张至少在「风格 / 标题花式 / 背景」三项中换两项；同一风格内也要换主体和构图骨架。
6. **评分与自检**（必做）：先按 `scene-builder.md` 第八节六维评分（丰富度 / 主题贴合 / 标题花式 / 层次 / 可读性 / 质感，各 1–5）：**总分 ≥20 且没有一项 ≤2 才交付**；再过下方冲击力自检 11 项。不通过→按低分项改 prompt 重生成，最多 3 次；3 次仍不过→换方案，或回步骤 1 重写标题。
7. **裁剪落盘**：
   ```bash
   python3 scripts/crop-cover.py <主图> --out-dir <包>/images/
   ```
   产出 `00-封面.png`（1500×600，X/公众号共用主文件）与 `00-封面-公众号.png`（900×383）；
   X 短文封面加 `--preset x-post`，产出 `00-封面-X短文.png`（1200×675）。
   公众号包规约：正文引用 `images/00-封面.png`，`图片上传清单.md` 登记两版。
8. **系列感**：同一系列固定色系 + 版式语言；系列内仍要换隐喻、主角动作和道具，不能只换标题字。

## 冲击力自检清单

**生成后必过**。

| # | 检查项 | 不通过怎么改 |
|---|--------|--------------|
| 1 | 3 秒测试：缩到 120px 宽，3 秒内读出标题并说清"这是什么" | 放大标题，删小字 |
| 2 | 标题字高 ≥ 画面高度 1/4，空间允许时冲击 1/3 | 放大标题，其他元素让路 |
| 3 | 对比果断：字色与底色明度差拉满（拒绝灰底白字式低对比） | 底色走极端（极深或极浅） |
| 4 | 记忆点：3 秒后能向人描述出一个具体的东西 | 加一个形象/数字/符号/质感记忆点 |
| 5 | 质感：背景有纹理、光影或描边，拒绝纯色死平 | 背景层加一层纸纹/噪点/光影 |
| 6 | 标题字逐字正确：无 AI 自造错字/乱码/笔画粘连（含装饰导致） | 有错字/粘连→减装饰、缩短标题或修正标题写法后重生成 |
| 7 | 标题与关键主体落在中央垂直 60% 安全区（900×383 裁剪不切字） | 把元素收拢进安全区 |
| 8 | `references/impact-language.md` 20 条原则快速勾选 | 按"保守陷阱清单"逐项纠正 |
| 9 | 丰富但单焦点：装饰 1–3 处、道具 2–4 个、只有一个视觉焦点（minimal 风格装饰仍只许 1 种） | 太空→按场景配方补道具 / 背景层；太乱→删最弱的道具或装饰 |
| 10 | 记忆点动作化：3 秒后能描述出"一个具体的东西 + 一个动作"（如"小熊破纸而出"），不能只描述出"一张白底图" | 记忆点只有静态物体→加动作：压字/破框/攀爬/托举，让角色与标题互动 |
| 11 | 高级感：标题有字体设计（非 plain font block）、有角度变化（非全正面平视）、景深≥4层、光有方向 | 按 `cover-styles.md` 高级感设计系统 4 维度（字体/角度/景深/光影）选 2~4 种手法重生成 |

## 设计铁律

- 一图一主题、一个焦点；主角与标题合计占画面 60% 以上，主角必须对标题做动作
- 丰富而有层次：前景道具 / 中景主角与标题 / 背景 ≥3 层；不是单色底 + 一行字
- 大标题 ≤10 字，2–3 行大小对比；对比与字高见冲击力自检 #2/#3
- 四周 8% 安全边距，标题不贴边（中央 60% 安全区见自检 #7）
- 忌：单调（一行黑体 + 纯色底 + 孤立图标）；也忌小字密排、多主体打架、强调色超过 2 个

## 被 topmind-briefs / topmind-viral-posts 调用时

- **briefs（干货短文）**：只在没有可用原图时走「X 短文封面」场景，标题取核心数字或结论；有原图就用原图当首图。
- **viral-posts（段子、涨粉帖）**：只借用本技能的风格配方与 prompt 写法（清新优雅 / MD3 商务风），
  画幅按调用方要求（X 单图 1200×675 或 1:1），不套用长文封面的标题字高、10% 安全区和 900×383 裁剪；无标题的图库类配图也不需要「标题 ≤10 字」。

## When NOT to use

- 长图、海报、信息图、榜单图（图里有必须逐字正确的文字和数字）：走 `topmind-poster`
- 短文、段子、快讯的写稿（只做它们的封面）：走 `topmind-briefs` / `topmind-viral-posts`
- 正文插图：主体是文字说明，按正文配图流程走
- 报告/PPT 封面：走 `topmind-presentation`（仓库 `topmind-presentation`，已从本仓独立出去）
- 只想找现成图：走 `image_search` 技能
