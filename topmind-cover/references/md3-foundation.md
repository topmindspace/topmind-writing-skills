# MD3：一种可选的设计参考

MD3 可用于需要清楚层级、颜色角色和一致组件的封面，不是所有封面的底层美学。摄影、编辑、纯字、复古、文化和实验方向不需要套用 UI 组件语言。

## 可以借鉴什么

把颜色分为背景、文字、强调与容器角色，能让系列更容易维护；Display、Headline、Title 与 Label 的区分帮助判断文字任务。但它们不决定中文封面的固定字号、字重、字数、留白和圆角。

| 借鉴点 | 可以怎样用 | 无需照搬 |
|---|---|---|
| 颜色角色 | 给系列定义背景、正文、强调关系 | 固定商务蓝、禁纯白或只准一种强调色 |
| 字体任务 | 区分表达性标题与实用说明 | 主标题必须占四分之一、固定 1.0 / 0.7 比值 |
| 组件一致 | 有产品语境时用容器与标签 | 每张胶囊、大圆角或卡片 |
| 形状语言 | 用重复形状串联内容 | 禁止直角或必须某个圆角半径 |

## 选择与转换

产品功能说明可从 MD3 角色开始；人物随笔可转向编辑摄影；文化评论可用宋体与印刷；纯字宣言可只保留颜色和字形。选择依据是文章，而不是模板忠诚度。

[Material 官方 applying type](https://m3.material.io/styles/typography/applying-type) 对表达性 display 字体提供方向。2026-10-27 直接页面需要 JavaScript，本次仅核到公开索引摘要，未声称阅读完整页面。更完整、已读的用途区分见 [Carbon 字体说明](https://www.carbondesignsystem.com/building-blocks/foundations/typography/overview)；UI 参数不能直接转为所有封面的硬门槛。
