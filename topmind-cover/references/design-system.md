# 封面设计规范（Design System）

> 适用：整张生成（主流程）和脚本叠字（兜底）都按这份规范。整张生成时，把规范写进 prompt（见 `cover-patterns.md` 的通用排版尾句），出图后照第八、九节核对。
> 管什么：标题与版式的层级、字号、网格、安全区、配色比例、字体搭配、设计模式和克制原则。场景怎么画看 `scene-builder.md`，风格配方看 `cover-styles.md`，字效写法看 `typography-system.md` 第十二章。
> 依据：CRAP 四原则、视觉层级与 Z 形动线、缩略图可读性研究、WCAG 2.2 对比度、60-30-10 配色、模块化字号比例、字体搭配原则。来源见文末。

**一句话**：一张封面只讲一件事。一个焦点、三级文字、一主一辅两种字体、一处重点处理，其余全部让路。

## 一、可读性基准

封面会被缩小显示：X 时间线卡片宽约 500–600px，公众号封面 900×383，缩略图常只有 160–200px 宽。所有字号都按**画面高度的比例**定义，并以 **900×383** 为底线检查（同一份 spec 换尺寸也成立）。

缩略图研究给出的经验值：设计尺寸缩到 1/8 后仍要读得出，需要被读到的最小文字约为画面高的 10%，低于约 6.5% 就只剩纹理；粗字重比细字重更耐缩小。

## 二、层级模型（三级文字 + 可选装饰行）

| 层级 | role | 字号（占画面高） | 900×383 下 | 字重 | 字数 | 对比度下限 |
|---|---|---|---|---|---|---|
| 主标题 | main | **0.20–0.36**（单行可到 0.40） | ≥ 77px | Bold / Black | 中文 4–8 字，最多 2 行 | 3:1 |
| 副标题 | sub | **0.09–0.14** | ≥ 35px | Medium / Bold | ≤ 14 字，1 行 | 4.5:1 |
| 标签 / 小字 | label | **0.06–0.08** | ≥ 23px | Medium 以上 | ≤ 12 字 | 4.5:1 |
| 装饰行（英文小字等） | ornament | 0.045–0.06 | ≥ 17px | Medium | 最多 1 行，删掉也不影响理解 | 3:1 |

- **字号比例**：主 ÷ 副 ≥ 1.6（推荐 2–2.6，约 1.618²），副 ÷ 标签 ≈ 1.4–1.6。同级内两行主标题可以差一档（如 0.20 / 0.25），制造节奏。
- **行距**：标题 1.05–1.2 倍字号；层级之间的间距 ≥ 0.5 倍下一级字号，同组更近、不同组更远（亲密原则）。
- **文字层级不超过 3 级 + 1 行装饰**。信息多了就删，不缩小。

`title-engine.py --check` 按这张表检查字号下限、主副比例与装饰行数量；出图时还会检查对比度和安全区。

## 三、网格、对齐线与安全区

- **安全区**：左右各 5%，上下各 7%（`title-engine.py` 出图时自动检查）。公众号 900×383 是 2.35:1，与 5:2 主图差别很小，按同一 spec 出图即可；X 短文 16:9 另开 spec。
- **12 栏网格**：左右边距 7%（推荐对齐线 x = 0.07），栏间距 1.5%。文字区一般占 5–6 栏（约 45%），主体区占 6–7 栏。
- **一条主对齐线**：左对齐版式所有文字的左边缘落在同一条线上（误差 ≤ 0.5% 画面宽）；居中版式所有文字以 x = 0.5 为轴。不要左对齐和居中混用。
- **呼吸带**：文字区和主体之间留 ≥ 3% 画面宽的空隙，字不压主体的脸和关键部位。
- **动线**：横版封面按 Z 形读：左上（标签）→ 主标题 → 副标题 → 右侧主体。

```
L1 左轴版式（12 栏）                   居中纪念碑版式
|7%|■标签■            |      主体      |   |      ■ 副标题 ■      |
|  |█主标题█████      |    (6–7 栏)    |   |      ■ 标签 ■        |
|  |█████             |                |   |                      |
|  |■副标题■■■        |                |   |   ████ 主标题 ████   |
```

## 四、配色比例 60-30-10

- **60%**：主导色，通常是低饱和的底色或场景大面积色。
- **30%**：辅色，主体与主标题的主色。
- **10%**：强调色，只给一处：重点词、数字或标签底板。强调色出现在 3 处以上就失效。
- 字色先满足对比度，再谈好看。浅底用近黑（#141414–#2A2A2A），深底用近白（#F2F2F2 以上）；强调色压浅底时要压暗（橙色 #FF5A1F 在白底上只有约 3:1，大字勉强，换成 #C93508 稳）。
- 文字压在复杂场景上时，优先换位置到负空间，其次用底板，最后才用描边或投影（描边要 ≥ 字号的 2%）。

## 五、字体搭配

**最多 3 种：一主一辅 + 可选一种标签字体**。每种字体有固定角色；同类相近的两种（比如两种黑体）不要混用，会像出错。一个字族配不同字重通常就够。

| 组合 | 主（main） | 辅（sub / label） | 适用风格 |
|---|---|---|---|
| 理性科技 | 思源黑体 Black | 思源黑体 Medium | brand-launch、dark-saas、cinematic-flow、white-clean、gan-huo |
| 人文杂志 | 思源宋体 Black | 思源黑体 Medium / 文楷 | magazine、academic-print、minimal、diorama-book |
| 纪念碑 | 思源黑体 Black（纹理 / 挤出） | 思源宋体 Black（副）+ 黑体 Medium（标签） | hard-core-type、big-type |
| 萌系 IP | 站酷快乐体 | 思源黑体 Black / Medium | ip-fun、chao-wan-3d、orange-warm、sketch-cartoon |
| 促销爆款 | 站酷庆科黄油体 | 思源黑体 Bold | gan-huo、news-flash |
| 国风书法 | 马善政毛笔 | 思源宋体 Regular / Bold | tutorial-steps、academic-print |

装饰字体（快乐体、黄油体、毛笔）只用于主标题，副标题和小字一律用黑体或宋体。

## 六、克制原则

1. **重特效只给一个重点词**：挤出、长投影、霓虹发光、内发光、故障、斜面这类效果，一张图只用在一个字块上。其他字块只用纯色，最多加描边或底板。
2. **非水平处理要有理由**：旋转、斜切、透视、弧形必须在 spec 里写 `reason`，说清它和场景的关系，比如「与建筑共用透视」或「顺着书页弯」。全图最多 2 个字块；旋转不超过 12°，同一张图里的角度要一致。
3. **装饰元件最多 2 个**，而且必须承担作用：引导视线（箭头、闪光指向主体），或者标记重点（圈、高亮笔）。纯填空的星星不要加。
4. **压字有条件**：主体遮住的部分不超过一个字的 15%，不能遮关键字；只在主体和字有叙事关系时才用。
5. **一个焦点**：眯眼看画面，第一眼只能落在一处，要么是主标题，要么是主体。可感知的视觉单元控制在 3–5 个。
6. **重复制造统一**：标签底板、强调色、圆角半径在同一张图里只用一套，系列封面也沿用同一套。

## 七、设计模式

每个模式都有现成 spec，放在 `assets/title-specs/`，换文字和场景就能用。

### P1 左轴三段式（发布 / 科技）

- **适用**：产品发布、版本更新、工具测评。主体在右侧 45%。
- **网格**：左对齐线 x = 0.07；标签 y 约 0.22，主标题 y 约 0.50，副标题 y 约 0.78。
- **层级**：标签（强调色字）→ 主标题（版本号放大 1.3 倍并换强调色）→ 副标题（浅灰白）。
- **字效**：只有主标题有轻微外发光，颜色与场景光源同色。
- **spec**：`brand-launch.json`

### P2 左文右图 + 关键词高亮（白色清新 / 干货）

- **适用**：效率、职场、清单类内容。浅底，插画主体在右。
- **网格**：两行主标题左对齐；第二行字号大一档，关键词换强调色，下方压一道高亮笔；副标题用实色胶囊底板。
- **字效**：不用重特效，靠颜色、高亮笔和字号节奏出层次。
- **spec**：`white-clean.json`

### P3 IP 对话贴纸标题（萌系 / 打卡）

- **适用**：IP、打卡、亲子、轻松科普。IP 在右并看向标题。
- **网格**：左对齐；主标题用快乐体加贴纸描边，顺着 IP 的道具轻微弧起（要写 reason）；副标题用黄色底板；标签用深色小字。
- **字效**：主标题用贴纸描边；装饰最多 1 个闪光，放在主标题与 IP 之间引导视线。
- **spec**：`ip-fun.json`

### P4 纪念碑居中巨字（硬核 / 宣言）

- **适用**：架构、方法论、观点宣言。场景是有地平线的大空间。
- **网格**：居中轴 x = 0.5；副标题和标签在上方 1/3，主标题立在地平线上（底边 y 约 0.9）。
- **字效**：主标题用浅色混凝土纹理、深色细描边、向下的 3D 挤出，加与建筑同向的轻微透视；场景里的小人站在字前，给出尺度（压字遮挡不超过 15%）。
- **spec**：`hard-core-type.json`

### P5 竖排人文（杂志 / 学术）

- **适用**：访谈、书评、论文解读。
- **网格**：主标题用宋体 Black 竖排，靠右 1/3 或左 1/3；副标题横排，与竖排的底边对齐；印章是唯一的强调色。
- **字效**：不用特效，靠字号对比和留白。

### P6 数字钩子（榜单 / 数据）

- **适用**：带数字的盘点、评测。
- **网格**：数字单独放大到主标题字号的 1.5–2 倍，作为第一焦点；文字主标题贴着数字的基线排。
- **字效**：只给数字加一种效果，挤出或底板二选一。

模式选择：先按场景主体的位置选（主体在右用 P1、P2、P3；有地平线的大场景用 P4；留白多的人文题材用 P5），再按题材微调。`cover-styles.md` 的 L1–L10 骨架决定场景怎么摆，P1–P6 决定字怎么排；两者要一致。

## 八、自检顺序

**整张生成（主流程）**：先跑 `check-title.py` 查标题风险，再生成。出图后按第九节逐字核对，然后缩到 900×383 眯眼看，最后按 `scene-builder.md` 第八节打分。下面 1–4 是脚本叠字兜底时的检查顺序。


1. `title-engine.py --check spec.json`：静态检查层级、字号下限、主副比例、字体数、重特效数、`reason`、装饰数。
2. 出图（加 `--strict` 时不达标会以退出码 2 结束）：检查对比度（取最暗和最亮的背景位置）、安全区。
3. 再出一张 900×383，眯眼看：2 秒内读得出主标题，副标题能读，标签不糊。
4. 按 `scene-builder.md` 第八节的设计评分打分。

## 九、中文字生图规约（整张生成必读）

**写 prompt 时**

1. **标题原文写死**：用英文双引号括起原文，并加上 `in Simplified Chinese characters exactly as given, no extra, missing or altered characters, no traditional characters`。副标题、标签也要逐条用引号写出；不在引号里的字一律不许出现（`no other text`）。
2. **长度**：主标题 ≤ 8 个汉字最稳，9–12 个可以做但要多核对，超过 12 个就拆成主标题加副标题，或者改走脚本叠字。副标题 ≤ 14 字，标签每个 ≤ 4 字、最多 3 个。
3. **用常用字**：只用 GB2312 一级常用字；二级字、生僻字、繁体字先换同义词。数字用阿拉伯数字，一张图最多一个数字。
4. **少用标点和符号**：书名号、引号、破折号、emoji 常被漏写或画乱，能删就删；中英混排时，英文单词放在一侧单独成块。
5. **字的设计写在场景里**：写清材质和立体方式，比如 `giant concrete letters standing on the ground` 或 `extruded glass-and-metal letters`，并写明字与场景共用光照和透视。只写"好看的字体"效果最差。
6. **生成前先查**：`python3 scripts/check-title.py "主标题" "副标题"`，报高风险就先改字。

**常错字与处理**

| 易错 | 常被写成 | 处理 |
|---|---|---|
| 于 | 干、千 | 首选换成「与」「对」，或改写句子；保留时重点核对 |
| 未 / 末 | 互换 | 换成「没」「尾」 |
| 己 / 已 / 巳 | 互换 | 「已经」改「早就」；「自己」保留时重点核对 |
| 拨 / 拔、侯 / 候、即 / 既、析 / 拆 | 互换 | 换同义词，如「即」改「就」，「时候」改「时」 |
| 繁体回流（键→鍵、论→論、设→設） | 繁体 | prompt 里写 `no traditional characters`；仍出错就局部修正 |
| 多字、漏字、重复字 | — | 缩短标题，每行 ≤ 6 字，主标题分两行 |

**出图后核对清单**（每张必做，逐字核对，不能看个大概）

1. 主标题逐字对照原文：字数、顺序、每个字的笔画、简繁体。
2. 副标题、标签逐字对照原文。
3. 画面里没有多余的字：乱码、假英文、UI 文字、水印都算。
4. 字没有被主体遮住关键笔画，字没有变形到难以辨认。
5. 缩到 900×383 后，主标题 2 秒内读得出，副标题能读。
6. 层级、对齐、强调色只用一处：按第二到第六节核对。

**错字怎么修**

1. **局部修正**（首选）：只错 1–2 个字时，用生图工具的局部重绘把错字区域重画，prompt 只写这一个字，并说明材质和光照与原图一致；或者用 `scripts/title-engine.py` 在错字处补一个同材质颜色的字，再用 occlude 保留前景。
2. **整张重出**：错 3 个字以上、字变形或版式乱了，就改 prompt 再出。改法：缩短标题、拆行、换掉风险字、把字的描述写得更具体。
3. **上限**：同一个方案整张重出不超过 3 次。3 次还不对，就改走「场景图 + `title-engine.py` 叠字」兜底；兜底版同样要过第二到第六节的规范。
4. 修完再走一遍核对清单。交付时告诉用户：这张图是整张生成的还是叠字兜底的，修过哪些字。
