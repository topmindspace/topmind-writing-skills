# 封面设计判断与出字协议

本文件定义封面版面诊断逻辑与 `title-engine.py` 的可编辑 JSON 协议。工具检查服务于视觉可读性与文件完整性，不设机械的审美门禁。

---

## 一、版面诊断与快速优化

| 画面症状 | 根因判断 | 推荐调整方案 |
|---|---|---|
| **第一眼平淡、划过去不想点** | 缺少视觉重心，主标题与主体一般大 | 放大核心词或关键数字（占画面 25%+），或拉大明暗/色彩反差 |
| **画面太挤、像塞满字的传单** | 企图把正文所有分点都搬上封面 | 只留 **1 句主结论 + 最多 1 组关键数据/标签**，其余留给正文或 `topmind-poster` |
| **太像千篇一律的 AI 模板** | 滥用居中发光字 + 对称蓝紫背景 | 改为不对称网格（左字右图）、真实原图高亮拼贴，或指定真实纸张/金属微距材质 |
| **文字与背景打架、笔画看不清** | 文字跨过了明暗交界线或复杂纹理区 | 将文字移入干净负空间，或添加高对比实色衬条 / 半透明磨砂底板 |
| **方图 / 竖图裁切后标题被切** | 直接用宽幅横图硬裁不同比例 | 从原图按对应 `--anchor` 独立裁切，或为横竖版分别安排文字位置 |

---

## 二、四条制作路径按需选用

1. **AI 字图一体直出**：适合短标题、材质字（压印/纸雕/白板手写）及原生中文渲染强的模型；出图后逐字核对。
2. **AI 纯净底图 + 脚本叠字（`title-engine.py` / `overlay-title.py`）**：适合长标题、多层级数字标签或系列化栏目封面，文字 100% 零错字。
3. **HTML / CSS / SVG 排版渲染**：适合 Swiss 国际主义网格、Bento 信息卡、代码/论文高亮拼贴等追求像素级对齐的封面。
4. **真实原图裁切 + 编辑排版**：适合硬件实测、论文解读与官方发布，用真实证据建立公信力。

## 三、`title-engine.py` 叠字协议

```bash
# 查看本机可用中文字体族、字重与 TTC 索引
python3 scripts/title-engine.py --list-fonts

# 检查 spec.json 结构与设计提示（默认提示不阻断；--strict 启用严格模板阈值）
python3 scripts/title-engine.py --check spec.json

# 将文字与装饰层渲染到底图上
python3 scripts/title-engine.py 背景.png spec.json --out 封面.png
```

### 可编辑 `spec.json` 示例

```json
{
  "layers": [
    {
      "type": "text",
      "role": "main",
      "text": "读慢一点",
      "font": "song",
      "size": 0.21,
      "fill": "#24221E",
      "x": 0.12,
      "y": 0.42,
      "anchor": "lm",
      "tracking": 0.08
    },
    {
      "type": "text",
      "role": "label",
      "text": "阅读与日常",
      "font": "hei-medium",
      "size": 0.055,
      "fill": "#675D50",
      "x": 0.12,
      "y": 0.76,
      "anchor": "lm"
    }
  ]
}
```

- **图层类型 (`type`)**：`text`（文字）、`deco`（几何装饰）、`occlude`（前景遮挡层）。
- **角色标识 (`role`)**：`main` / `sub` / `label` / `ornament`（仅用于诊断提示，不强制每张图凑齐三级文字）。
- **坐标与字号**：`x`、`y`、`size` 支持画面比例小数（`0`–`1`）或像素整数。
- **核字辅助**：可用 `python3 scripts/check-title.py "标题文本"` 检查常见形近易错字（默认仅作提示，不限制长标题或繁体字）。
