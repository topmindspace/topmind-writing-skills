# 构图关系库

X 编号沿用检索入口；它们描述关系，不固定人物、颜色、字高或画幅。下面的示例句可以自然改写，不要求先选编号。

## 可选提示词尾句

```text
Use the headline "{title}" exactly in the language supplied by the author. Build the intended reading order and compose for {ratio}. Typography can be integrated into the image or added separately. Inspect the actual text and crop before delivery.
```

这句只约束文案与交付完整性，不要求简体、统一安全区或中心横带；使用作者提供的真实标题。
