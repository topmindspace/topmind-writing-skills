## 一、冲击力强的封面有哪些通用手法（8 条）

1. **标题"贴纸化"**：字有白色描边 + 柔和阴影，像贴纸贴在画面上——
   字不是"印"上去的，是"放"上去的，有厚度。
2. **撞色分层**：关键词各自撞色（如蓝色关键词 / 橙红渐变数字 / 黑色主标题），
   不是全标题一个色。
3. **英文斜体混排**：品牌词或专有名词用彩色斜体，中英混排本身就是记忆点。
4. **马克笔横条**：黄色横条衬底，横条略宽于字、不压笔画。
5. **毛绒/Q版 3D 角色**：有体积感、有表情（微笑/专注），不是扁平插画。
6. **场景化道具讲故事**：卡片、代码窗口、书堆、灯泡、图表——
   每个道具都在讲"正在用/正在做"的故事。
7. **小装饰**：星星、感叹号、放射线，至多 3 处，点到为止。
8. **胶囊标签行带图标**：用图标 + 短词概括内容要点（如实测、长文、全流程）。

## 二、老示例为什么普通（6 个病因）

1. **标题字是平的**：无描边、无阴影、无立体感——plain font block。
2. **撞色只有一处**：蓝色只给"起步指南"，不够丰富，冲击力弱。
3. **角色"摆拍"**：小熊抱着电脑站在底部，与标题零互动——
   标题和角色是两个互不相干的图层。
4. **所有元素贴在一个平面**：无前景/中景/远景之分，无纵深。
5. **光线平淡**：无体积光、无明暗渐变，白底就是死白。
6. **构图全水平**：标题、胶囊、角色全部水平居中，无动能。

## 三、新版改进对照

| 病因 | 老示例 | 新示例（v0.7.3） |
|------|--------|------------------|
| 标题平 | 无描边无阴影 | 1px 描边 + 3px 投影，雕塑感 |
| 撞色单 | 一处蓝色 | 蓝撞色 + 黄马克笔横条 + 蓝印章 |
| 角色摆拍 | 站底部，无互动 | 破纸而出，压住标题下 1/4 |
| 无纵深 | 单平面 | 远景光晕 → 中景标题 → 前景角色 |
| 光线平 | 死白 | 左上体积光照亮标题区 |
| 全水平 | 无动能 | 纸片沿对角线排布 |

## 四、沉淀进技能的优化方向

以下已写入 `references/cover-styles.md` 的 white-clean"震撼升级包"，
并应逐步推广到其他 10 种风格：

1. **标题贴纸化是标配**：白色描边（或深色描边）+ 柔和阴影，不是可选项。
2. **撞色分层**：关键词各自撞色，每行至多 1 个撞色词，全图 ≤3 色。
3. **角色与标题互动**：压字 / 攀爬 / 托举 / 从字后探出——拒绝摆拍。
4. **纵深三层必须拉开**：远景（光晕/留白）→ 中景（标题）→ 前景（角色/物件带投影）。
5. **体积光标配**：一束斜向柔光照亮标题区，光就是最便宜的震撼。
6. **场景化道具**：每个道具讲"正在用"的故事，无意义装饰一律不用。
7. **对角线动能**：元素沿对角线走位，标题本身永远水平。
8. **冲击力自检新增**：3 秒后能描述出"一个具体的东西 + 一个动作"
   （如"小熊破纸而出"），不能只描述出"一张白底图"。
