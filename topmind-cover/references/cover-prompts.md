# 封面生成提示词大全（可直接拷贝给 AI 生图）

> **这份文档给谁用**：你想自己写提示词、直接丢给 AI 生图工具（即梦、Midjourney、GPT-4o、Flux 等），
> 不走 topmind-cover 技能流程时，从这里拷贝。
> **和 `cover-styles.md` 的区别**：那份是技能内部配方（含 `{PLACEHOLDER}` 与优选组合，供 AI agent 调用）；
> 这份是**完整、可直接粘贴**的提示词，变量用标出，选好、填好、粘贴、生成。
>
> 配套：`cover-styles.md`（19 风格技能配方）· `impact-language.md`（20 条冲击力设计语言）·

## 0. 使用说明：三步替换法

1. **选一条**：第 1 章按风格选，或第 4 章按内容类型看推荐。
2. **填**：把等变量换成你的真实文案（**必须是真实的**，不要编造数据）。
3. **粘贴生成**：全文（含"绝不"段）一起粘贴。尺寸见下表。

### 尺寸速查

| 平台 | 尺寸 | 比例 | 备注 |
|---|---|---|---|
| X 长文 / 通用横图 | 1500×600 | 5:2 | X Article 封面主尺寸 |
| 公众号封面 | 900×383 | 2.35:1 | 取横图**中央**裁剪（左右各裁约 3%），标题与关键主体避开左右各 10% 边缘 |
| 小红书封面 | 1080×1440 | 3:4 | 信息流占屏比横版大 40%，标题放上半部（下部会被标题栏遮挡） |
| B站 / YouTube 封面 | 1280×720 | 16:9 | 文字 3~5 个词为佳（英文），中文 4~8 字 |

### 中文准确性技巧（所有 AI 生图通用）

- 标题**逐字准确**：提示词里写"标题（逐字准确）"，并把标题单独成行。
- 标题越短越安全：4~8 字最稳，超过 12 字错字率陡增。
- 避免生僻字、异体字；数字用阿拉伯数字（"26篇"比"二十六篇"稳）。
- 一句话里中文不超过 15 字；除标题外不加第二处中文。
- 生成后**逐字检查**：错 1 字就重画，不要将就。

## 3. 外部调研：全平台爆款封面流派

> 2026-09 调研总结。核心结论：**所有平台的爆款封面都在做同一件事——3 秒内让标题被读懂**。
> 手段各不相同，下面按平台给出可直接拷贝的提示词。

### 3.1 小红书：六大高互动封面类型

调研结论（来源见文末）：小红书封面首选 3:4 竖版（1080×1440，信息流占屏比横版大 40%）；
六大高互动类型：**纯文字大字报 / 数据截图+文字 / 人物+文字 / 清单列表 / 对比图 / 信息图**；
黄金法则：3 秒法则、缩略图测试（170×227px 下标题可读）、信息前置（核心信息放上半部，
下部会被标题栏遮挡）、对比反差、避免模板感；
标题标配：综艺超粗黑体 + 柔和浅黄 #FDFFA7 填充 + 粗黑描边。

**类型 A · 纯文字大字报**（观点、金句类，互动率极高）：

```
小红书 3:4 竖版封面（1080×1440）。高饱和撞色背景。
画面上方 40% 放置超大中文标题""（逐字准确），综艺感超粗黑体，
柔和浅黄色 #FDFFA7 填充 + 粗黑描边 + 轻微白色高光，有强烈压迫感；
标题中 1 个关键词用白色填充（其余浅黄），形成对比。
画面两侧加入 3~5 个，只做情绪强化，不抢标题。
高对比、高密度、强点击感。所有重要元素在安全区内，底部 120px 不放重要信息。
绝不：极简留白；细字体；低对比浅灰字；荧光黄。
```

**类型 B · 清单列表**（干货、推荐类）：

```
小红书 3:4 竖版封面（1080×1440）。浅色干净底。
顶部超大中文标题""（逐字准确），超粗黑体，深色字 + 粗描边，字高占画面 1/4。
标题下方纵向排列条清单，每条格式：绿色勾选框 + 短句""（每条≤8 字），
条目字号约为标题的 1/3，行间距宽松。
每条条目旁配 1 个小 emoji 或小贴纸。清单是视觉主体，一目了然。
底部 120px 不放重要信息。绝不：条目超 5 条；细字体；低对比。
```

**类型 C · 人物+文字**（个人 IP 类）：

```
小红书 3:4 竖版封面（1080×1440）。真人半身出镜，人物居中偏下，占画面约 45%，
，眼神看向镜头，
人物边缘有浅黄色 #FDFFA7 描边，形成清晰抠图感。
画面顶部放置超大中文标题""（逐字准确），综艺感超粗黑体，
浅黄色 #FDFFA7 填充 + 粗黑描边，文字占据画面上方约 40%。
背景是，轻微虚化，不抢人物和标题。
标题不遮挡人物眼睛和嘴巴。底部 120px 不放重要信息。
绝不：极简留白；标题遮挡五官；荧光黄。
```

**类型 D · 对比图**（before/after 类）：

```
小红书 3:4 竖版封面（1080×1440）。左右对比构图（非镜像呆板，中间一条粗分割线）。
左侧，上方压小标签"BEFORE"；右侧，上方压小标签"AFTER"，
AFTER 标签用浅黄 #FDFFA7 底 + 粗黑字。
顶部横跨超大中文标题""（逐字准确），超粗黑体，白色填充 + 粗黑描边，
压在画面上方，不遮挡对比主体。
高对比、一眼看懂反差。底部 120px 不放重要信息。绝不：对比不鲜明；标题过小。
```

### 3.2 YouTube / B站：高 CTR 范式

调研结论：文字 **3~5 个词**（中文 4~8 字）、粗黑无衬线占画面 20~30%；
人脸 + 真实情绪 = CTR +20~30%；好奇心缺口（给悬念不给答案）；
对比度 7:1 以上；中央构图（主体占中央 60%）优于三分法；40~60% 留白；
公式：1 个承诺 + 1 张脸 + 1 个道具 + 2 个主色 + ≤5 个词。

**YouTube 高 CTR 封面**：

```
YouTube 16:9 封面（1280×720）。中央构图：占据中央 60% 画面，眼神看向镜头。
左侧放置 3~5 个词的超大标题""（逐字准确），粗黑无衬线，
白色填充 + 深色粗描边，占画面 20~30%，与视频标题不重复、只给悬念（一句话承诺）。
只用 2 个主色，对比度 7:1 以上，主体从背景中跳出来。
40~60% 留白，一个视觉焦点。移动端缩略图下标题清晰可读。
绝不：超 5 个词；中性无表情；杂乱背景；标题与视频标题逐字重复。
```

### 3.3 公众号 / X：信任感范式

公众号与 X 长文封面拼的是**信任感 + 主题清晰**，不是纯点击率。
用第 1 章的 white-clean / magazine / news-flash 即可，记住两条平台规则：

- **公众号**：900×383 是从 5:2 横图**中央裁剪**的（左右各裁约 3%）——标题和关键元素避开左右各 5% 边缘，
否则会被裁掉。生成时用 5:2 出图，标题居中。
- **X**：1500×600（5:2）全显示，但信息流缩略图很小——标题字高 ≥1/4 是底线，冲击 1/3 最佳。

## 5. 通用负面提示词（所有风格通用，粘贴在正向提示词后面）

```
中文：绝不出现：错别字、多字、少字；绝不出现英文乱码、无意义符号；
绝不出现可识别的真实人物长相；绝不出现水印、logo（除非后期贴图）；
绝不深底配深字、浅底配浅字（文字与背景必须明暗对立）；
绝不大标题透视变形、扭曲、弧形排列；绝不一句话超过 3 种颜色；
绝不装饰压住文字笔画；绝不左右对半镜像分区（除对比图外）；
绝不死白平板底（必须带纸纹/颗粒/光晕其一）。

EN: Never include: misspelled, missing, or extra characters; garbled English or
meaningless symbols; recognizable real people's faces; watermarks or logos
(unless composited later); dark text on dark ground or light text on light
ground (text must contrast against the background); perspective-warped,
distorted, or arched main titles; more than 3 colors in one line;
decorations covering glyph strokes; mirrored left-right split layouts
(except comparison images); dead flat white grounds (must carry paper grain,
film grain, or a light halo).
```
