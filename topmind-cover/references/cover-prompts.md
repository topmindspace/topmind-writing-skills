# 封面提示词：从意图到具体关系

以下均为本仓原创教学简报，没有效果保证。替换为当前文章的标题与真实材料；按用户要求选择画幅、语言与方向。无需把所有段落相接，也不要求固定数量的候选。

## 组装时可用的信息

| 内容 | 作用 |
|---|---|
| 主题与读者 | 决定画面要解释什么 |
| 第一眼 / 第二眼 | 决定读序与重点，可在脑中直接判断 |
| 字图关系 | 字主导、图主导、场景内文字、对照或共同叙事 |
| 媒介与气质 | 摄影、平面、材料、印刷、插画、抽象等 |
| 实际文案与画幅 | 文字逐字正确，按横竖版分别构图 |

字体、字号、字距、颜色、镜头与道具只写当前方案需要的内容。用户意图已清楚时可以直接完成，不让用户填表。详细方向看 [cover-styles.md](cover-styles.md)，字形看 [typography-system.md](typography-system.md)。

## 1. 编辑摄影

```text
为虚构练习文章设计封面，标题逐字为“少一点，找得到”。
以静物摄影和编辑排版表达整理后的清楚。画面保留一只打开的档案盒与足够负空间，标题使用细致宋体或稳健窄黑体，与盒边形成对齐关系；纸白、深灰和温和蓝色。可安静、可有一处视觉偏移，不加没有意义的装饰。
按指定比例完成构图；可以整张生成，也可以先做主体与背景再后期排字。
出图后核对标题、主题、缩略图与最终裁切，实际问题局部修正。
```

## 当输出不理想

先定位具体问题。泛泛时重想主题关系；画面拥挤时改变读序或对比；字不准确时修字或改用确定性排版；横竖版切坏时重新布局。纯色、无角色或普通字体不自动说明失败。多次迭代没有改善时换路径，迭代与预算相称。

平台尺寸依据与限制见 [platform-cover-specs.md](platform-cover-specs.md)，不把安全区百分比和点击率假设写进所有提示词。
