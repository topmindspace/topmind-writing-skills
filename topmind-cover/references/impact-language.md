# 冲击力设计经验：比较不同关系

醒目可以来自巨大、微小、留白、摄影、字体、情绪或信息价值，没有每张都要加入的元素。先看实际参考与本库样张，选对这篇有用的手法。

| 手法 | 什么时候有帮助 | 另一种同样成立的选择 |
|---|---|---|
| 巨字或大数字 | 主题能浓缩，信息流需快速识别 | 图片主导，标题作为轻辅助 |
| 高对比 | 文字需要跨背景可读 | 柔和对比配足够字号与留白 |
| 单色 / 单点强调 | 需要统一记忆 | 多色编辑系统，层级有序 |
| 角色动作 | 主题有叙事、幽默或冲突 | 无人物的静物、纯文字、抽象图形 |
| 纸纹 / 颗粒 | 介质与题材有关 | 干净纯色与平面留白 |
| 透视 / 材质字 | 字与场景是同一物理世界 | 水平普通字体，用尺度与间距构成设计 |
| 关键词强调 | 读者需要快速扫到重点 | 整句同权，靠断行形成节奏 |
| 原图裁切 | 真实素材本身有价值 | 自制图承载新的组织与判断 |

不要用这些手法逐项打勾。先缩小看主题和读序，再看字、裁切、整体关系；一次有问题就改具体关系。纯色、普通字体、无角色不自动等于单调，复杂场景也不自动高级。

需要构图选项看 `cover-styles.md`，字效看 `typography-system.md`，场景看 `scene-builder.md`。数字、署名、品牌与事实素材准确；其余按当前设计选择。
