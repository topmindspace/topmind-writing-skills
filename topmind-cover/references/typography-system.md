# 字体排印系统（Typography System）

> 标题字体不能单一。变化来自：字形、字号、颜色、高亮、衬条、装饰——
> 六选二，组合出丰富度。

## 一、字形变化（6 种）

| 字形 | 效果 | 适用 |
|------|------|------|
| 超粗黑 | 力量、冲击 | 主标题 |
| 宋体 | 文化、典雅 | 学术、人文 |
| 书法体 | 艺术、个性 | 观点、品牌 |
| 手写体 | 亲切、随性 | 生活、创意 |
| 等宽字体 | 极客、数据 | 科技、代码 |
| 描边字 | 跳跃、醒目 | 点题词 |

**规则**：一封面 ≤2 种字形；主标题 1 种 + 点题词可另 1 种。

## 二、字号层级（4 级）

- Display（1.0）：主标题，字高 ≥1/4
- Headline（0.7）：副标题/双行第二行
- Title（0.4）：胶囊/标签
- Label（0.3）：英文点缀/小字

## 三、高亮手法（5 种，三选一）

1. **撞色**：点题词换主色（如 #0B57D0）
2. **色块衬底**：点题词压色块（白字 on 主色块，全圆角）
3. **马克笔**：荧光色横条（黄/粉/蓝）划过点题词
4. **描边**：双层描边（外白 3px + 内色 1px）
5. **立体**：真 3D 挤压（5-10px，仅 2-4 字）

**禁忌**：全标题高亮 = 没高亮；超过 2 个高亮词即乱。

## 四、背景衬条（4 种）

1. **横向色条**：标题下方的色带（MD3 推荐，优雅）
2. **胶囊底**：全圆角 pill（现代、亲和）
3. **不规则形**：撕纸/笔刷形（创意、手作）
4. **无衬条**：靠字重/颜色区分（极简、高级）

**禁忌**：左侧竖条（太 AI 味）；衬条抢标题风头。

## 五、装饰元素（6 种，≤3 种）

1. 几何线条（细线、虚线、波浪）
2. 光斑/粒子（体积光、lens flare）
3. 纹理（纸纹、噪点、布纹）
4. 印章/标签（旋转 8-15°）
5. 数字徽章（01/02/03）
6. 英文点缀（细体 + 字母间距）

## 六、透视与景深（4 种）

1. **倾斜透视**：元素 5-15° 倾斜（条件触发）
2. **大小透视**：近大远小
3. **前景虚化**：故意虚化的前景元素（镜头感）
4. **背景虚化**：虚化背景突出主体（bg-blur 风格核心）
