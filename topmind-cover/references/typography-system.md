# 字体、字重与排版张力系统

文字在封面上不仅是“说明标签”，更是**画面的骨架、重心与情绪来源**。好的封面排版靠**尺度级差、字重对比与空间对齐**立住气场，而不是堆砌廉价描边和发光特效。

---

## 一、字族气质与跨界搭配

| 字形方向 | 视觉性格 | 经典适用题材 | 反差混搭灵感（破除刻板印象） |
|---|---|---|---|
| **现代无衬线 / 粗黑体** | 理性、直接、力量感强 | 科技发布、干货清单、观点宣言 | 配柔和静物摄影，形成“冷静文字 + 温暖画面”的克制感 |
| **窄黑体 / 压缩哥特体** | 紧凑、现代、极具杂志海报感 | 深度特稿、行业快讯、大数字榜单 | 密集字块配大面积留白，制造瑞士国际主义网格张力 |
| **高对比宋体 / 明朝体** | 锋利、知性、书卷气、精密 | 人文随笔、文化评论、深度长文 | 用于硬核 AI 论文或算法哲学封面，瞬间跳出千篇一律的黑体科技风 |
| **等宽字体 (`Monospace`)** | 工程感、数据精度、档案感 | 价格/性能数字、代码拆解、版本号 | 用超大号等宽数字（如 `$0.25`、`10×`）做主视觉，配中文粗黑标题 |
| **手写体 / 马克笔字** | 在场感、批注感、松弛幽默 | 白板拆解、踩坑吐槽、个人笔记 | 在严谨的论文截图或架构图旁用一行手写红字做批注点睛 |
| **圆体 / 软雕塑字** | 亲切、轻盈、无攻击性 | 入门指南、生活好物、趣味科普 | 配暗色或冷色背景，避免画面过于低幼 |

## 二、建立视觉层级的 4 个实战抓手

1. **字号与字重级差（Scale & Weight Contrast）**
   - 主标题与辅助标签要拉开明显差距（例如主标题用 Heavy/Black 超粗黑，副标题用 Medium 或等宽小字）。
   - 如果标题较长（如 10–14 字），不要全缩成一行小字；按语义分成 2–3 行，或将**最核心的 3–4 个关键词放大加粗 / 换强调色**。
2. **断行即节奏（Line Break as Rhythm）**
   - 断行切忌拆碎完整词组（如不要把“本地模型”拆成两行）。
   - 错位断行（第一行靠左、第二行缩进或对齐图片边缘）能自然引导视线流向画面主体。
3. **数字与单位分离（Number-Unit Hierarchy）**
   - 当封面有关键数字时，把数字本身放大（如 `64`），单位或定语缩小跟在旁边（如 `% 完成率`），比平铺直叙更有冲击力。
4. **300px 缩略图可读性底线**
   - 在手机双列流或公众号列表里，封面往往只有 300px 宽。主标题笔画不能被背景纹理吞没；若背景复杂，优先将文字移入干净负空间，或加一块利落的实色衬条/高对比色块。

## 三、高辨识度字效工具箱（克制使用，每次选 1 项即可）

| 字效手法 | 视觉效果与适用场景 | 避坑提醒 |
|---|---|---|
| **实色衬条 / 荧光笔高亮** | 文字底部垫一条亮黄、国际橙或黑底白字色带，适合新闻快报与证据拼贴 | 衬条边缘要利落，与文字留出适度内边距 |
| **纸面压印 / 浮雕 (Deboss/Emboss)** | 文字像陷进厚棉纸或铸在金属板上，适合重磅总结与人文封面 | 保持光源一致，切忌让过深的阴影遮住关键笔画 |
| **字形蒙版 / 穿插遮挡** | 主体局部（如机箱一角、人物手部）轻微挡住标题非关键笔画，建立前后空间 | 被挡住的字必须依然能一眼认出，绝不遮挡核心词 |
| **轮廓描边 / 双色错位套印** | 营造复古印刷（Risograph）或海报冲击感 | 仅用于超大字号主标，小字做错位会重影发糊 |
| **磨砂玻璃底板 (Frosted Glass)** | 在复杂摄影或暗色架构图上提供干净的落字区 | 底板透明度与明暗对比要够，确保文字锐利清晰 |

## 四、确定性叠字工具（`overlay-title.py` 与 `title-engine.py`）

当生图模型直出中文不够精准、或需要制作版式稳定的系列封面时，推荐先生成无字高质感底图，再用内置脚本精确叠字：

- **`scripts/overlay-title.py`**：轻量快速叠字，支持多行字号、颜色、下划线、描边、阴影与顶部标签胶囊（chips）。
- **`scripts/title-engine.py`**：高级排版引擎，支持按比例定位、逐字字号/颜色、字距（tracking）、竖排、弧排、渐变、材质、实色底板、贴纸、旋转、透视与主体遮挡。
- 运行 `python3 scripts/title-engine.py --list-fonts` 查看本机可用中文字体与字重索引；协议细节见 [design-system.md](design-system.md)，交互样张见 [creative-atlas.html](../assets/examples/creative-atlas.html)。
