# 字体、字号与花式：从字的气质到图像关系

文字既可以负责阅读，也可以成为画面的形状、材料和节奏。先决定它承担什么，再选字族、字重、大小、字距、断行和效果。没有“每张至少两种变化”“最多两个字体”或固定高亮配额。

## 字族与气质

| 字形方向 | 可能的表达 | 可以反向使用 |
|---|---|---|
| 几何或现代黑体 | 理性、清楚、稳定 | 用于温柔生活题材，靠空间而非卡通表达 |
| 窄体 / 压缩黑体 | 紧张、编辑、速度 | 配空白产生克制感 |
| 宋体 / 明朝体 | 书卷、精密、锋利或轻盈 | 科技封面也可用宋体 |
| 圆体 | 亲近、软、轻松 | 与严肃内容形成有意反差 |
| 手写 / 书法 | 节奏、性格、身体感 | 配现代网格，而非总配山水 |
| 等宽 / 像素 | 代码、档案、机器或复古 | 作为小号注释，也可主导整版 |
| 原创字形 | 将文字语义变成形状 | 关键笔画与意思仍需核对 |

同一字族不同字重常能形成统一；相近字族也可以有意搭配，多字族可用共同基线、色彩或节奏组织。字体名称是方向，不表示已安装或允许商用。用实际字体文件与字库覆盖确认，不自动安装到用户系统。

## 字号与阅读任务

大可以制造冲击，小也可以制造空间。先在目标缩略图上看：需要读清的标题是否读清，辅助文字是否真有必要，装饰行是否被误当事实。改字号之外，还可换行数、字重、宽窄、位置、底色与字距。

- 单行可以连续有力，多行可以形成停顿与级差；
- 同字号不同字重、同字重不同位置，均能形成层级；
- 主副标题不必统一比值；字数多不等于要删意思；
- 中英混排看字面高度、基线、标点与单词完整性，不固定英文只能两个词；
- 竖排、斜排、弧线和透视按题材选，不因“非水平”自动重画。

## 花式工具箱

| 手法 | 图文关系 | 常见修正 |
|---|---|---|
| 断行错位 | 让语言节拍成为空间节奏 | 拆坏词意时换断点 |
| 宽窄 / 字距变化 | 疏密本身形成对比 | 拥挤时先调字面与间距 |
| 颜色 / 透明叠印 | 将层次或关键词显现 | 对比不足时换位置或底色 |
| 色块 / 衬条 / 底板 | 构成阅读支点 | 让色块与字有清楚关系，竖条也可用 |
| 轮廓字 / 套印错位 | 露出空间与印刷感 | 关键字不清时增加实色或取消错位 |
| 图像蒙版 / 镂空 | 字与照片或材料共用一层 | 背景太复杂时改变裁切 |
| 压印 / 浮雕 / 纸切 | 触感和光源参与叙事 | 不让材质吞掉关键笔画 |
| 金属 / 玻璃 / 织物 | 材料与主题产生隐喻 | 参数过重时换平面处理 |
| 粉笔 / 铅笔 / 毛笔 | 笔触承担情绪 | 需要精确文字时采用可控字库 |
| 透视 / 弧排 / 波形 | 与建筑、物件或动线一致 | 检查语义、笔画和最终裁切 |
| 像素 / 故障 / 低保真 | 体现媒介、时代或技术感 | 刻意噪声不应冒充故障截图证据 |
| 遮挡与穿插 | 字与前景建立空间或幽默 | 关键字认不出时调遮挡关系 |
| 巨字边界 / 局部出血 | 用画框建立力量 | 出血可设计，误切需要修正 |
| 小字大空间 | 用安静与距离建立辨识度 | 缩略图不清时改字重或布局 |
| 数字与单位分级 | 区分量与说明 | 数字、单位与来源必须真实 |
| 多重字效 | 同一媒介下形成复杂表现 | 关系失去读序时有针对性减法 |

不要把表逐项叠到一张图，也不规定每张只能几项。系列可重复同一种处理，是否变化由内容与作者决定。

## 三种完整的文字方案

标题“重新理解我们与工具的关系”（虚构教学）：

1. 编辑式：窄黑体拆三行，第一行轻，第二行重；一张静物照片压在右下，标题沿左轴，背景纸白。
2. 人文式：宋体完整横排，字号较小、间距舒展，深绿底与浅米字，留出大面积空白。
3. 实验式：把“关系”做成相互穿插的纸字，其他文字平排；通过纸边、材料和光线连接字与场景。

三条路径都保留标题意思，区别是读序与媒介。长标题不必先压成八个字，手法的价值由实际成图判断。
