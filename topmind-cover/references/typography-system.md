# 字体排印系统（Typography System）

> 标题字体不能单一。变化来自：字形、字号、颜色、高亮、衬条、装饰——
> 六选二，组合出丰富度。第七节的 12 种基础花式、第九节的 12 种强调手法（T13–T24）、第十节的副信息组件与第十一节的字体气质表，
> 用于让标题不再是「一行黑体居中」。场景与标题的配合见 `scene-builder.md`。

## 一、字形变化（6 种）

| 字形 | 效果 | 适用 |
|------|------|------|
| 超粗黑 | 力量、冲击 | 主标题 |
| 宋体 | 文化、典雅 | 学术、人文 |
| 书法体 | 艺术、个性 | 观点、品牌 |
| 手写体 | 亲切、随性 | 生活、创意 |
| 等宽字体 | 极客、数据 | 科技、代码 |
| 描边字 | 跳跃、醒目 | 点题词 |

**规则**：一封面 ≤2 种字形；主标题 1 种 + 点题词可另 1 种。

## 二、字号层级（4 级）

- Display（1.0）：主标题，字高 ≥1/4
- Headline（0.7）：副标题/双行第二行
- Title（0.4）：胶囊/标签
- Label（0.3）：英文点缀/小字

## 三、高亮手法（5 种基础手法；更多见第九节）

1. **撞色**：点题词换主色（如 #0B57D0）
2. **色块衬底**：点题词压色块（白字 on 主色块，全圆角）
3. **马克笔**：荧光色横条（黄/粉/蓝）划过点题词
4. **描边**：双层描边（外白 3px + 内色 1px）
5. **立体**：真 3D 挤压（5-10px，仅 2-4 字）

**规则**：一个关键词用 1 种主手法，可再叠 1 种辅手法（如「变色 + 手绘底线」）；**禁忌**：全标题高亮 = 没高亮；超过 2 个高亮词即乱。

## 四、背景衬条（4 种）

1. **横向色条**：标题下方的色带（MD3 推荐，优雅）
2. **胶囊底**：全圆角 pill（现代、亲和）
3. **不规则形**：撕纸/笔刷形（创意、手作）
4. **无衬条**：靠字重/颜色区分（极简、高级）

**禁忌**：左侧竖条（太 AI 味）；衬条抢标题风头。

## 五、装饰元素（6 种，≤3 种）

1. 几何线条（细线、虚线、波浪）
2. 光斑/粒子（体积光、lens flare）
3. 纹理（纸纹、噪点、布纹）
4. 印章/标签（旋转 8-15°）
5. 数字徽章（01/02/03）
6. 英文点缀（细体 + 字母间距）

## 六、透视与景深（4 种）

1. **倾斜透视**：元素 5-15° 倾斜（条件触发）
2. **大小透视**：近大远小
3. **前景虚化**：故意虚化的前景元素（镜头感）
4. **背景虚化**：虚化背景突出主体（bg-blur 风格核心）

## 七、标题花式库（12 种，T1–T12）

> 每张封面选 1 种花式作为主手法，最多再叠 1 种辅助手法。写进 prompt 时把「做法」一列原样写进去，
> 并保留「标题（逐字准确）」的要求。花式只改字的形态，不改字本身。

| 编号 | 花式 | 做法（写进 prompt） | 适合风格 | 注意 |
|---|---|---|---|---|
| T1 | 巨字压版 | 标题占画面高度 1/3–1/2，字距收紧，主体从字后探出半身 | big-type、hard-core-type | 主体不遮笔画 |
| T2 | 马克笔高亮 | 1 个关键词下垫一条荧光黄/粉马克笔横条，横条略宽于字、边缘手绘感 | white-clean、tutorial-steps、orange-warm | 只高亮 1 词 |
| T3 | 报头横栏 | 标题上方一条细横栏写栏目名与日期，标题粗黑，爆点词换朱红 | news-flash、minimal | 日期必须真实 |
| T4 | 中英混排 | 中文粗黑为主，英文产品名或关键词用细体斜体、放大 1.2 倍并换强调色 | brand-launch、dark-saas | 英文 ≤2 个词 |
| T5 | 巨型数字 | 核心数字放大到其余字的 2–3 倍，单独换强调色，单位缩小贴在右下 | gan-huo、chao-wan-3d、gallery-grid | 数字须有出处 |
| T6 | 玻璃浮雕 | 标题做磨砂玻璃质感，边缘一道细高光，背后有柔和彩色光晕 | dark-saas、cinematic-flow、brand-launch | 保证明暗对比 |
| T7 | 衬线宋体 | 标题用高对比衬线宋体，字距加宽，旁边配一枚朱红小印章 | academic-print、magazine、minimal | 不配黑体 |
| T8 | 步骤数字串 | 标题下方一行 01 → 02 → 03 的细线数字串，每个数字配 2–4 字短语 | tutorial-steps、white-clean | 最多 4 步 |
| T9 | 印章角标 | 右上或左下一枚旋转 8–12° 的圆形/方形印章，章内 2–4 字或一个数字 | news-flash、gan-huo、academic-print | 印章内容真实 |
| T10 | 数据胶囊 | 标题下 2–3 个圆角胶囊，各写「指标 + 数字」，胶囊浅色底深色字 | gan-huo、dark-saas、white-clean | 胶囊 ≤3 个 |
| T11 | 断句错落 | 标题拆成两行，第二行右移半个字宽并加大一号，形成节奏 | big-type、orange-warm、bg-blur | 断在词边界 |
| T12 | 贴纸描边 | 标题外加 6–10px 白色描边 + 轻投影，像贴在画面上的贴纸 | chao-wan-3d、ip-fun、sketch-cartoon | 描边不糊字 |

轮换规则：同一系列连续两张封面不用同一花式；同一花式连续用时，必须换背景和主体。

## 八、背景库（按主题挑，与风格配方叠用）

| 背景类型 | 画面描述（写进 prompt） | 适合主题 |
|---|---|---|
| 纸纹米底 | 米白新闻纸底，细微纤维纹理，边角轻微泛黄 | 资讯、快讯、观点 |
| 坐标网格 | 浅灰细网格或等距点阵，局部有淡蓝辅助线 | 数据、榜单、工程 |
| 柔光渐变 | 两色大面积柔和渐变（如蜜桃→奶油、雾蓝→白），带细噪点 | 生活方式、轻观点 |
| 体积光舞台 | 深色背景，一束斜上方体积光打在主体上，空气里有细尘 | 产品发布、版本更新 |
| 景深虚化 | 真实场景大光圈虚化（办公桌、咖啡馆、街景），前景有虚化光斑 | 职场、日常、生活 |
| 微缩场景 | 移轴摄影质感的小场景（书桌城市、纸上山河） | 学习路线、知识地图 |
| 材质特写 | 混凝土、牛皮纸、磨砂玻璃、金属拉丝的大面积特写 | 硬核教程、学术 |
| 霓虹夜景 | 深蓝夜色，远处城市霓虹虚化，地面有反光 | AI 前沿、科幻、极客 |
| 手绘纸面 | 牛皮纸或素描本纸面，铅笔辅助线可见 | 创意、手作、科普 |
| 纯色撞色 | 单一高饱和底色（柠檬黄、克莱因蓝、番茄红）+ 细噪点 | 观点金句、段子 |

原则：背景只承担气氛，不承载信息；背景里不出现第二处可读文字；同一账号同周的封面背景类型不重复超过 2 次。

## 九、关键词强调与多行层级（T13–T24）

> 标题常见的单调：一行、一个字号、一个颜色、居中。下面的手法让标题有「节奏 + 重点」。
> 每张封面：**多行层级 1 种 + 关键词强调 1–2 种**。写进 prompt 时照「做法」一列原样写；字本身逐字不变。

| 编号 | 手法 | 做法（写进 prompt） | 适合 |
|---|---|---|---|
| T13 | 大小行对比 | 标题 2–3 行，最重要的一行字号是其余行的 1.5–2 倍，行距收紧 | 几乎所有，默认首选 |
| T14 | 关键词变色描边 | 关键词换强调色（橙红 / 品牌色），外加 6–10px 深色或白色描边 + 轻投影 | 3D IP、运营、教程 |
| T15 | 硬投影 | 标题加同色系深色硬投影（右下偏移 4–8px，无模糊），像丝网印刷错版 | 复古、报纸、像素 |
| T16 | 手绘圈注 | 关键词外画一个手绘椭圆圈，线条略不闭合，颜色用批改红 | 写作、纠错、清单 |
| T17 | 手绘底线 | 关键词下一条手绘弧线或波浪线（马克笔质感），比字略宽 | 教程、观点、生活 |
| T18 | 符号替换 | 标题里的关系词换成大号符号：≠ → × + ？，符号可断裂、发光或换色 | 对比、纠偏、流程 |
| T19 | 问号 / 感叹号放大 | 句末问号放大到字高 1.3 倍并换强调色，可略微倾斜 | 疑问、悬念、差价 |
| T20 | 斜切色块 | 关键词压在一块倾斜 3–6° 的纯色块上（白字 on 色块），块边缘直切 | 资讯、发布、警示 |
| T21 | 贴纸块 | 副标题或关键词做成圆角贴纸，白色描边 + 轻投影，旋转 5–10° | 合集、运营、旅行 |
| T22 | 双色拼字 | 同一行前半段墨黑、后半段强调色（如「本地部署 / 开源大模型」） | 中英混排、产品名 |
| T23 | 渐变大字 | 英文或产品名用品牌渐变（如蓝 → 紫 → 橙），中文保持纯色 | 发布、品牌 |
| T24 | 字中嵌物 | 一个笔画或字母被道具替换（「O」换成芯片、点换成小鸡头），只换 1 处，保证可读 | 极简、概念海报 |

**多行排法**：

- 上小下大：首行是引子（小一号，可手写体），第二行是主标题（大字）。适合「如何…？」「为什么…」。
- 上大下小：首行主标题，第二行是三个关键词（`选型 · 安装 · 调优` 式）。适合教程、系列课。
- 左对齐三行阶梯：每行略缩进或加大，形成阶梯，最后一行放问号或数字。适合观点、差价。
- 左右分立：标题拆成前后两半，分列主角左右两侧，中间是主角。适合冲突、反差。

## 十、副信息组件（标题之外的点缀，0–2 个）

| 组件 | 做法 | 要求 |
|---|---|---|
| 眉题 / 系列角标 | 左上一块小圆角色块写「第 3 期」「入门篇」 | 真实的系列信息 |
| 标签胶囊 | 2–3 个圆角胶囊，浅底深字或描边 | 每个 ≤6 字，真实 |
| 按钮 | 一个品牌色圆角按钮「开始使用 →」式，轻投影 | 只用于发布 / 产品类 |
| 地标签 | 图钉图标 + 地名胶囊 | 只用于地点相关主题 |
| 引子手写条 | 标题上方一行手写体问句，带手绘底线 | ≤12 字 |
| 流程小字 | 「下载 → 配置 → 运行」式三段，箭头分隔 | 每段 ≤4 字 |

## 十一、字体气质与主题匹配

| 主题气质 | 主标题字体描述 | 辅助字体 |
|---|---|---|
| 运营 / 涨粉 / 活泼 | 超粗圆黑，边角圆润，贴纸描边 | 手写体 |
| 科技 / 发布 | 几何无衬线粗体（英文）+ 现代黑体（中文） | 细体英文，字距拉开 |
| 警示 / 内幕 | 压缩超粗黑体，字距极紧，可做旧印刷 | 等宽小字 |
| 复古 / 视频 / 人文 | 粗黑体带轻微做旧，或复古海报体 | 衬线宋体 |
| 教程 / 方法论 | 中粗黑体，清晰稳重 | 手写批注体 |
| 学术 / 论文 | 高对比衬线宋体 | 细体英文 |
| 写作 / 手作 | 粗黑体 + 局部手写替换 | 钢笔手写体 |

## 十二、多层字效引擎（`scripts/title-engine.py`）

`overlay-title.py` 只能叠水平的单一字体标题，适合快速出稿。要做有设计感的标题时用 `title-engine.py`。先读 `design-system.md`：下面的字效是工具箱，不是清单，一张图里只挑一处重点处理。用法是一份 JSON spec 写多层，每个字块单独定字体、字号、颜色、角度、透视和特效，装饰元件和主体压字也写在同一份 spec 里。每个文字块要写 `role`（main / sub / label / ornament），做非水平处理时写 `reason`。

```bash
python3 scripts/title-engine.py 场景.jpg spec.json --out 封面.png --size 2480x992
python3 scripts/title-engine.py --check spec.json     # 静态检查层级、字号下限、克制原则，不出图
python3 scripts/title-engine.py 场景.jpg spec.json --out 封面.png --strict   # 出图并检查对比度、安全区，不达标退出码 2
python3 scripts/title-engine.py --list-fonts          # 看本机字体是否齐全
```

坐标、字号、描边宽度写 0–1 小数时按画面比例换算（字号相对画面高），写整数时按像素。`anchor` 由两个字母组成：第一个是水平方向 l/m/r，第二个是垂直方向 t/m/b。完整 spec 示例见 `assets/title-specs/`（brand-launch、ip-fun、hard-core-type、white-clean 各一份）。

### 12.2 字效清单与 spec 片段

| 花式 | spec 写法 | 用在哪 |
|---|---|---|
| 字号跳跃 | `"sizes":[0.26,0.21,0.26,0.21]` | 萌系、口号 |
| 逐字变色 | `"char_colors":["#FFF","#FFE14D",null]` | 强调关键字 |
| 渐变填充 | `"fill":{"gradient":["#FF7A1F","#FF3D5A"],"angle":0}` | 主关键词 |
| 纹理填充 | `"fill":{"texture":"concrete"}`，可选 `metal` / `gold` / `scene` / 图片路径 | 硬核、奢华 |
| 多重描边 | `"strokes":[[0.022,"#5A2A0A"],[0.01,"#FFFFFF"]]`（由外到内） | 贴纸、爆款 |
| 3D 挤出 | `"extrude":{"depth":0.12,"dx":0.15,"dy":-1,"color":"#8E8B86","color_end":"#3A3836"}` | 立体字、纪念碑 |
| 长投影 | `"long_shadow":{"length":0.06,"angle":45,"color":"#1E1E1E"}` | 扁平、白色清新 |
| 霓虹外发光 / 内发光 | `"glow":{"color":"#39FF88","radius":0.1,"strength":2.4}`、`"inner_glow":{"color":"#39FF88"}` | 发布、赛博 |
| 故障错位 | `"glitch":{"offset":0.04,"colors":["#FF2BD6","#00F0FF"],"slices":6}` | 赛博、AI |
| 贴纸白边 + 投影 | `"sticker":{"border":0.12,"color":"#FFFFFF"}` | IP、手账 |
| 斜面高光 | `"bevel":true` | 石材、金属 |
| 色块底板 | `"plate":{"color":"#FFE14D","pad":0.12,"radius":0.2}` | 副标题、标签 |
| 高亮笔 / 下划线 | `"highlight":{"color":"#FFE14DCC","height":0.15}`、`"underline":{"color":"#FF3D5A"}` | 干货、教程 |
| 旋转 / 斜切 | `"rotate":-7`、`"shear":-0.18` | 让组合不呆板 |
| 四点透视 | `"perspective":[[0.13,0.22],[0.87,0.22],[1,1],[0,1]]`（左上 右上 右下 左下，相对字块宽高） | 字立在地面、字贴墙 |
| 弧形 / 波浪 | `"arc":{"radius":5.5}`（负值向下弯）、`"wave":{"amp":0.15,"period":4,"tilt":8}` | 环绕主体、活泼 |
| 竖排 | `"vertical":true` | 国风、杂志、错位组合 |
| 手抖 | `"jitter":5`（逐字随机小角度） | 手作、萌系 |
| 英文装饰行 | 小字号 `hei-medium` 加 `"tracking":0.35` | 所有风格的顶部或底部点缀 |

装饰元件写成 `{"type":"deco","kind":...}`，kind 可选 `star`、`sparkle`、`burst`（爆炸框，可带 `text`）、`circle`（手绘圈）、`arrow`（`points` 三点手绘弧线箭头）、`stamp`（印章，可带 1–4 字）、`tape`（胶带）、`dots`（点阵）、`lines`（速度线）。

主体压字写成 `{"type":"occlude","mask":"rembg","region":[x0,y0,x1,y1]}`：在 region 范围内把场景主体抠出来，贴回最上层，让主体压在字上。rembg 需要先 `pip install rembg onnxruntime`。不装 rembg 时，可以用 `"mask":"luma>200"`、`"sat>80"` 这类阈值，或用 `"polygon":[[x,y],...]` 手画。

### 12.3 组合示例（旧版，仅演示写法；成品请用 `assets/title-specs/` 的 P1–P4）

```json
{"type":"text","text":"晨光","font":"hei-black","size":0.36,
 "fill":{"gradient":["#FFFFFF","#C9FFE0","#39FF88"],"angle":90},
 "extrude":{"depth":0.07,"dx":0.5,"dy":0.9,"color":"#0E5A3A","color_end":"#031A12"},
 "glow":{"color":"#39FF88","radius":0.12,"strength":1.4},
 "perspective":[[0,0.08],[1,0],[0.96,1],[0.03,0.9]],"x":0.06,"y":0.48}
```

"3.0" 另起一层，用镂空霓虹（深色填充 + 荧光描边 + 外发光 + 内发光），再加 `shear` 和 `rotate`，和主词的透视方向形成反差。顶部放英文小字行，底部放宋体副标题加半透明底板，最后点两颗 sparkle。
