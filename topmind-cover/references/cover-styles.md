# 封面视觉方向库（22 个可检索起点）

风格名用于找方法，不是允许创作的全集。先读当前文章与实际参考，选择贴题的字图关系，可以混合、变化或另起方向。色彩、字高、字号、角色、纹理、透视、装饰数量和留白比例都由任务与成品判断；不据此统一重画。

实际版式小样见 [creative-atlas.html](../assets/examples/creative-atlas.html)，旧样图可看 `assets/examples/overview.png`。单风格 PNG 若未安装，使用总览、图册和本页继续；文字配方不能代替实际看图。

先选一个视觉关系：字主导 / 图主导 / 字图相互解释 / 系列与对照 / 空间叙事。完整提示词看 [cover-prompts.md](cover-prompts.md)，技术出字看 [design-system.md](design-system.md)，平台场景见 [platform-cover-specs.md](platform-cover-specs.md)。

## 参考、事实与裁切

参考可借读序、网格、色彩关系和材料语言；当前内容形成自己的表达，真实素材与独特标识按许可使用。文案、人物、署名、产品信息与数字据实；旧样图中的名字和数字是虚构演示。按目标横竖画幅分别设计，没有全平台统一安全区。

## 1. white-clean · 白色清新

**视觉关系**：用亮面、负空间和明确读序建立轻盈感。
**字体与空间**：黑体、细宋或同字族不同字重。从断行、字距、字重、位置选择实际需要的变化。
**场景与色彩方向**：静物、线描、原图局部或无主体；纸白 / 炭黑 / 钴蓝。
**可变与反向方案**：可改为冷白或暖白，标题也可低位、小而明确。
**示例简报**：以虚构标题“让资料回到手边”为练习，选择上述关系做一张封面；按指定画幅安排读序，标题逐字保持，不补造副标题与数据。
**需要进一步想法时**：查知识卡 cover-editorial / cover-typography / cover-scene 或相关题材。旧样图若存在为 `assets/examples/white-clean.png`。
