# 场景构建配方（Scene Builder）

> **为什么要有这份**：只给生图模型「风格名 + 标题 + 一个主体」，出来的封面就是「纯色底 + 一行字 + 一个摆拍角色」，单调。
> 好封面是**一个场景在讲标题这句话**：主角在对标题做动作，周围有主题道具，背景有层次，标题本身有花式。
> 本文给出：场景配方（七层）→ 丰富度下限 → 分层提示词模板（中 / 英）→ 风格组合与多方案 → 主题映射 → 配色与背景层次 → IP 与人物 → 评分门槛 → 双路径出字。
> 风格配方见 `cover-styles.md`，标题花式见 `typography-system.md`，构图骨架见 `cover-styles.md`「构图骨架」。

## 一、场景配方：七层，从主题推到画面

先写配方，再写提示词。七层逐层填，每层一句话。

| 层 | 要回答的问题 | 例（虚构主题「本地部署开源大模型」） |
|---|---|---|
| 1. 主题 | 这篇讲什么、给谁看、读者看完得到什么 | 给开发者：在自己电脑上跑开源大模型，不花 API 钱 |
| 2. 核心隐喻 / 冲突 | 用哪个具体画面把主题「演」出来？冲突、反差、对比、转变、动作瞬间 | 「把云搬回家」：一朵云被装进家用主机机箱 |
| 3. 主角 | 谁来演？IP 角色 / 原创人物（不可识别真人）/ 拟人物件 | 原创 3D 小鸡工程师，戴安全帽 |
| 4. 动作与标题互动 | 主角对标题做什么？指、举牌、掀纸、坐在字上、推字、拍摄、拉横幅、从字后探头 | 小鸡用手推车把一朵发光的云推向标题，另一只手指着「本地」二字 |
| 5. 主题道具（2–4 个） | 哪些物件一看就知道是这个主题？优先「行业里的人一眼认得」的东西 | 机箱（侧透能看到显卡）、终端窗口卡片、散热风扇、网线 |
| 6. 背景环境 | 主角在哪里？承载面（桌面 / 地面 / 舞台 / 纸面）+ 远景 + 纹理 | 深夜书房桌面，远处窗外城市灯火虚化，桌面有木纹 |
| 7. 氛围光 | 光从哪来、什么颜色、什么情绪 | 机箱 RGB 冷光从下往上打 + 台灯暖光，冷暖对撞 |

写隐喻时的五个来源（挑一个最贴的）：

1. **字面动作化**：标题里的动词直接演出来（「破圈」→ 角色撞破一张纸；「搬家」→ 推车）。
2. **反差 / 等式**：A ≠ B、A → B、小 vs 大（「会写代码 ≠ 会做产品」→ 一根断开的网线两端各连一个世界）。
3. **行业道具实体化**：把抽象工具做成实物（工作流 → 一排流程卡片；知识库 → 抽屉柜；模型 → 一颗芯片）。
4. **场景置换**：把话题放进一个大家熟悉的场景（旅行地标、电影片场、报纸头版、实验室、厨房）。
5. **结果糊脸**：真实可展示的成果（数据面板、收益截图）——**必须是真实素材**，用原图或打码的用户截图，不让模型编数字。

## 二、丰富度下限（必填，少一项不出图）

| 槽位 | 下限 | 说明 |
|---|---|---|
| 主角 | 1 个 | 角色、人物或拟人物件；**有表情或姿态**，不是证件照 |
| 主角动作 | 1 个，且与标题互动 | 指、举、掀、推、坐、拍、拉、探头、托举之一；「站着微笑」不算 |
| 主题道具 | 2–4 个 | 与主题强相关、能叫出名字；纯星星、光点、气泡不算道具 |
| 装饰 | 1–3 处 | 箭头、手绘圈、贴纸、胶带、印章、光效、纸片；跟主风格走 |
| 背景层次 | ≥3 层 | 远景（虚化环境 / 渐变）+ 中景承载面（桌面 / 地面 / 纸面）+ 纹理或光效；可再加前景虚化 |
| 标题花式 | 1 主 + 1 辅 | 见 `typography-system.md` 第七、九节，至少有「关键词强调」 |
| 副信息 | 0–2 个 | 副标题、标签胶囊、按钮、角标、地标签，**内容必须真实**，不写假编号假署名 |

**上限（防止元素大乱斗）**：主角 ≤2、道具 ≤4、强调色 ≤2、标题外可读文字 ≤2 处；画面只能有**一个第一视觉焦点**（标题或主角之一），另一个排第二。丰富 ≠ 堆砌：每个元素都要回答「它为什么在这里」。

## 三、分层提示词模板

把七层配方填进槽位，**按层顺序写**，标题单独一行逐字写出。【】为必填槽位。

## 四、风格组合与多方案

**主风格 + 辅风格**：主风格定主角和光影的材质，辅风格定背景与装饰的质感。组合时只借辅风格的 1–2 个手法，不把两套配方全叠上去。

| 组合 | 主风格给 | 辅风格给 | 适合 |
|---|---|---|---|
| 3D IP + 纸张拼贴 | `chao-wan-3d` 的毛绒 / 黏土主角 | `paper-collage` 的撕纸、胶带、便签 | 教程、合集、新手向 |
| 复古报纸 + 电影剧照 | `news-flash` 的报头、网点、黑红 | `cinematic-flow` 的剧照光影、胶片颗粒 | 行业内幕、热点评论、反差暴论 |
| 浏览器 UI + 3D IP | `dark-saas` / `white-clean` 的窗口卡片 | `ip-fun` 的角色指向动作 | 产品、建站、工具测评 |
| 像素 + 纯色撞色 | 像素风角色（8-bit） | `big-type` 的巨字压版 | 涨粉、运营、游戏化话题 |
| 旅行实景 + 3D IP | `bg-blur` 的真实地标虚化 | `chao-wan-3d` 的角色 | 消费、旅行、地域差价 |
| 手绘插画 + 流程卡片 | `sketch-cartoon` / `anime-desk` 的人物 | `tutorial-steps` 的步骤卡 | 方法论、实操流程 |
| 发光科技 + 品牌渐变 | `cinematic-flow` 的光带、地平线 | `brand-launch` 的品牌色与按钮 | 模型 / 产品发布 |
| 暗黑报纸 + 硬核立体字 | `news-flash` 的暗版报纸 | `hard-core-type` 的立体大字 | 警示、风险、争议 |
| 学院版画 + 微缩场景 | `academic-print` 的线稿 | `diorama-book` 的移轴小场景 | 论文、原理、知识地图 |

**同主题多方案（默认）**：每次给 **2–3 个明显不同的方案**让用户挑（或按用户要求只出 1 张）。「明显不同」= 下面四项里至少换三项：

1. 核心隐喻（换一个画面讲同一句话）
2. 风格组合
3. 布局骨架
4. 主色调（冷 / 暖 / 黑白红之类）

每个方案先给一句话方案卡：`方案 A｜隐喻：…｜风格：主 + 辅｜骨架：L?｜配色：…`，用户选定后再出图；用户说「直接出」就各出一张。

**禁止连续重复**：同一账号相邻两张封面不用同一主风格；同一主风格连续出现时，必须换隐喻、骨架和配色。查不到历史时，问一句「最近一张封面用了什么风格？」或直接避开本次方案里已用过的。

## 六、配色与背景层次

**配色逻辑**（来自概念海报方法论，见文末出处）：2–4 种颜色——「1 个强主色 + 1 个纸感浅色或低彩中性色 + 1 个深色支撑 + 极少量强调色」。颜色由情绪决定：

| 情绪 | 配色 | 背景纹理 |
|---|---|---|
| 警示 / 内幕 / 冲突 | 黑 + 正红 + 米白 | 报纸网点、旧纸褶皱、暗光 |
| 活泼 / 运营 / 涨粉 | 柠檬黄 / 番茄红 + 黑 + 白 | 纯色细噪点、像素格 |
| 复古 / 人文 / 视频 | 米白 + 墨绿或墨黑 + 赭石 | 牛皮纸、胶片颗粒 |
| 科技 / 发布 | 深蓝 / 深黑 + 品牌渐变 + 白 | 地平线光、粒子、细网格 |
| 温暖 / 生活 / 副业 | 奶油 + 暖橙 + 深棕 | 柔光虚化、植物剪影 |
| 清爽 / 教程 | 白 + 品牌蓝 + 荧光黄 | 方格纸、桌面实物、浅阴影 |
| 理性 / 学术 | 牛皮纸 + 墨黑 + 朱红 | 坐标纸、铜版线条 |

**背景四层**（至少用三层）：

1. **远景**：虚化环境（城市、书房、地标、展厅）或大面积渐变。
2. **承载面**：让主角「站住」的横向结构——桌面、地面、舞台、纸面、台阶、地平线。
3. **纹理**：纸纹、网点、胶片颗粒、噪点、方格。
4. **光效 / 粒子**：体积光、轮廓光、光斑、尘埃、扫描线；前景可加一处虚化物（树叶、纸片、镜头光斑）制造镜头感。

## 七、IP 与人物

- **TopMind 人设可作主角**：鸡（🐔 小鸡）、猫（🐱）、植物（🌱）三个原创形象，和 `topmind-briefs` / `topmind-viral-posts` 共用的 emoji 人设一致。可做 3D 黏土 / 毛绒 / 像素 / 手绘四种材质；同一系列固定一种材质，保持辨识度。
- **原创角色**：可以新造（戴墨镜的小狗、拿红笔的机器人），但**不照抄现有 IP**，不用第三方品牌吉祥物。
- **真人**：不生成可识别的真实人物长相。需要「人」时用原创卡通人物、背影、剪影或手部特写；要真人出镜就用用户自己提供的照片。
- **热点贴合**：重大热点或产品发布时，可以去掉自家 IP，改用贴合该产品的视觉语言（官方配色、产品气质），但不用对方的 logo 与吉祥物原图，除非是用户提供的官方素材。
- **事实类资讯原图优先**：有官方图、截图时用原图当首图，不另画封面；封面里的数字、价格、日期必须在正文有出处。

## 八、成图评分（每项 1–5 分，总分 ≥20 且无单项 ≤2 才交付）

| 维度 | 5 分的样子 | ≤2 分的样子 | 低分怎么改 |
|---|---|---|---|
| 丰富度 | 主角 + 动作 + 2–4 道具 + 装饰 + ≥3 层背景，全部到位 | 纯色底 + 字 + 一个摆拍角色 | 回到第二节补槽位 |
| 主题贴合度 | 遮住标题也能猜出主题 | 换个标题照样能用 | 换成第五节的行业道具 / 隐喻 |
| 标题花式 | 多行大小对比 + 关键词强调 + 1 处辅手法 | 一行黑体居中 | 按 `typography-system.md` 第九节加手法 |
| 层次 | 一个第一焦点，前中远景分明，光有方向 | 元素平铺、互相抢戏或全部一样亮 | 删弱元素、加承载面和光 |
| 信息可读性 | 缩到 120px 宽仍能读出标题，字逐字正确 | 错字、糊字、被遮挡、小字密排 | 缩短标题、减装饰，或改走叠字路径 |
| 质感 | 材质真实，无塑料油光，比例正常 | 劣质 AI 感、手脸崩坏 | 换材质描述、降低复杂度，宁可退到极简大字 |

这份评分和 `SKILL.md` 的冲击力自检一起用：先过自检，再打分。不达标最多重做 3 次，仍不达标就换方案（隐喻或风格组合）。

## 九、双路径出字

| 路径 | 什么时候用 | 做法 |
|---|---|---|
| A. 生图直出字 | 标题 ≤10 字、常用字、模型中文可靠 | 按第三节模板写标题槽位，逐字检查 |
