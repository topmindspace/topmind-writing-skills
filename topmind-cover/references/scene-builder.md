# 场景构建：一种可选的封面方法

场景叙事用动作、隐喻、道具与空间帮助读者记住主题。它适合趣味、故事和部分产品主题；纯文字、摄影、抽象、极简同样成立，见 SKILL.md。

## 一、七层提问（按需取用）

| 层 | 设计问题 | 可用例子 |
|---|---|---|
| 主题 | 读者要记住什么 | 在本地运行工具 |
| 隐喻 / 冲突 | 具体画面能否帮助理解 | 把云搬回家；也可直接展示设备 |
| 主体 | 什么承载主题 | 实物、角色、图形、标题本身 |
| 动作 | 动态是否增加意义 | 搬、推、掀开、连接；静物也可成立 |
| 道具 | 哪些细节能让题材具体 | 机箱、线缆、笔记；数量随叙事 |
| 环境 | 需要多少上下文 | 桌面、留白、展厅、纯色 |
| 光与色 | 想传达什么情绪 | 暖光、冷光、平光、黑白 |

没有角色就不填表情，没有场景就不凑背景层。想法直接写成自然语言也可以，不要求填写整张表。

## 二、元素增减

丰富度来自元素间的关系，单纯多放物件不保证更好。标题有力量时，一行字与纯色就可成立；需要完整场景时，让道具、动作与光线共同说明主题。没有主角动作、道具少或背景平，不构成失败。

## 三、提示词片段

按实际方案删改，文字以用户文案为准，尺寸以当前画布为准：

```text
横向封面，主题是本地运行工具。
一台家用主机放在桌面，窗边自然光，标题落在左侧负空间。
标题逐字为“把工具留在本地”，用清楚的黑体；强调设备与桌面的实际尺度。
```

英文场景版可从具体介质与光线入手：

```text
Editorial still life of a small desktop computer beside a notebook, soft window light,
quiet negative space on the left for the exact Chinese headline provided by the author.
Landscape composition; use the requested export ratio and check the final crop.
```

需要模型生成文字就写明原文并核字；文字难度高时直接留标题区，后期排版。提示词中的道具、风格与负面条件只保留当前方案需要的部分。

## 四、组合与候选

3D + 纸张、摄影 + 编辑文字、手绘 + 流程、纯色 + 巨字、暗底 + 原图都可尝试。一次借几项有用手法即可；系列可稳定重复，也可逐期变化。

需要探索时先看实际样张，做少量结构不同的小样，比较“哪里是第一眼、图文怎么互相解释、主题能否读出”。用户要一张直接完成一张，没要求多图时不固定生成 2–3 张。

## 五、主题联想

| 主题 | 可尝试的具体表达 |
|---|---|
| 本地部署 | 真实设备、桌面、云与机箱的关系 |
| 写作改稿 | 稿纸、红笔、差异标注、纯文字 |
| 教程 | 步骤图、手部操作、成果截图 |
| 人文随笔 | 静物摄影、留白、字体与纸张 |
| 数据 | 关键数字、真实图表、尺度对照 |

## 六、背景与配色

根据媒介选择：摄影可有景深，平面可纯色，版画可线条，信息图可网格。60-30-10 是一种配色起点，不是所有作品的比例。通过实际小图验证层级，纹理、渐变和装饰均按需。

## 七、主体与真实素材

TopMind 小鸡、猫、植物是可选 motif，不代表其他作者身份。原图、人物照片、品牌资产与原创插画根据用途、授权和当前工具能力选择。事实来源与生成示意分清，数据、署名和产品行为准确；角色与品牌素材注意许可及上下文。

## 八、看图判断

| 维度 | 看什么 | 可能改法 |
|---|---|---|
| 主题 | 图是否支持这篇文章 | 换主体、收准标题或删无关细节 |
| 可读性 | 文字是否准确，缩略图能否读 | 换字号、字重、位置、背景 |
| 层级 | 读序是否符合意图 | 调整尺度、对比、间距 |
| 整体 | 颜色、字与图是否合适 | 换一项关系，而非堆满效果 |
| 细节 | 裁切、遮挡、错字、变形 | 局部修正或换制作路径 |

不设置总分交付门槛；自评高分不能证明作者更喜欢。不同候选同标准看，必要时用匿名选择验证。纯色、无人物等不作为扣分项。

## 九、出字路径并列选择

整张生成适合文字与场景融为一体；场景图 + `scripts/title-engine.py` / `scripts/overlay-title.py` 适合精确、较长或需迭代的文案；纯文字可直接排版。按任务从一开始选合适路径，无需先失败三次才切换。

## 十、排版实施

需要现成起点可看 `assets/title-specs/`、`design-system.md` 和 `typography-system.md`。标题工具的固定尺寸与装饰检查只反映模板配置，实际设计以核字、可读、裁切与用户意图判断。迭代以问题和预算为依据，不因自评未达数字持续重做。

## 更多场景路径

| 路径 | 可用关系 | 气质变化 |
|---|---|---|
| 空镜 | 门框、走廊、桌面、光落点 | 从清晨到深夜，从纪录到悬念 |
| 静物 | 材料、尺度、使用痕迹 | 精密、温暖、粗粝或洁净 |
| 人物 | 视线、姿态与环境距离 | 纪实、时尚、生活或戏剧 |
| 建筑 | 墙面、楼梯、路径与字 | 理性网格或透视张力 |
| 微缩 | 地形、地图、书页世界 | 玩具感、研究感或轻幽默 |
| 纸与档案 | 裁边、索引、叠层 | 编辑、复盘或历史 |
| 抽象 | 重复、疏密、异常、通路 | 冷静或表现，不画假统计 |
| 无场景 | 字、纯色、留白 | 字形与空间自己讲述主题 |

知识卡 cover-scene / cover-photo / cover-abstract / cover-material 有可迁移例子；检索方法见 [knowledge-library.md](knowledge-library.md)。同主题可以换镜头、时间、材料或读序，不靠道具数量制造丰富度。
