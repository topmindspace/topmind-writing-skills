# 全平台封面与头图尺寸实战指南

不同平台的信息流缩略图、文章页头图、转发卡片和个人主页网格各自采用不同的画幅比例。做封面前先确定目标发布形态，按对应画幅构图，让核心标题与主体在手机缩略图（约 300px 宽）下一眼可读、不被裁切。

---

## 一、主流平台封面尺寸速查表

| 平台与发布形态 | 推荐像素尺寸 | 画幅比例 | 预设标识 (`--preset`) | 排版与防遮挡实战要点 |
|---|---|---|---|---|
| **公众号 · 普通长文宽封面** | **900×383** | 约 `2.35:1` | `wechat` / `article` | 顶图横幅较扁，标题宜精炼（1–2 行），避免上下贴边 |
| **公众号 · 转发与列表方图** | **900×900** | `1:1` | `wechat` | 与宽图独立从原图裁切或单独排版；勿直接从 2.35:1 宽图硬截中央 |
| **公众号 · 图片消息（小绿书）** | **1080×1440** | `3:4` | `xiaohongshu` | 竖版满屏展示感最强，整组图片保持画幅统一（或用 `1:1` 方图） |
| **X Article · 长文头图** | **1500×600** | `5:2` | `article` | 超宽画幅，适合左右分栏或中央聚焦构图；注意与个人主页 Banner 区分 |
| **X 普通短帖 · 单图配图** | **1200×675** | `16:9` | `x-post` | 时间线单图完整展开不裁切；高密度信息卡片也可用 `1:1` (`1200×1200`) |
| **小红书 · 竖版图文/视频笔记** | **1080×1440** | `3:4` | `xiaohongshu` | 双列流首选比例（占屏面积最大）；主标题放中上部，避开底部梯度阴影与角标 |
| **小红书 · 横版笔记** | **1080×810** / **1440×1080** | `4:3` | `landscape-pair` | 适合风光、桌面横拍、宽屏实测对比 |
| **抖音 / 视频号 · 图文与 3:4 封面** | **1080×1440** | `3:4` | `douyin` | 信息流与个人主页双列网格通用比例 |
| **抖音 / 视频号 · 全屏竖版视频** | **1080×1920**（含中央 `3:4`） | `9:16` ⇄ `3:4` | `vertical-pair` | 核心文字与主体排在中央 `1080×1440` (`3:4`) 窗口内，避开底部文案与右侧图标 |
| **横版视频 · 跨平台双封面** | **1920×1080** + **1080×810** | `16:9` ⇄ `4:3` | `landscape-pair` | 核心文字与主体排在 `1920×1080` 的中央 `1440×1080` (`4:3`) 窗口内，两侧背景延展 |

> **注**：以上尺寸为经过实战验证的高清导出预设。若具体发布入口或广告/商城类目有特殊像素与文件体积要求，以用户指定尺寸和当前发布页预览为准。

## 二、跨平台「一图多投」与安全区法则

### 1. 横版一图双投（`16:9` 母图 ⇄ 中央 `4:3` 核心区）
当同一条横版内容需要同时适配宽屏（`16:9`，如 X 短帖、B 站/横屏视频）和双列流横图（`4:3`，如抖音/小红书横版封面）时：
- **画布尺寸**：按 **1920×1080**（`16:9`）建立母图。
- **中央安全窗**：将主标题、人物面部、核心产品轮廓全部安排在中央 **1440×1080**（`4:3`）区域内；左右两侧各 **240px** 仅放置可裁切的环境延展或纯色背景。
- **一键导出**：使用 `--preset landscape-pair` 自动输出完整 `1920×1080` 与中央裁切的 `1080×810`（`4:3`）。

### 2. 竖版一图双投（`9:16` 母图 ⇄ 中央 `3:4` 核心区）
当同一条竖版内容需要同时适配全屏竖版（`9:16`，如抖音/视频号全屏流）和 `3:4` 封面框（如小红书笔记、抖音个人主页与双列流）时：
- **画布尺寸**：按 **1080×1920**（`9:16`）建立母图。
- **中央安全窗**：将主标题与核心视觉主体放在中央 **1080×1440**（`3:4`）区域内；上下两端各 **240px** 仅作背景延展（同时天然避开手机顶部状态栏与底部字幕/操作栏遮挡）。
- **一键导出**：使用 `--preset vertical-pair` 自动输出完整 `1080×1920` 与中央裁切的 `1080×1440`（`3:4`）。

### 3. 横竖跨形态适配（横图 vs 竖图 vs 方图）
- **宽幅横图（`5:2` / `2.35:1`）转方图（`1:1`）**：如果是无字或文字居中的主视觉图，可直接从高清原图分别等比裁切宽图与方图；如果宽图采用「左字右图」排版，直接居中方裁会切掉左半边标题，此时应使用 `--anchor left` 或针对 `1:1` 重新排字。
- **横版长文转小红书/抖音竖版**：不要把 `2.35:1` 的横幅硬塞进竖版画布上下留黑边，应当改为 `3:4` 竖向构图（上字下图，或满幅大图 + 负空间落字）。

## 三、平台视觉气质与实战经验

- **小红书（`3:4` 竖版为主）**：
  - 双列信息流里封面缩略图宽度约占半屏，**第一眼视觉焦点与标题字重对比**决定了点击意愿。
  - 生活方式、好物实拍类封面宜用自然光真实场景，文字简洁点睛；干货清单、测评对比、工具拆解类封面可用 **Bento 模块化信息卡**、**手绘批注** 或 **瑞士网格大字**，把核心数字和结论直接亮在封面上。
- **抖音 / 视频号（`3:4` 图文与 `9:16` 视频）**：
  - 信息流滑动极快，主标题宜控制在 **6–12 个字** 以内，重点词通过字号级差或高对比色块突出。
  - 注意避开右侧头像/点赞列（约占右侧 12% 宽度）和底部账号名/文案区（约占底部 15%–20% 高度）。
- **微信公众号（`2.35:1` 宽图 + `1:1` 方图）**：
  - 深度长文封面讲究**编辑质感与真实信息密度**，切忌“大片苍白底色 + 三个孤零零大字”的假极简，也不要堆砌廉价赛博霓虹。
  - 转发到微信群或朋友圈时只显示 **1:1 方形小图**，务必确认方图内主体完整、核心关键词未被切断。
- **X Article（`5:2`）与 X 短帖（`16:9`）**：
  - `1500×600` 的 `5:2` 画幅非常扁宽，适合「左侧强字重结论 + 右侧真实截图/论文高亮/等轴测结构图」的黄金分割布局。
  - 凡涉及生成式概念 UI 或功能效果的封面，在边角清晰标注 **`功能示意，不是实拍`**，用诚实建立专业信任。

## 四、多平台裁切脚本速查

安装了 `topmind-cover` 时，可在该技能的 `scripts` 目录使用 `crop-cover.py` 从原图独立等比裁切（绝不拉伸变形，且自动保护原图不被覆盖）：

```bash
# 1. 默认预设 (article)：同时输出 X Article (1500×600) 与公众号宽封面 (900×383)
python3 crop-cover.py 横版主图.png --out-dir 输出目录

# 2. 公众号双封面 (wechat)：从原图分别裁切宽图 (900×383) 与分享方图 (900×900)
python3 crop-cover.py 原图.png --preset wechat --out-dir 输出目录
python3 crop-cover.py 原图.png --preset wechat --anchor left --out-dir 输出目录

# 3. X 普通短帖配图 (x-post)：输出 16:9 (1200×675)
python3 crop-cover.py 主图.png --preset x-post --out-dir 输出目录

# 4. 小红书 / 抖音图文竖版 (3:4)：输出 1080×1440
python3 crop-cover.py 竖版主图.png --preset xiaohongshu --out-dir 输出目录
python3 crop-cover.py 竖版主图.png --preset douyin --out-dir 输出目录

# 5. 横版双尺寸母图 (landscape-pair)：从中央 4:3 已构图的 16:9 母图导出 1080×810 与 1920×1080
python3 crop-cover.py 横版16比9母图.png --preset landscape-pair --out-dir 输出目录

# 6. 竖版双尺寸母图 (vertical-pair)：从中央 3:4 已构图的 9:16 母图导出 1080×1440 与 1080×1920
python3 crop-cover.py 竖版9比16母图.png --preset vertical-pair --out-dir 输出目录
```

`--anchor` 支持 `center`（默认）、`left`、`right`、`top`、`bottom`。裁切后务必打开实际输出图核对文字与主体完整性。
