# 封面样张与交互图册

本目录保留 29 张历史主样张 / 变体及一张 overview.png，总计 30 张 PNG；另有可直接打开的 [creative-atlas.html](creative-atlas.html)，含 8 组可切换横竖布局的原创 HTML/CSS 排版研究。

## 怎样看

- 先看总览或交互图册，比较字图关系、字体气质、材料、镜头与空间；不只比较颜色。
- `<style>.png` 为历史主样张，通常是 1500×600；`-alt`、`white-clean-b/c/d` 与 showcase 提供变化。它们不是所有封面的固定尺寸或风格标准。
- Git 仓库与独立 Release ZIP 保留全部 PNG；npm 仅带 overview.png 和 HTML 图册以减小体积。单图未安装时使用已有材料，不声称看过缺失图片。
- 26 张可再生的 `-wechat.png` 裁切副本已移除。需要宽图 / 方图时用当前裁切工具从原图独立输出，损伤标题或主体时重排，不沿用旧中央横带要求。

## 内容与复用

历史示例按仓库的原创与虚构示例声明提供，图片中的标题、品牌、署名和数字不作为事实材料。参考可迁移构图、色彩与叙事方法；使用真实素材和独特标识时核对许可，不复制虚构数据到正式稿。

样图可按本仓许可使用或修改，当前用户意图和文章主题优先；不要求只能替换主体与标题，也不固定系列必须换花式、必须有角色或纹理。
