# 知识卡导航

原创教学卡以 illustrative 标记，已运行的技术回归与实际检查记录以 observed 标记；active 只表示可检索，不表示效果已验证。先按用途选卡，再读正文；无需一次加载全部。候选与增补流程见技能参考中的 knowledge-library.md。
