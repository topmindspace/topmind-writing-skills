# 视觉简报转化：把空泛形容词变成具体画面

用户常说“想要一张高级、有层次、吸引人、不落俗套的封面”。如果直接把“高级、震撼、大师级、电影感”塞进生图提示词，模型只会吐出千篇一律的发光塑料图。先把形容词翻译成**具体的视觉关系**：

## 形容词 → 可执行的视觉动作
- **“高级 / 克制”** → 减少颜色数量（控制在 2–3 色）、拉大负空间留白、指定真实物理材质（厚棉纸、阳极氧化铝、哑光亚克力）与严密对齐轴；
- **“有吸引力 / 抓眼球”** → 建立极端尺度级差（如巨型关键数字 `$0.25` 占画面三分之一）或真实原图上的荧光黄高亮反差；
- **“有层次 / 丰富”** → 采用 Bento 模块化卡片分区，或用 2–3 层扫描纸片与索引卡错位叠放，而非堆砌零碎道具。

## 简报转化示范
- **原始需求**：“写了一篇关于精简笔记系统的文章，做个有质感的封面。”
- **转化后的视觉简报**：
  ```text
  16:9 横版编辑静物封面。暖白桌面上仅放一只半开的牛皮纸档案盒，右侧清晨自然光投下干净阴影；左侧预留 45% 开阔负空间，用高对比细宋体排布标题“少一点，找得到”，标题基线与档案盒边缘严密对齐。
  ```
