# 抽象图形：用秩序与唯一异常表达概念

当文章探讨算法机制、系统瓶颈或思维方法时，用**规律阵列中的一次异常（The Anomaly）**来表达核心概念，远比堆砌发光大脑、芯片和代码雨更高级。

## 概念到图形的转化
- **筛选 / 过滤**：一组杂乱线条穿过一道窄门后变成整齐的平行线；
- **偏差 / 破局**：严整的黑白点阵或细竖线中，唯独一枚圆点或一条线变成朱红色并向外折开；
- **上下文压缩**：左侧密集的多层网格向右收束为一条极简的高亮细线；
- **协同 / 路由**：几条不同色相的干净几何轨迹在中心节点汇合。

## 两种高辨识度配色
- **瑞士理性白**：骨白底（`#FAF8F5`）、细灰网格、炭黑粗黑标题 + 一处国际橙/朱红异常点；
- **深邃精密暗**：近黑底（`#0B0D13`）、暗灰结构线、银白标题 + 一道翠绿/青色信号轨迹。
