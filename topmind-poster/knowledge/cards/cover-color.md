# 色彩：关系、面积与语境

原创教学示例；人物、产品和数字如未另有来源均为虚构练习，不可充当作者亲历或实测。

## 可用起点
- 墨黑 / 骨白：靠字号、材料与空间出层次；
- 酒红 / 纸白 / 暖灰：温暖、编辑感，也可用于技术评论；
- 藏蓝 / 雾蓝 / 银白：安静、精密；
- 桃粉 / 辣椒红：近似色制造热烈；
- 苔绿 / 柠檬黄：自然与跳跃；
- 多彩：统一明度、重复形状或稳定网格，避免每项同时争主角。

## 一次有效调整
若浅蓝字在米底上难读，可加深字色、换底、增加底板、换字重或移动位置。不要把问题直接归因为“颜色不够炸”。纯白、纯黑、低饱和与荧光都可有用途。

参数只是起点，文字跨复杂背景时检查局部；自动对比度数字不能覆盖所有质感与边缘情况。
