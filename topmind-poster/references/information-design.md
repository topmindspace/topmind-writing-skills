# 信息设计：结构与形式的选项

先想读者需要理解什么，再选择承载它的形式。结构可以在写前梳理，也可以通过草稿和资料反复修订。复杂任务有骨架更省返工，简单短文在脑中理清主信息就能开始。

## 可选骨架

```markdown
# 骨架
类型：（记录 / 观点 / 教程 / 资讯 / 方法论 / 随笔等）
主要信息：（读者带走什么）
读者：（已有知识、关心的问题）
篇幅：（按任务估计，可调整）

## 主线与依据（按体裁选填）
观点：主张 / 依据 / 可能反例
教程：目标 / 前提 / 步骤 / 成功判断
故事：场景 / 变化 / 细节 / 余味
资讯：事件 / 时点 / 范围 / 对读者的影响

## 每节（需要时填写）
| 节 | 要点 | 形式 | 图表或材料 | 字数 |
|---|---|---|---|---|
| | | | | |
```

判断数量、素材比例、自制图数量都不设配额。骨架可以修改，材料没有支持原设想时调整主线。方法论与架构图常有帮助，纯文字解释更清楚时也可采用。

## 内容与形式

| 内容 | 可选形式 | 如何比较 |
|---|---|---|
| 一个判断 | 首句、标题、故事后落点 | 读者何时需要知道它 |
| 并列项 | 列表、短段、卡片 | 条目是否易扫描，是否值得分开 |
| 步骤 | 编号、操作段、流程图 | 顺序、分支和前提是否清楚 |
| 多对象多维比较 | 表格、分行、小多图 | 能否对齐相同维度 |
| 改前改后 | 两段、对照块、差异标注 | 差别与代价是否可见 |
| 趋势与排名 | 原图、重画图、表或数字 | 量纲、时间、误差与来源 |
| 时间线 | 时间轴、列表、叙事 | 读者关心顺序还是因果 |
| 因果与取舍 | 段落、因果图、案例 | 中间推理是否完整 |
| 故事与情绪 | 场景段落、对话、节拍换行 | 节奏是否服务体验 |

一张图可以解释结构，也可以展示比较；图标题可给结论或说明主题。原图、自制图各有用途。必要的文字概述帮助扫读和无障碍阅读，不必完全移除图中已有数字。

## 长度与密度

短文 300–800 字、长文 1500–2500 字、手机短段两三句，是常见起点，不是上限。教程、研究、随笔有不同节奏。图、表、列表不按字数配额插入，连续文字本身不证明问题。

用“这部分让读者多理解了什么”分配篇幅：背景、反例、情绪、铺垫也可以有价值。删句、合并、转列表都是工具；必要时补解释比删字更好。

## 平台适配

普通 X 帖以纯文本读序为主，Markdown 标记通常原样显示；`-` 和 `1.` 可以直接当文字列表。X Article 富文本、公众号 HTML 与纯文本是不同链路，按实际导出器适配。表格、图片粘贴等行为可能变化，发布前实际检查。

[creative-practice.md](creative-practice.md) 给出不同骨架的样张；各写作技能随包的 X 排版说明提供普通帖选项。

## 脚本的 I1–I9

`info_design_hints.py` 标记连续文字、图表密度、并列与对照、重复、首段长度、长节、预算偏差和判断分布。它量的是表面特征，无法判断故事铺垫、论证和审美质量；I 提示不作退出失败条件。`type: essay` 可减少不适合随笔的提示。已适合读者时直接保留，不为得到“零提示”改变形式。
