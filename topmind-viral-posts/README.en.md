# topmind-viral-posts · X Viral Short Posts

**[中文](./README.md)** | English

Short, real, hooked — read in 3 seconds, impossible not to like/comment/follow. 6 viral templates distilled from real high-engagement X posts in the Chinese community, each post paired with 1 image.

- Version: **v0.3.2** (ships with `@topmindspace/topmind-writing-skills@0.8.22`)

## Install

```bash
npx @topmindspace/topmind-writing-skills install topmind-viral-posts
```

## 6 Types

| Type | Hook | Image |
|---|---|---|
| Tips & advice | "Mistakes beginners make" | Slogan graphic / landscape |
| Follow-for-follow | Direct ask + follow-back promise | Pet / portrait |
| Self-deprecating humor | Concrete numbers + contrast | Funny pet / fantasy |
| Interactive question | Either-or / soul question | Slogan graphic / landscape |
| Daily check-in | Small wins + blessings | Landscape / pet |
| Newcomer intro | Personification + ask for follows | Pet / portrait |

## Images

Generated via `topmind-cover`, 5 image banks: portraits / pets (cats first) / landscapes / fantasy / slogan graphics. X single image 1200×675.
