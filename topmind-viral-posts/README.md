# topmind-viral-posts · X 段子

[English](./README.en.md) | 中文

**一句一行、零 emoji、三秒看完的 X 短帖。** 12 种话题段子 + 2 种关系帖，每种都有适用题材、钩子、结构、收尾、反例和原创示例。先想清楚想让哪种人来评论，再挑写法。

- 版本：**v0.3.19**

```bash
npx @topmindspace/topmind-writing-skills install topmind-viral-posts
```

你可以这样说：「来条段子」「不懂就问」「写个群聊体」「来条卧槽体」「蹭一下这个热点」「写条互关帖」。

## 14 种写法

| 写法 | 一句话 | 典型开头 | 想要的评论 |
|---|---|---|---|
| A1 不懂就问 | 装傻式真疑问 | 难道没人…吗？ | 懂行的人来解释 |
| A2 扒料求证 | 线索 + 上次结果 + 猜测 | XX 要上新了？！ | 补线索、猜结果 |
| A3 故障求证 | 第一时间问挂没挂 | XX 挂了吗？ | 「我也是」+ 接梗 |
| A4 卧槽体 | 真实反应 + 换算反差 | 卧槽，算完我人傻了 | 震惊、转发 |
| A5 冷知识 | 我才知道 / 白干了 | 我才知道… | 「我也才知道」 |
| A6 群聊体 | 每家一句「xx：」 | 今日 XX 群： | 接梗、补一家 |
| A7 连续剧 | 同一主角的连续进展 | 栏目名 + Day N | 竞猜、出主意 |
| A8 算账 | 自己的数字换算成钱和时间 | 一个 XX 干掉我 N% 额度 | 晒自己的账 |
| A9 站边轻判断 | 承认一方 + 内行轻判断 | 确实…但… | 两边站队 |
| A10 荒诞自嘲 | 集体痛点写成荒诞画面 | 我以为…已经是极限了 | 共鸣、晒经历 |
| A11 产品反转 | 具体产品 + 场景 + 动作反转 | 一个生活场景 | 接梗 |
| A12 借热点 | 新事套旧梗 | X 版「某某」来了 | 接梗、站队 |
| B1 关系帖 | 互关、新人、打卡、差额冲刺 | 真实进展 | 关注、打招呼 |
| B2 互助帖 | 求码、送码 | 真实需求 | 送码、求码 |

完整拆解见 [references/patterns.md](./references/patterns.md)，里面还有旧版类型的对照表。

## 示例（原创）

**A4 卧槽体**

```text
卧槽，算完我人傻了

某公司一个新机房要放 20 万张卡

按一张卡一台电脑算，差不多是一个小县城每家一台

我这边还在为一个月 20 块的订阅犹豫...
```

**A5 冷知识**

```text
说个冷知识：

草稿箱里的定时帖，改过一次就重新排队

我昨晚改了三次错别字

难怪到现在还没发出去...
```

**A11 产品反转**

```text
让某编辑器的 agent 帮我整理仓库

它扫了一遍

说有个文件三个月没人动过

建议删掉

我点了确认

然后它自己的配置文件就没了
```

## 几条关键做法

- **段子体**：一句一行，行与行之间空一行，完全不用 emoji，分点不加符号。
- **收尾**：「...」留白、作者真拿不准的问题、或一个动作反转都可以；不用「你们觉得呢？」这类套路互动尾巴。删尾测试：删掉最后半句更好就删。
- **话题标签**：话题段子默认不带，要带最多 2 个；关系帖、互助帖 1–3 个。内部分类标签（类型、想要的评论、平台、语气）写在交付说明里，不进正文。
- **配图按类型**：多数写法纯文字就够；扒料、故障、算账在截图本身就是证据时配一张；关系帖用自己的主页或后台截图。没有原图先问，同意后再走 `topmind-cover`。
- **有事实的段子**：先核对来源，链接和原图另发，正文不写查证过程。
- **回复与转发点评**：先接住对方的点，再补一条自己的信息；给两个口吻不同的版本。

## 检查

```bash
python3 scripts/lint_x_post.py 段子.txt --duanzi          # 段子：出现 emoji 报 W13
python3 scripts/lint_x_post.py 关系帖.txt --kind ops      # 关系帖、互助帖
```

E 错误清零；W 警告每条给结论；H 提示只供判断。现成文字转段子交给 `topmind-format`；改稿交给 `topmind-revise`。

## 何时不用

快讯、榜单、新品这类信息型短文 → `topmind-briefs`；X 长文 → `topmind-x-article`；只排版不改字 → `topmind-format`；发帖 → `topmind-x`（须你确认）。

示例全部自己写，名称和数字虚构，不收录任何第三方原文。
