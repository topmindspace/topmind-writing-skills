# topmind-viral-posts 原创示例（段子）

七条段子示例，都是我们自己写的，人物、产品、数字和情节全部虚构，只演示写法。

| 文件 | 类型 | 看点 |
|---|---|---|
| [`01-A1-不懂就问.txt`](./01-A1-不懂就问.txt) | A1 不懂就问 | 真疑问开头 + 一个具体体验，「...」收 |
| [`02-A4-卧槽体.txt`](./02-A4-卧槽体.txt) | A4 卧槽体 | 情绪后面马上跟数字，换算成熟悉的单位 |
| [`03-A5-冷知识.txt`](./03-A5-冷知识.txt) | A5 冷知识 | 「我才知道」的懵逼口吻，不当老师 |
| [`04-A11-产品反转.txt`](./04-A11-产品反转.txt) | A11 产品反转 | 具体产品 + 可信场景 + 末行动作反转 |
| [`05-A6-群聊体.txt`](./05-A6-群聊体.txt) | A6 群聊 / 拟人对话 | 每家一句「xx：」，最后一句是包袱 |
| [`06-A7-连续剧.txt`](./06-A7-连续剧.txt) | A7 连续剧 | 固定栏目名 + 先给自己的押注 |
| [`07-A2-扒料求证.txt`](./07-A2-扒料求证.txt) | A2 扒料求证 | 线索 + 上次的结果，「？！」开头 |

格式要点：一句一行，行与行之间空一行，全程不用 emoji，对话写「xx：」，正文不放链接；话题段子默认不带话题标签。自查：`python3 scripts/lint_x_post.py 文件 --duanzi`。
