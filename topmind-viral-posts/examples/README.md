# topmind-viral-posts 原创示例（爆款段子与短帖）

七条原创段子示例（人物、产品、数字与情节均为教学虚构，演示不同互动机制与节奏）：

| 文件 | 机制类型 | 核心看点 |
|---|---|---|
| [`01-A1-不懂就问.txt`](./01-A1-不懂就问.txt) | A1 不懂就问（扮猪吃老虎） | 抓住离谱的产品槽点故意装傻发问，用 `？？？` 与 `...` 把吐槽空间留给评论区 |
| [`02-A4-卧槽体.txt`](./02-A4-卧槽体.txt) | A4 卧槽体（量级换算） | 情绪破冰后立刻给真实量级，换算成日常可感知的参照物，末尾拉回自身反差 |
| [`03-A5-冷知识.txt`](./03-A5-冷知识.txt) | A5 踩坑冷知识 | 用「我刚踩坑才知道」的平视口吻代替好为人师的科普 |
| [`04-A11-产品反转.txt`](./04-A11-产品反转.txt) | A11 产品反转 | 具体操作场景铺垫，最后一行揭晓荒诞结果，包袱落完立刻收住 |
| [`05-A6-群聊体.txt`](./05-A6-群聊体.txt) | A6 群聊 / 拟人对话 | 同台紧凑排布多方台词，最后一句用用户视角抖响包袱 |
| [`06-A7-连续剧.txt`](./06-A7-连续剧.txt) | A7 追更连续剧 | 时间线递进建立反差，末尾给出自己的具象押注引发互动 |
| [`07-A2-扒料求证.txt`](./07-A2-扒料求证.txt) | A2 扒料求证 | 先抛悬念钩子，紧跟一手代码/文档线索与历史规律对照 |

**排版与节奏提示**：短段子常用空行拉开呼吸感，群聊对话可紧凑连排；标点（如 `？？？`、`？！`、`...`）与少量契合语气的 emoji 按情绪自然取用，不设死板禁令。可用 `python3 scripts/lint_x_post.py 文件 --duanzi` 检查格式。
