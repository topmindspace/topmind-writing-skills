# topmind-viral-posts · X 引流段子/爆款短篇

基于对 X 中文区常见高互动写法的归纳，示例均为自编。目标：**短、真、钩子**——读者 3 秒能看完，忍不住点赞/评论/关注。

> **必读（交付格式是硬约束）**：[references/x-delivery-contract.md](references/x-delivery-contract.md)——**段子完全不用 emoji**（无人设点缀、无情绪表情、无列表符号）；分点就一条一行、靠行间空行区分，禁用 `- ` `1. `；每条帖子正文是一段可直接复制的纯文本（单独一个 `text` 块），**不含 URL 和来源行**；链接一条、图片一条另发，内部标签放说明里。
> **写法规则**：段子、回复、转发点评按 [references/core-voice.md](references/core-voice.md) 的段子 / 回复条目（V19 V26 V27 V29–V32）；去 AI 味按 [references/de-ai-rules.md](references/de-ai-rules.md)。

## 先读：写作原则与信息设计

本技能建立在两份共享文件上，动笔前先读：

- [references/social-writing-principles.md](references/social-writing-principles.md)：8 条社交媒体写作原则（先想清楚、结论先行、每句都有新信息、形式跟内容走、简单清楚、原图优先、站在读者那边、真实有分寸）
- [references/information-design.md](references/information-design.md)：内容 → 形式决策表、篇幅和密度、去啰嗦的判断法
- 措辞和口吻在这两层之上，见 [references/core-voice.md](references/core-voice.md)
- 研究类选题（要查资料、做对比的）：[references/research-mode.md](references/research-mode.md)

段子：一个主角、一个画面、一句动作反转；不铺垫，每句都有新信息。

## 十八大类型

| 类型 | 核心钩子 | 配图建议 | 默认标签（用途｜语气｜话题） |
|---|---|---|---|
| 1. 干货忠告型 | "新手最容易犯的错误" | 标语图 / 风景（远眺感） | 立人设、涨粉｜干货利落｜#新手指南 |
| 2. 互关求粉型 | 直接求 + 承诺回关 | 宠物（亲和力） / 美女（吸睛） | 互关｜亲和低姿态｜#蓝V互关 #follow |
| 3. 自嘲幽默型 | 具体数字 + 反差 | 宠物（搞笑） / 奇幻（反差萌） | 互动、日常｜自嘲幽默｜#涨粉日记 |
| 4. 互动提问型 | 二选一 / 灵魂拷问 | 标语图（二选一文字） / 风景 | 互动｜好奇追问｜话题词按题材取 |
| 5. 打卡日常型 | 日拱一卒 + 祝福 | 风景（日出/坚持感） / 宠物（陪伴） | 日常｜温暖祝福｜#日拱一卒 |
| 6. 新人报到型 | 拟人化 + 求带 | 宠物（拟人化） / 美女（新人设） | 互关、涨粉｜亲和低姿态｜#新人报到 #蓝V互关 |
| 7. 热点资讯型 | 真实热点 + 段子化解读 | 官方原图 / 资讯截图（可多图 2-4 张） | 追热点、引流｜克制客观｜事件通用名 + #AI |
| 8. 暴论型 | 反常识论断 + 短句分行 | 标语图（暴论金句） | 互动、引流｜反差暴论｜#暴论 |
| 9. 数据晒单型 | 具体数字 + 反差/进度 | 后台截图 / 数据图（信任状） | 立人设、涨粉｜真诚笃定｜#数据复盘 #曝光量 |
| 10. 真诚交友型 | "不骗关"信任状 + 低姿态 | 生活照（真实感） | 互关｜真诚笃定｜#真诚交友 #蓝V互关 |
| 11. 吐槽共鸣型 | 平台痛点 + 自嘲 | 表情包 / 宠物（委屈感） | 互动、日常｜自嘲幽默｜#创作者日常 |
| 12. 干货技巧型 | 实用技巧 + 原理 | 信息图（干货可视化） | 立人设、引流｜干货利落｜#运营技巧 #follow |
| 13. 经验忠告型 | 新手误区 + 生动比喻 | 标语图 / 风景 | 立人设｜亲和低姿态｜#新手指南 |
| 14. 执行清单型 | 每日执行数字 + 周期 | 执行清单信息图 | 涨粉、立人设｜干货利落｜#执行清单 #蓝朋友 |
| 15. 冷知识揭秘型 | 「说个冷知识：」+ 反直觉机制 + 数字后果 | 标语图 / 无图 | 互关、引流｜好奇追问｜#蓝V互关 |
| 16. 差额冲刺型 | 吐槽开场 + 精确粉丝数 + 「就差 N 个」 | 自己的主页 / 后台截图（打码他人） | 涨粉、互关｜自嘲幽默｜#蓝V互关 #涨粉日记 |
| 17. 反差对照型 | 「别人：/ 我：」对照 + 自嘲结论 | 宠物 / 表情包 | 互动、日常｜自嘲幽默｜#创作者日常 |
| 18. 自问自答型 | 「总有人问：」+「答：」一句结论 | 标语图 / 无图 | 立人设、互动｜干货利落｜#运营心得 |

详见 `references/patterns.md`（每种类型的示例拆解 + 写作公式 + 配图公式；末尾有「段子体排版」和「组合玩法（钩子 × 主体 × 收尾）」两节）。

**组合玩法**：一条段子 = 钩子 + 主体 + 收尾，换一种组合就是一条新帖。常用组合：冷知识揭秘 + 互关求粉、吐槽共鸣 + 差额冲刺（配主页截图）、反差对照 + 自嘲、自问自答 + 互动提问、热点资讯 + 暴论、打卡日常 + 进度条。同一天连发时相邻两条换钩子和收尾。
补充：附录「X 中文区互关运营实战」归纳 X 中文区互关运营的常见写法（出摊体/目标打卡/进度条体/人设承诺/真诚区隔/提问钩子/自嘲求助/收益换算/经验祛魅/股东体/干货警告 + 圈内用语词库，示例均为自编）。

## 标签体系

每条帖子带两类标签，详见 [references/tags-and-topics.md](references/tags-and-topics.md)：

- **内部分类标签**：类型（上面 18 个之一）、用途（涨粉 / 互关 / 引流 / 日常 / 立人设 / 追热点 / 互动）、平台（X）、语气（亲和低姿态 / 自嘲幽默 / 干货利落 / 克制客观 / 反差暴论 / 温暖祝福 / 好奇追问 / 真诚笃定）。写在正文块外的「内部标签」里，不进正文。
- **话题标签（hashtag）**：话题段子默认 2 个（宽泛词 + 主题词），运营引流帖（互关、新人报到、打卡）1–3 个，放在正文最后一行，不插进正文或列表中间；互关类以 `#蓝V互关 #follow` 为核心；不叠同义标签，不用诱导刷量、敏感或与内容无关的标签；热点资讯型只用事件、产品、公司的通用名称，传闻不用会让人以为已证实的标签。

## X 纯文本排版

规则见 [references/x-post-format.md](references/x-post-format.md) 与交付规约：

- 不用 Markdown；段子体完全不用 emoji，分点不加符号，一条一行、行间空行；热点资讯型的「短文版」按短文体处理（分点默认「·」，行多用「1）」，短列表才用 emoji）。
- 有事实的帖子（热点、数据、工具）：正文里用文字点到出处（「官方称」「据传」），来源链接另发一条；纯运营段子不需要。
- 自检：`python3 scripts/lint_x_post.py X稿.txt --duanzi`（等同 `--genre duanzi`；回复用 `--genre reply`；出现 emoji 报 W13；正文有 URL / 来源行 / 配图说明报 E10–E12；多条用 `---` 分隔；`--fix --out 新文件` 自动改 Markdown）。

## 热点资讯型（第 7 类）专项规约

选题池：AI / 科技 / 技能 / 工具 / 有趣科技 / 娱乐热点 / 社会新闻。**必须基于真实检索调研**，不编造。

### 监控范围（段子/短文选题雷达）

| 监控对象 | 内容 | 来源 |
|---|---|---|
| 科技公司动态 | 新品发布、版本更新、财报、融资、收购、人事 | 官方博客/新闻稿、TechCrunch、36氪 |
| 大佬发言 | 访谈、演讲、播客、听证会证词 | 原文/实录、权威媒体报道 |
| 大 V 观点 | X/微博热帖、技术讨论、争议话题 | 原帖截图（注明作者+时间） |
| 行业报告 | 论文、榜单、白皮书、数据报告 | arXiv、官方报告、原图引用 |
| 产品实测 | 新工具上手、横评、翻车现场 | 一手体验优先，二手转述注明 |
| **AI 模型追踪** | 最新模型发布、多模态模型、开源权重、部署教程、效果对比 | 官方发布、HuggingFace、GitHub、技术博客 |
| **生图生视频** | 提示词技巧、ComfyUI 工作流、模型对比、参数调优 | Civitai、GitHub、教程文章、实测 |
| **工具技巧** | ChatGPT / Codex / Claude / Grok / 豆包 / Manus 等 AI 工具的使用技巧 | 官方文档、社区分享、实测 |
| **优惠免费** | 云服务/AI 服务/模型/云主机/订阅的限免、优惠、薅羊毛 | 官方公告、社区爆料（注明时效） |
| **视觉灵感** | 热门奇特的图片视频、美学风格、创意案例 | X/IG/B站热门（注明来源） |

大 V 原帖可直接做"观点摘抄+一句点评"型段子；
争议性讨论做"双方观点+你站哪边"型互动帖；
新模型发布做"参数+效果+部署难度"三行速报型；
优惠信息做"是什么+怎么领+截止时间"型实用帖。

### 工作流：调研 → 核对 → 段子化 → 配图

1. **检索**：用 browser.search / news vertical 查最新动态，至少 2 个独立来源交叉验证。
2. **核对**：区分事实 / 传闻 / 推测——
   - 传闻类必须标注"（传闻，未经证实）"
   - 厂商数据标注"（厂商口径）"
   - 推测与事实分开，标注"（推测）"
   - 无法核实的承重事实直接删除
3. **段子化**：把资讯压缩成 3-8 行短句，保留核心事实 + 一个钩子（反差/提问/神评论）。
   事实部分不许为了效果篡改；幽默只加在评论/解读层。
4. **配图**：**官方原图 / 资讯截图优先**，可多图（2-4 张）；在段子化之前就找，流程见 [references/image-sourcing.md](references/image-sourcing.md)；
   图能说清的不再用文字复述；每张图注明来源（来源另发，不进正文）。

### 选题标准

- 时效：48 小时内的热点优先；超过一周的除非有新角度不做。
- 范围：AI / 科技 / 技能 / 工具 / 有趣科技 / 娱乐热点 / 社会新闻，不设限；
  纯娱乐八卦选与科技圈/大众情绪相关的，不做纯花边。
- **时空锚点**：新闻资讯类正文必须带时间点（如"10 月 3 日""昨天""上周"）
  或事件发生地点（如"旧金山""北京""斯洛文尼亚"）；
  时间地点是资讯可信度的地基，不许写成"最近""某地"。
- 涉国内厂商：不贬低、不站队攻击、不传谣；事实清楚时可以用有冲击力的表述；敏感表述先和用户确认（core-voice V21）。

### Output（热点型）

- 段子版：50-150 字 + 1-4 张原图（注明来源）。
- 短文版：300-800 字 + 多图，结构：导读句 → 事实（分点默认「·」） → 需要时点评一句（写成「预计」「现在看起来」，不用「我认为」）。
- 两种版本都必须核实一手来源；正文用文字标注口径（「官方称」「据传」），来源链接另发，不进正文。

## 何时不用

- X 长文（数千字深度稿）、发 X 文章 → `topmind-x-article`
- 公众号文章（长文）→ `topmind-wechat-post`；公众号短文、双平台干货短文 → `topmind-briefs`
- 干货短文、快讯、数据榜单（第三方客观口吻）→ `topmind-briefs`
- 只要封面、头图 → `topmind-cover`；长图、海报、信息图 → `topmind-poster`
- 单独改一条现成的帖子、去 AI 味、质检 → `topmind-revise`（`mode=quick genre=duanzi`）
- 把帖子发到 X → `topmind-x`（须用户确认）
- 需要深度论证的严肃话题（本技能只做短平快引流；热点深度解读走 briefs 或长文）

## 写作要点

1. **开头定生死**：读者先看到的是前几行，**钩子 + 核心事实 + 行动号召放在最前面**；
   hashtag 放最后一行。没有 280 字限制，但段子要短平快，写完把废话砍掉。
   运营引流帖结构：第一行即钩子 → 2-4 行核心事实 → 最后一行神评论 / 提问；话题段子见下面「段子配方」，末行用动作完成反转。
2. **段子体排版**：一句一行，**行与行之间都空一行**；一行一个意思，尽量不超过 20 字，长句在逗号处断开。
   现成文字要转段子体时交给 `topmind-format`（只排版不改字）；段子体零 emoji（emoji 体系只用于短文体）。
3. **口语化**：说人话，不说书面语。"蓝朋友""上岸""串门"比"用户""成功""交流"好。
4. **具体数字**：4869 个粉 > "几千个粉"；3 小时 > "刚才"。
5. **互动钩子**：只限运营引流类（互关、新人报到、打卡、冷知识引流），每帖至少一个——提问、二选一、求互关、求评论；话题段子不强制，以动作反转收尾。
6. **Hashtag**：话题段子默认 2 个，运营引流帖 1–3 个，放最后一行；互关类必带 `#蓝V互关 #follow`；干货类带 `#新手指南`、`#运营技巧` 这类读者会搜的词；日常类可带 `#日拱一卒`。数量、位置与敏感词规则见 [references/tags-and-topics.md](references/tags-and-topics.md)。
7. **不用 emoji**：段子里没有人设点缀、情绪表情和列表符号，语气全靠文字本身。
8. **去 AI 味**：不用"首先其次最后""综上所述""值得注意的是""不仅…更…"，少用"不是 A 而是 B"和三连排比，不用感叹号堆砌，结尾不升华；对话写「人名：」，不写「人名说：」。
   **成稿后自查**：按 [references/de-ai-rules.md](references/de-ai-rules.md) 过一遍（审稿用，只改表达，不改事实）；吸引力看 [references/core-voice.md](references/core-voice.md) 原则 2、4、9；lint 的 W 警告每条要有结论（改掉或说明保留理由），H 提示只供判断。
9. **不用 Markdown**：分点不加符号，见上节与交付规约。

## 段子配方（话题段子）

按 `references/core-voice.md` V31：

- 具体产品（点名某个 agent、某个编辑器）+ 真实可信的生活场景 + 它的典型特点（翻你的记录、照章办事）+ 末行**用动作完成反转**。
- 时事段子：首句点出两方的场景，第二句直接亮出反差，少铺垫。
- 对话写「人名：」；凭空设计的情节显得尴尬；调侃厂商可以，不编、不传谣。
- 圈内梗可以用，梗放在大家都看得懂的位置（V19）。
- 短、口语，一个主角；场景一句交代，不并列堆细节。太整齐的金句和对仗读着像 AI，也不好转述。
- 语气像还在学习的普通人，不是专家、不像科普；可以带一点老司机式的自嘲（core-voice 原则 9）。

## 回复与转发点评

按 `references/core-voice.md` V29、V30：

- 回复越短越好，可以只是词组；基本形是「态度 + 一点口语」，态度放第一个字，不复述原帖、不重复原帖的数字；带保留的赞同用口语转折（「好用，除了略慢」）；要加深度只加帖子外或推出来的东西（站队、代入自己、理解动机、往后问一句）。
- 自己的推测写成问句；真心不懂可以装傻问一句，但不写明知故问的反问（V22）。立场清楚，给反驳留一点余地。
- 被批评时的公开回复可以客气；纠正别人一句口语点破。
- 转发点评：当前热词 + 动作（更新了 / 发新版了）+ 感叹，可以配一个匹配的 emoji 和一次「！！」；不复述更新内容。
- 自检：`python3 scripts/lint_x_post.py 回复.txt --genre reply`。

## 配图

**优先级（段子/短文/长文通用）**：

1. **官方原图第一**：发布会截图、官方博客配图、GitHub README 图、产品截图
2. **第三方原图第二**：权威媒体资讯图、原帖截图（注明来源）
3. **AI 生图兜底**：只有两种情况用——
   - 纯粹引流运营段子（互关/自嘲/打卡/新人报到，无具体新闻事实）
   - 有事实但找不到可用原图

**生图风格**：清新优雅 或 商务美观 MD3 风格（Material Design 3：干净留白、柔和圆角、克制配色）。
不搞暗黑炫酷，不搞油腻网红风。

**图库匹配**（仅 AI 生图时用）：

| 图库 | 适用类型 | 出图要点 |
|---|---|---|
| **美女** | 互关求粉 / 新人报到 | 吸睛但不低俗，自然笑容，生活感；避免过度修图网红脸。尺度两档：默认清纯吸睛；性感档（大学生穿搭 T 恤/热裤/吊带、苗条曲线突出、近距离特写）按用户要求选用 |
| **宠物** | 互关 / 自嘲 / 打卡 / 新人 | 猫为主，狗 / 鸟点缀；表情生动、有故事感 |
| **风景** | 干货 / 提问 / 打卡 | 日出/远眺/星空，配"坚持""远方"意境；清新优雅风 |
| **奇幻** | 自嘲 / 提问 | 异星风光、奇特地貌、超现实；反差萌，引发好奇 |
| **标语** | 干货 / 提问（二选一） | MD3 商务风：金句一行 + 浅色底 + 深色字；字少而大 |

**人像生图提示词公式**（目标：自然、清爽、有生活感，不像 AI 图）：

```
Photorealistic portrait, 35mm film photography aesthetic, shot on 85mm lens f/1.8, subtle film grain:
a stunningly beautiful young Chinese woman in her early 20s,
pure innocent look, big clear bright eyes, soft natural makeup,
flawless porcelain skin, sweet gentle smile, long silky black hair,
slender graceful figure,
[场景 + 服装 + 举牌/动作], soft golden-hour / window light,
clean uncluttered background, vertical 9:16
```

要点（都来自实际使用中遇到的问题）：
- **只用正面描述**：写"flawless porcelain skin"，不写"no AI face / natural skin texture"——否定词会被理解成"往脸上加点瑕疵"，雀斑痣就是这么来的
- **美貌必须给具体锚点**："beautiful"太抽象，要拆成"大眼睛/清澈眼神/淡妆/柔顺长发/干净气质"，清纯才落得下来
- **真实感靠相机语言**："35mm film + 85mm f/1.8 + film grain"比任何"不要AI感"都管用，给模型一个物理介质参照
- **环境做减法**：干净背景 + 柔和自然光；"candid snapshot/抓拍感"会把质感拉回路人随手拍，只在用户明确要生活流时用
- **身材要显式写**：不写就只拍大头照；"slender graceful figure" + 得体服装（白裙/亚麻衬衫/针织衫），吸睛不低俗

**配图流程**：
1. 写完段子 → 先找原图（官方 > 第三方 > 原帖图 / 原帖截图），有就直接用 1–2 张并给出图片地址与来源
2. 无原图 → 先问用户要不要配图；用户同意后按上表选图库，走 topmind-cover 的「X 短文封面」场景出图，不擅自生图；纯文字段子（冷知识、自问自答）也可以不配图
3. 尺寸：X 单图 1200×675（16:9）；多图也可用 1:1；原图 + 封面合计不超过 4 张
4. 检查：图与文案情绪一致，不抢戏，不低俗；原图不裁掉关键信息

## 工作流

1. **选类型**：看用户要什么效果（涨粉→互关型/新人型；互动→提问型/自嘲型；立人设→干货型/打卡型；追热点→热点资讯型）。
2. **套公式**：从 `references/patterns.md` 取对应公式，填内容。
3. **配图**：先找原图（官方 > 第三方 / 原帖图，注明来源），给 1–2 张图片地址；没有原图时**先问用户要不要配图**，用户同意才走 topmind-cover 生图（清新优雅/MD3商务风），可先附一个出图 prompt 供用户决定；不擅自生图。
4. **自检**：删掉"正确的废话"；成稿后按 `references/de-ai-rules.md` 做去 AI 味自查；用户要改稿时转 `topmind-revise`（`mode=quick genre=duanzi`），没装就按 `references/revision-workflow.md` 手动走（备份 → ⓪ 结构 → 事实 → 逻辑 → 删冗余 → 去 AI 味 → 措辞原则对照 → 排版 → 保真审计，报改前 / 改后字数）；确认有钩子、段子体行间空行、话题标签 1–3 个在末行、事实类的来源链接已整理到另发的链接里；`scripts/lint_x_post.py --duanzi` E 类清零（含 E10 URL、E11 来源行、E12 配图说明）、W12（正文混入标签 / 说明）清零；加 `--duanzi` 时 W13（出现 emoji）清零。
5. **交付**：一次 3–5 条让用户挑，严格按 [references/x-delivery-contract.md](references/x-delivery-contract.md)。

## Output Contract

- 3–5 条独立短帖，每条 50–150 字，默认段子体；**每条正文单独一个 `text` 块**（块名「帖 N」写在块外），块里只有正文和末行话题标签，没有 URL、来源行、配图说明。
- 正文块之后依次另发：**链接**（来源 / 原帖，每条一行「名称｜发布时间｜URL」，纯运营段子写「无」）→ **图片**（1–2 张地址 + 来源；没有就写「未找到原图」并问要不要配图，可附 1 个出图 prompt 供决定；纯文字段子可写「不配」）→ **内部标签**（类型 / 用途 / 平台 / 语气 + 备选话题标签）。
- 段子零 emoji；热点短文版 emoji 可选，用就按 [references/emoji-system.md](references/emoji-system.md)；厂商数字标「（厂商口径）」，未证实标「（传言）」。
- 不编造用户数据：粉丝数、收益等数字用户给才写。

示例（原创，数字与名称为虚构）：

````text
帖 1：
```text
说个冷知识：

X 的创作者收益，不只看浏览量。

蓝V用户的互动，据说权重更高（传言，以官方说明为准）。

难怪大家都在找蓝V互动

蓝V互关，评论区报到！！

#蓝V互关
```

帖 2：
```text
这周把发帖流程压缩成三步：

早上先回评论

中午发一条原创

睡前回访新关注

三步走完，不焦虑

#日拱一卒
```

链接：无（运营段子）
图片：帖 1 不配（纯文字段子）；帖 2 未找到原图——要不要配图？可选：风景（日出）· 清新优雅，同意后用 topmind-cover 出图。
内部标签：
- 帖 1：类型=冷知识揭秘型｜用途=互关、引流｜平台=X｜语气=好奇追问｜备选 #创作者收益
- 帖 2：类型=打卡日常型｜用途=日常、立人设｜平台=X｜语气=温暖祝福｜备选 #运营心得
````

## Operating Rules

1. **不碰政治、色情、medical advice**。
2. 中文区风格，不硬翻英文 meme。
3. 互关帖不承诺做不到的事（如"必回关"写成"尽量回关"除非用户明确）。
4. 美女图不低俗：自然、生活感、有笑容；用户明确要"流量向"时再放开。
5. 宠物图猫优先，外星 / 奇幻图取异星风光和奇特地貌。
