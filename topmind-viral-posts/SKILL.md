# topmind-viral-posts · X 引流段子/爆款短篇

基于对 X 中文区常见高互动写法的归纳，示例均为自编。目标：**短、真、钩子**——读者 3 秒能看完，忍不住点赞/评论/关注。

## 十四大类型

| 类型 | 核心钩子 | 配图建议 |
|---|---|---|
| 1. 干货忠告型 | "新手最容易犯的错误" | 标语图 / 风景（远眺感） |
| 2. 互关求粉型 | 直接求 + 承诺回关 | 宠物（亲和力） / 美女（吸睛） |
| 3. 自嘲幽默型 | 具体数字 + 反差 | 宠物（搞笑） / 奇幻（反差萌） |
| 4. 互动提问型 | 二选一 / 灵魂拷问 | 标语图（二选一文字） / 风景 |
| 5. 打卡日常型 | 日拱一卒 + 祝福 | 风景（日出/坚持感） / 宠物（陪伴） |
| 6. 新人报到型 | 拟人化 + 求带 | 宠物（拟人化） / 美女（新人设） |
| 7. 热点资讯型 | 真实热点 + 段子化解读 | 官方原图 / 资讯截图（可多图 2-4 张） |
| 8. 暴论型 | 反常识论断 + 短句分行 | 标语图（暴论金句） |
| 9. 数据晒单型 | 具体数字 + 反差/进度 | 后台截图 / 数据图（信任状） |
| 10. 真诚交友型 | "不骗关"信任状 + 低姿态 | 生活照（真实感） |
| 11. 吐槽共鸣型 | 平台痛点 + 自嘲 | 表情包 / 宠物（委屈感） |
| 12. 干货技巧型 | 实用技巧 + 原理 | 信息图（干货可视化） |
| 13. 经验忠告型 | 新手误区 + 生动比喻 | 标语图 / 风景 |
| 14. 执行清单型 | 每日执行数字 + 周期 | 执行清单信息图 |

详见 `references/patterns.md`（每种类型的示例拆解 + 写作公式 + 配图公式）。
补充：第 15 节归纳 X 中文区互关运营的常见写法（出摊体/目标打卡/进度条体/人设承诺/真诚区隔/提问钩子/自嘲求助/收益换算/经验祛魅/股东体/干货警告 + 圈内用语词库，示例均为自编）。

## 热点资讯型（第 7 类）专项规约

选题池：AI / 科技 / 技能 / 工具 / 有趣科技 / 娱乐热点 / 社会新闻。**必须基于真实检索调研**，不编造。

### 监控范围（段子/短文选题雷达）

| 监控对象 | 内容 | 来源 |
|---|---|---|
| 科技公司动态 | 新品发布、版本更新、财报、融资、收购、人事 | 官方博客/新闻稿、TechCrunch、36氪 |
| 大佬发言 | 访谈、演讲、播客、听证会证词 | 原文/实录、权威媒体报道 |
| 大 V 观点 | X/微博热帖、技术讨论、争议话题 | 原帖截图（注明作者+时间） |
| 行业报告 | 论文、榜单、白皮书、数据报告 | arXiv、官方报告、原图引用 |
| 产品实测 | 新工具上手、横评、翻车现场 | 一手体验优先，二手转述注明 |
| **AI 模型追踪** | 最新模型发布、多模态模型、开源权重、部署教程、效果对比 | 官方发布、HuggingFace、GitHub、技术博客 |
| **生图生视频** | 提示词技巧、ComfyUI 工作流、模型对比、参数调优 | Civitai、GitHub、教程文章、实测 |
| **工具技巧** | ChatGPT/codex/Claude/grok/豆包/Manus/Dots/MIMO/cue 等使用技巧 | 官方文档、社区分享、实测 |
| **优惠免费** | 云服务/AI 服务/模型/云主机/订阅的限免、优惠、薅羊毛 | 官方公告、社区爆料（注明时效） |
| **视觉灵感** | 热门奇特的图片视频、美学风格、创意案例 | X/IG/B站热门（注明来源） |

大 V 原帖可直接做"观点摘抄+一句话点评"型段子；
争议性讨论做"双方观点+你站哪边"型互动帖；
新模型发布做"参数+效果+部署难度"三行速报型；
优惠信息做"是什么+怎么领+截止时间"型实用帖。

### 工作流：调研 → 核对 → 段子化 → 配图

1. **检索**：用 browser.search / news vertical 查最新动态，至少 2 个独立来源交叉验证。
2. **核对**：区分事实 / 传闻 / 推测——
   - 传闻类必须标注"（传闻，未经证实）"
   - 厂商数据标注"（厂商口径）"
   - 推测与事实分开，标注"（推测）"
   - 无法核实的承重事实直接删除
3. **段子化**：把资讯压缩成 3-8 行短句，保留核心事实 + 一个钩子（反差/提问/神评论）。
   事实部分不许为了效果篡改；幽默只加在评论/解读层。
4. **配图**：**官方原图 / 资讯截图优先**，可多图（2-4 张）；
   图能说清的不再用文字复述；每张图注明来源。

### 选题标准

- 时效：48 小时内的热点优先；超过一周的除非有新角度不做。
- 范围：AI / 科技 / 技能 / 工具 / 有趣科技 / 娱乐热点 / 社会新闻，不设限；
  纯娱乐八卦选与科技圈/大众情绪相关的，不做纯花边。
- **时空锚点**：新闻资讯类正文必须带时间点（如"10 月 3 日""昨天""上周"）
  或事件发生地点（如"旧金山""北京""斯洛文尼亚"）；
  时间地点是资讯可信度的地基，不许写成"最近""某地"。
- 涉中国厂商/中国语境：措辞正面积极客观；敏感表述先和用户确认。

### Output（热点型）

- 段子版：50-150 字 + 1-4 张原图（注明来源）。
- 短文版：300-800 字 + 多图，结构：一句话导读 → 事实（分点） → 一句点评。
- 两种版本都必须带来源链接或来源标注。

## 何时不用

- X 长文（数千字深度稿）→ `topmind-x-article`
- 公众号长文 → `topmind-wechat-post`
- 干货短文（第三方客观口吻）→ `topmind-briefs`
- 需要深度论证的严肃话题（本技能只做短平快引流；热点深度解读走 briefs 或长文）

## 写作铁律

1. **140 字生死线**：X 时间线只显示前 280 字符（约 140 个中文字），
   超出部分被折叠。**钩子 + 核心事实 + 行动号召必须在前 140 字内**；
   hashtag 放最后（被折叠不影响）。
   结构：第一行即钩子 → 2-4 行核心事实 → 最后一行神评论/提问。
   写完数一下字数，超了就砍废话，砍到 140 字内。
2. **短句分行**：一行一个意思，不超过 15 字；段与段空一行。
3. **口语化**：说人话，不说书面语。"蓝朋友""上岸""串门"比"用户""成功""交流"好。
4. **具体数字**：4869 个粉 > "几千个粉"；3 小时 > "刚才"。
5. **互动钩子**：每帖至少一个——提问、二选一、求互关、求评论。
6. **Hashtag**：互关类必带 `#蓝V互关 #follow`；干货类可带 `#涨粉`；日常类可带 `#日拱一卒`。
7. **表情点缀**：1-3 个，不要堆。😭😎🤝 比纯文字有温度。
8. **去 AI 味**：不用"首先其次最后"，不用"综上所述"，不用感叹号堆砌。

## 配图铁律

**优先级（段子/短文/长文通用）**：

1. **官方原图第一**：发布会截图、官方博客配图、GitHub README 图、产品截图
2. **第三方原图第二**：权威媒体资讯图、原帖截图（注明来源）
3. **AI 生图兜底**：只有两种情况用——
   - 纯粹引流运营段子（互关/自嘲/打卡/新人报到，无具体新闻事实）
   - 有事实但找不到可用原图

**生图风格**：清新优雅 或 商务美观 MD3 风格（Material Design 3：干净留白、柔和圆角、克制配色）。
不搞暗黑炫酷，不搞油腻网红风。

**图库匹配**（仅 AI 生图时用）：

| 图库 | 适用类型 | 出图要点 |
|---|---|---|
| **美女** | 互关求粉 / 新人报到 | 吸睛但不低俗，自然笑容，生活感；避免过度修图网红脸。尺度两档：默认清纯吸睛；性感档（大学生穿搭 T 恤/热裤/吊带、苗条曲线突出、近距离特写）按用户要求选用 |
| **宠物** | 互关 / 自嘲 / 打卡 / 新人 | 猫为主（用户偏好），狗/鸟点缀；表情生动、有故事感 |
| **风景** | 干货 / 提问 / 打卡 | 日出/远眺/星空，配"坚持""远方"意境；清新优雅风 |
| **奇幻** | 自嘲 / 提问 | 异星风光、奇特地貌、超现实；反差萌，引发好奇 |
| **标语** | 干货 / 提问（二选一） | MD3 商务风：一句话金句 + 浅色底 + 深色字；字少而大 |

**美女生图提示词公式**（2026-10-06 实测优化，用户偏好：漂亮、清纯、身材好、去 AI 味）：

```
Photorealistic portrait, 35mm film photography aesthetic, shot on 85mm lens f/1.8, subtle film grain:
a stunningly beautiful young Chinese woman in her early 20s,
pure innocent look, big clear bright eyes, soft natural makeup,
flawless porcelain skin, sweet gentle smile, long silky black hair,
slender graceful figure,
[场景 + 服装 + 举牌/动作], soft golden-hour / window light,
clean uncluttered background, vertical 9:16
```

要点（都来自实际使用中遇到的问题）：
- **只用正面描述**：写"flawless porcelain skin"，不写"no AI face / natural skin texture"——否定词会被理解成"往脸上加点瑕疵"，雀斑痣就是这么来的
- **美貌必须给具体锚点**："beautiful"太抽象，要拆成"大眼睛/清澈眼神/淡妆/柔顺长发/干净气质"，清纯才落得下来
- **真实感靠相机语言**："35mm film + 85mm f/1.8 + film grain"比任何"不要AI感"都管用，给模型一个物理介质参照
- **环境做减法**：干净背景 + 柔和自然光；"candid snapshot/抓拍感"会把质感拉回路人随手拍，只在用户明确要生活流时用
- **身材要显式写**：不写就只拍大头照；"slender graceful figure" + 得体服装（白裙/亚麻衬衫/针织衫），吸睛不低俗

**配图流程**：
1. 写完段子 → 先找原图（官方 > 第三方），有就直接用并注明来源
2. 无原图 → 按上表选图库，走 topmind-cover 出图（风格：清新优雅/MD3商务）
3. 尺寸：X 单图 1200×675（16:9）；多图也可用 1:1
4. 检查：图与文案情绪一致，不抢戏，不低俗；原图不裁掉关键信息

## 工作流

1. **选类型**：看用户要什么效果（涨粉→互关型/新人型；互动→提问型/自嘲型；立人设→干货型/打卡型；追热点→热点资讯型）。
2. **套公式**：从 `references/patterns.md` 取对应公式，填内容。
3. **配图**：先找原图（官方 > 第三方，注明来源）；无原图或纯引流段子才走 topmind-cover 生图（清新优雅/MD3商务风）。
4. **自检**：读一遍，删掉任何"正确的废话"；确认有钩子、有 hashtag、有配图；热点型确认来源标注齐全。
5. **交付**：正文 + 配图（原图附来源 / 生图附 prompt），一次 3-5 条，用户挑。

## Output Contract

- 输出：3-5 条独立短帖，每条 50-150 字。
- 每条配图：原图优先（附来源）→ 无原图则 1 张生图或 1 个可直接用的出图 prompt（含图库类型 + 风格 + 画面描述）。
- 格式：纯文本，短句分行，hashtag 放末尾；配图说明另起一行。
- 不编造用户数据：粉丝数、收益等数字用户给才写，不给就用模糊表述。

## Operating Rules

1. **不碰政治、色情、medical advice**。
2. 中文区风格，不硬翻英文 meme。
3. 互关帖不承诺做不到的事（如"必回关"写成"尽量回关"除非用户明确）。
4. 美女图不低俗：自然、生活感、有笑容；用户明确要"流量向"时再放开。
5. 宠物图猫优先（用户偏好），外星/奇幻图取异星风光和奇特地貌。
