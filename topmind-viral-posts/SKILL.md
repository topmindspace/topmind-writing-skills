# topmind-viral-posts · X 段子与互动短帖

写读者愿意接话的帖子：一个鲜活观察、一个反差、一句真问题，或者一次真实的关系互动。默认中文，风格跟当前用户与作者样本走。

## 按需借鉴与积累

需要新方向、完整例子或相关经验时，用 [知识使用与增补](references/knowledge-library.md) 检索幽默机制、生活观察、回复与转发；先读摘要，再选相关卡片。可以混合、改造或采用库外思路，简单任务直接完成。知识不替代当前用户要求；新反馈先作为有范围的候选，不自动改长期规则。

## 从可用素材里找方向

用户要一条就交一条；用户在找角度、要一组备选时，试几个真的不同的方向：

| 方向 | 适合的素材 | 可尝试的写法 |
|---|---|---|
| 真问题 / 求证 | 一个有出处但还不明白的细节 | 线索 + 哪一点没想通 |
| 算账 / 冷知识 | 可核对的数字或机制 | 结果 + 生活尺度的比较 |
| 对话 / 反转 | 产品特点、日常痛点 | 场景 → 预期 → 意外动作 |
| 轻判断 / 自嘲 | 观察或作者提供的经历 | 承认一点 + 自己的选择 |
| 连载 / 关系帖 | 真实进展、求助、打卡 | 发生了什么 + 希望怎样互动 |

[类型经验库](references/patterns.md) 有 12 + 2 类写法和完整例子，可拆、可混合，也可另起方向。它们帮助找角度，不定义允许创作的全集。

## 先看成品，再谈口味

选读 [创作方法与样张](references/creative-practice.md) 的短帖与回复例子；有作者样本、原帖或指定参考时实际阅读。留意第一句怎么进入场景、哪里产生反差、结尾留了什么；迁移方法，使用当前素材重新表达。

探索时给可直接用的完成稿，让差别出现在叙事、立场或节奏上。对单条、赶时间、风格已定的任务，直接推荐最合适的一稿，不增加选择回合。

## 写法选择

- 一句一行、行间留白适合口语段子；紧凑短段、对话、单行回复、带列表的幽默都能用。
- emoji、问句、类比、对仗、标签可以贡献情绪和辨识度，也可以省略。根据作者习惯和这条的实际效果选择。
- 反转可落在动作、细节、误会或一句回答上。读完已经成立，就停；有具体问题或行动目标，也可以邀请互动。
- 回复先接住对方，再决定是简短态度、补充经验、追问还是认真反驳。篇幅服务于交流，作者要讲完整理由就展开。

更多口吻选择见 [core-voice.md](references/core-voice.md)，排版见 [x-layout-patterns.md](references/x-layout-patterns.md)。

## 真实与虚构分清

新闻、平台机制、价格和数字回到来源核对；保留“厂商称”“预计”“未确认”等影响理解的限定。两篇转载同一消息不算两份独立证据。

第一人称经历、收益、粉丝数只使用作者给的素材；虚构对话或讽刺让读者能识别其创作性质，别把它包装成真实实测或公司行为。对任何厂商都按同样的证据标准评论。关系帖的承诺以作者能履行为准。

## 配图与交付

文字成立可直接交稿。翻车截图、账单、代码和实测结果能增强信息时再配图，截图先处理隐私。用户已要图就找合适素材或生成示意；未要求图时不把配图变成必答问题。配图方向可用作品截图、摄影、宠物、抽象视觉、文字图等，跟内容与作者身份匹配。

每条一个可复制纯文本块，来源、图片、备选解释在块外；用户希望正文带链接就保留。正文仍保留必要归因。[交付建议](references/x-delivery-contract.md) 说明不同安排。

可运行 `python3 scripts/lint_x_post.py 稿子.txt --duanzi`（回复加 `--genre reply`）。风格提示由上下文判断，合理写法可以直接保留。检查器不证明帖子会爆，也不要求每条提示写报告。本技能交付草稿，发布由用户或获授权的发布工具处理。

## 分工

信息型快讯、论文、新品用 `topmind-briefs`；只排版用 `topmind-format`；独立改现成帖子用 `topmind-revise`；长文用 `topmind-x-article` / `topmind-wechat-post`；封面、长图用 `topmind-cover` / `topmind-poster`。
