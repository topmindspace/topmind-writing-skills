# topmind-viral-posts · X 段子、观察反差与互动短帖

写有内容、有特色、真正让人会心一笑或愿意接话的帖子：**一个内行观察、一次算账反差、一句留了空位的真问题、一个动作反转段子，或一句到位的评论回复**。已全面清理早期肤浅的「互关、互浇、出摊、打卡、冲粉」套路，专注于有价值、有意思的创作。默认中文，风格跟当前用户与作者样本走。

## 一、核心创作思考（给 AI 留出发挥空间，不套死模板）

1. **邻座身位，不当讲师**：像坐在读者旁边的同行朋友聊天。把命令式的「别无脑开最高档」改成商量式的「都开最高档吗？可能大多数时候次高档就够了...」，判断还在，接话空间就出来了。
2. **问号本身不涨流量，切身痛点 + 七分留白才有效**：好的「装傻 / 真疑问」必须切中具体人群的日常痛点，门槛低到一句话就能接，而且**后半句忍住不说完**。避开「有什么特点有没有坑」这类空壳伸手党提问和文末「你觉得呢」假互动。
3. **画面与动作代替评论**：「一个进门，一个下楼」「先交 8 刀保护费」「它先把自己退订了」——包袱落在最后一个具体动作或台词上，说完即停，绝不解释笑点。
4. **回帖与引用分清边界**：
   - **引用转发（Quote）**：去掉原帖已有的信息后，必须剩下自己的一句实质判断、吐槽或使用切口（忌「官方公告中文版」式薄引用）。
   - **评论区回复（Reply）**：是聊天接话，不复述原帖、不套「跟……一个道理」的说教类比、不端架子（英文大号下常为 3–6 个词的自然口语）。

## 二、从素材里选方向（12 类内容切口，可自由混搭与扩展）

用户要一条就交一条；用户在找角度时，从真正不同的切口给候选：

| 方向 | 适合的素材 | 核心机制与发力点 |
|---|---|---|
| **真问题 / 装傻求证** | 档位选择、反常定价、新入口线索、服务故障 | 切身痛点 + 自己看到的一点线索 + 一句话能接的真问题（A1–A3） |
| **算账反差 / 冷知识** | 离谱额度、token 账单、隐藏计费规则 | 「等一下……？？？」愣一下 → 换算成日常开销/月费 → 点到为止（A4, A5, A8） |
| **群聊拟人 / 产品反转** | 多家同日发版、智能体照章办事的荒诞瞬间 | 隐去「某某说：」直接对白，或末行动作完成反转（A6, A10, A11） |
| **内行轻判断 / 借热点** | 工具选型、行业习惯、连续进展、新事套旧梗 | 承认一点 + 亮出内行态度，给讨论留余地（A7, A9, A12） |
| **引用转发 / 评论神回复** | 热门原帖、离谱新闻、同行分享 | 亮出一句增量判断、自嘲共鸣或具体追问 |

完整 12 类策略、有效提问对比与失败反例见 [patterns.md](references/patterns.md)；按需检索 `viral-play-dumb`、`viral-mechanisms`、`viral-observation`、`viral-replies`、`voice-peer-stance` 等经验卡见 [knowledge-library.md](references/knowledge-library.md)。遇到新的好段子思路或互动策略，可随时通过 `scripts/knowledge.py add` 扩展入库。

## 三、真实与虚构边界（仅守底线，不卡门禁）

- **不代编亲历与「我」**：作者没提供过的个人经历、账单数字或实测过程，绝不为了「像真人」而代编；需要时写「有人测了」「看了一圈」或留给作者自己补。
- **传闻与玩梗分清**：扒料与传闻保留「？！」或未确认口径；群聊拟人对话让读者一眼看出是幽默创作，不伪造真实企业官方声明。
- **标点与排版灵活服务内容**：`？？？`、`！！！`、`！！？`、`……` 随真实反差和情绪自然使用，不作机械限制；普通帖按语义段落空行，段子与群聊可按节拍分行。更多见 [core-voice.md](references/core-voice.md) 与 [x-layout-patterns.md](references/x-layout-patterns.md)。

## 四、配图与交付

- 纯文字成立就直接交文字；报错截图、账单、代码线索能增加喜感或证据力时配一张真实截图（注意隐私打码）。
- 每条一个可复制纯文本块，来源与说明放块外（详见 [x-delivery-contract.md](references/x-delivery-contract.md) 与 [tags-and-topics.md](references/tags-and-topics.md)）。
- 可按需运行 `python3 scripts/lint_x_post.py 稿子.txt --duanzi` 检查 Markdown 残留；风格提示（W/H）仅作参考，**绝不作为阻断交付的硬门禁**。只交付草稿，不擅自外发。
