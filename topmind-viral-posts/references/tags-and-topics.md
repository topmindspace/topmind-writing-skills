# 标签与话题规则（段子 / 爆款短篇）

每条帖子带两类标签：

- **内部分类标签**：写给自己和用户看的归档与筛选标签，不进正文。
- **话题标签（hashtag）**：写进 X 正文末行的 `#标签`，面向读者和搜索。

两类各管各的，不要混用。本文所有示例均为原创，数字与名称为虚构。

## 一、内部分类标签（四个维度）

| 维度 | 取值 | 作用 |
|---|---|---|
| 类型 | 18 个类型之一（见下表） | 决定写法公式与配图 |
| 用途 | 涨粉 / 互关 / 引流 / 日常 / 立人设 / 追热点 / 互动 | 说明这条帖子要达成什么 |
| 平台 | X（默认）；可补充“中文区”或“英文区” | 决定字数线、列表写法和话题标签规则 |
| 语气 | 亲和低姿态 / 自嘲幽默 / 干货利落 / 克制客观 / 反差暴论 / 温暖祝福 / 好奇追问 / 真诚笃定 | 保证同一批帖子语气不串味 |

一条帖子通常 1 个类型、1–2 个用途、1 个语气，平台固定写 X。

## 三、话题标签（hashtag）规则

**数量**：每条 1–3 个，不要超过 3 个。互关类以 `#蓝V互关` 和 `#follow` 为核心，最多再加 1 个补充标签。纯日常、没有传播目的的帖子可以只带 1 个，或不带。

**位置**：放在正文最后，空一行后单独成行。不插进正文，不夹在列表中间，不占用前 140 字的位置。

**中英文**：
- 主标签用中文区读者会搜的中文词，互关类再配 1 个英文标签（如 `#follow`）扩大触达。
- 英文标签用常见写法，多个单词用驼峰（`#BuildInPublic`）或全小写，不加空格和标点。
- 中文标签不加空格，不夹标点，不超过 10 个字。

**不堆砌**：
- 不叠同义标签（`#互关 #互关互赞 #互粉` 只留一个）。
- 不蹭与内容无关的热门标签，不把别的话题硬拉进来。
- 标签和正文里的词重复时，只保留标签，正文里照常写词。

**避免违规或敏感**：
- 不用诱导刷量、互赞互粉群、买粉卖粉一类的标签或暗示。
- 不用涉及政治站队、色情低俗、医疗功效、投资荐股承诺的标签。
- 不用他人姓名、未经许可的品牌名借势；热点资讯型只用事件、产品、公司的通用名称。
- 没有上热搜就不写“热搜”“爆了”类标签，传闻类帖子不用会让读者误以为已证实的标签。
- 互关帖不要用同一段文案和标签批量重复发布，也不借助自动化工具发，避免被平台判定为垃圾信息。

## 四、各类型的话题怎么取

| 场景 | 取法 | 示例（虚构） |
|---|---|---|
| 互关类 | 固定组合 `#蓝V互关 #follow`，需要时加 `#真诚交友` 或 `#浇朋友` 之一 | `#蓝V互关 #follow #真诚交友` |
| 日常打卡 | 用习惯类词，一个就够 | `#日拱一卒` |
| 干货与技巧 | 用读者会搜的问题词，而不是宣传词 | `#新手指南` `#运营技巧` |
| 数据晒单 | 用数据主题词，数字写在正文里 | `#数据复盘` |
| 热点资讯 | 事件或产品通用名 + 领域词，传闻在正文里标明 | `#某模型发布` `#AI` |
| 互动提问 | 问题主题词，让评论区按话题聚拢 | `#通勤方式` |

## 五、交付时标签放哪

话题标签**属于正文**（正文块末行）；内部分类与备选话题标签**不进正文块**，写在所有正文块之后的「内部标签」块（规约见 [x-delivery-contract.md](x-delivery-contract.md)）：

````text
帖 1：
```text
刚来的小松鼠，把蓝V松果藏好了

想认识爱囤干货的朋友。

带着坚果去串门，说到做到。

#蓝V互关 #follow
```

帖 2：
```text
10 月 9 日，某图像模型单图降到 0.01 美元（厂商口径）。

上个月还是 0.03。

生图的门槛又低了一截。

#AI #图像模型
```

链接：帖 2：厂商定价页｜2026-10-09（页面标注）｜https://example.com/pricing
图片：帖 1 未找到原图——要不要配图？；帖 2 [图1] 官方定价页截图 — 来源：厂商官网
内部标签：
- 帖 1：类型=新人报到型｜用途=互关｜平台=X｜语气=亲和低姿态｜备选 #新人报到
- 帖 2：类型=热点资讯型｜用途=追热点、引流｜平台=X｜语气=克制客观｜备选 #降价
````

规则：
1. 内部分类四项齐全：类型、用途、平台、语气；备选话题标签最多 2 个。
2. 一批 3–5 条帖子里，类型和语气尽量错开。

## 六、检查清单

- [ ] 每条话题标签 ≤3 个，位于正文最后一行，没有叠同义词。
- [ ] 互关类带了 `#蓝V互关` 和 `#follow`；热点类只用通用名称。
- [ ] 没有诱导刷量、敏感或与内容无关的标签。
- [ ] “标签”项里的话题与正文末行一致，内部分类四项齐全。
- [ ] 正文没有 Markdown 列表、标题和加粗（见 `x-post-format.md`）。
