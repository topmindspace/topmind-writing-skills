# 标签与话题规则（段子 / 爆款短篇）

每条帖子带两类标签：

- **内部分类标签**：写给自己和用户看的归档与筛选标签，不进正文。
- **话题标签（hashtag）**：写进 X 正文末行的 `#标签`，面向读者和搜索。

两类各管各的，不要混用。本文所有示例均为原创，数字与名称为虚构。

## 一、内部分类标签（四个维度）

| 维度 | 取值 | 作用 |
|---|---|---|
| 类型 | A1–A12、B1、B2 之一（见 [patterns.md](patterns.md)） | 决定写法和配图 |
| 想要的评论 | 解释补充 / 接梗 / 站队 / 转发 / 共鸣 | 动笔前先定，决定留什么口子 |
| 平台 | X（默认）；可补充「中文区」或「英文区」 | 决定列表写法和话题标签规则 |
| 语气 | 装傻求教 / 自嘲幽默 / 老司机吐槽 / 克制客观 / 震惊换算 / 亲和低姿态 | 保证同一批帖子语气不串味 |

一条帖子通常 1 个类型、1 个想要的评论、1 个语气，平台固定写 X。

## 二、类型 → 默认语气、话题标签

| 类型 | 默认语气 | 话题标签 |
|---|---|---|
| A1 不懂就问 | 装傻求教 | 不带 |
| A2 扒料求证 | 克制客观 + 一点兴奋 | 不带；要带只用产品通用名，不用会让人以为已证实的词 |
| A3 故障求证 | 自嘲幽默 | 不带 |
| A4 卧槽体 | 震惊换算 | 不带 |
| A5 冷知识 | 装傻求教 / 自嘲 | 不带 |
| A6 群聊 / 拟人对话 | 自嘲幽默 | 不带 |
| A7 连续剧 | 老司机吐槽 | 可带 1 个固定栏目标签，方便读者追 |
| A8 算账 | 自嘲幽默 | 不带 |
| A9 站边轻判断 | 老司机吐槽 | 不带 |
| A10 荒诞自嘲 | 自嘲幽默 | 不带 |
| A11 产品反转 | 自嘲幽默 | 不带 |
| A12 借热点 | 老司机吐槽 | 不带；要带用事件通用名 |
| B1 关系帖 | 亲和低姿态 | 1–3 个关系类标签，如 `#蓝V互关` `#follow` |

语气是默认值，可以调整，但要和正文一致：自嘲的帖子不要标「克制客观」。

## 三、话题标签（hashtag）规则

**数量**：
- 话题段子（A 组）和短文**默认不带**。复盘里带标签的帖子没有更好，标签对段子基本没有增益。
- 要带就**最多 2 个**：一个宽泛词（如 `#AI`）+ 一个主题词（如 `#AI编程`）。
- B 组关系帖 1–3 个，以关系类标签为核心，最多再加 1 个补充。

**位置**：放在正文最后，空一行后单独成行。不插进正文，不夹在列表中间。

**中英文**：
- 主标签用中文区读者会搜的中文词；关系帖可以再配 1 个英文标签。
- 英文标签用常见写法，多个单词用驼峰（`#BuildInPublic`），不加空格和标点。
- 中文标签不加空格，不夹标点，不超过 10 个字。

**不堆砌**：
- 不叠同义标签（`#互关 #互关互赞 #互粉` 只留一个）。
- 不蹭与内容无关的热门标签。
- 标签和正文里的词重复时，正文照常写，标签可以省掉。

**避免违规或敏感**：
- 不用诱导刷量、互赞互粉群、买粉卖粉一类的标签或暗示。
- 不用涉及政治站队、色情低俗、医疗功效、投资荐股承诺的标签。
- 不用他人姓名、未经许可的品牌名借势；只用事件、产品、公司的通用名称。
- 没有上热搜就不写「热搜」「爆了」类标签；传闻类帖子不用会让读者误以为已证实的标签。
- 关系帖不要同一段文案和标签批量重复发布，也不借助自动化工具发。

## 四、交付时标签放哪

话题标签**属于正文**（正文块末行，没有就不写）；内部分类与备选话题标签**不进正文块**，写在所有正文块之后的「内部标签」块（规约见 [x-delivery-contract.md](x-delivery-contract.md)）：

````text
帖 1：
```text
难道没人觉得 Nova 的语音模式比打字好用吗？

开车时说一句，它就把明早的会挪好了

我是不是用错了打开方式...
```

帖 2：
```text
就差 37 个破 4000

这周写得最用心的一条只有 200 浏览

路过的朋友帮冲一把，评论我都会回

#蓝V互关 #follow
```

链接：无
图片：帖 1、帖 2 不配（纯文字）
内部标签：
- 帖 1：类型=A1 不懂就问｜想要的评论=解释补充｜平台=X｜语气=装傻求教｜备选 无
- 帖 2：类型=B1 关系帖｜想要的评论=共鸣｜平台=X｜语气=亲和低姿态｜备选 #涨粉日记
````

规则：
1. 内部分类四项齐全：类型、想要的评论、平台、语气；备选话题标签最多 2 个。
2. 一批 3–5 条帖子里，类型和语气尽量错开。

## 五、检查清单

- [ ] A 组默认没有话题标签；带了的不超过 2 个，在正文最后一行。
- [ ] B 组不超过 3 个，没有叠同义词。
- [ ] 没有诱导刷量、敏感或与内容无关的标签。
- [ ] 内部分类四项齐全。
- [ ] 正文没有 Markdown 列表、标题和加粗（见 `x-post-format.md`）。
