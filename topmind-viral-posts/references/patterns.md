# 十八大类型写作公式 + 示例拆解

> 本文件的示例均为自编的匿名通用示例，用来说明各类型的写法，不对应任何真实账号或真实帖子，也不含真实互动数据。写作时把示例替换成自己的素材与数字，只借用结构与公式。

> **标签说明**：每个类型和示例后面都带一行 `**标签**`。其中“类型/用途/语气”是内部分类标签（写给自己和用户看的归档标签，不进正文），“话题”是建议写进 X 正文末行的 hashtag。
> 取值范围、话题标签的数量、位置、中英文与敏感词规则见 [tags-and-topics.md](tags-and-topics.md)。
> 示例里的列表需要用 emoji 项目符号，写法见 [x-post-format.md](x-post-format.md)（X 不渲染 Markdown 列表）。

## 1. 干货忠告型

**公式**：痛点标题 + 3-4 行短句讲透 + 一句金句收尾

**标签**（类型）：类型=干货忠告型｜默认用途=立人设、涨粉｜默认语气=干货利落｜话题 #新手指南 #运营心得

**示例**：
```
刚起步时容易漏掉的一步：
内容写完就收工。
不去别人的评论区坐一坐，
再认真的稿子，也像在空房间里念。
先做别人的观众，才会慢慢有自己的观众。
```
**拆解**：标题即钩子；每行 <15 字；"空房间里念"是具象比喻；末句用"先…才…"收束。

**标签**（示例）：用途=立人设｜语气=亲和低姿态｜话题 #新手指南

**示例2**：
```
账号冷启动，先别纠结文案
把前 30 天当成"认识人"的时间
每天看 3 个陌生主页
给其中 1 个留下具体的回应
```
**拆解**：把大目标拆成"3 个、1 个"这样的小任务；时间框（30 天）让建议可执行；每行只说一件事。

**标签**（示例2）：用途=涨粉、立人设｜语气=干货利落｜话题 #运营心得

## 2. 互关求粉型

**公式**：现状/请求 + 回关承诺 + #蓝V互关 #follow

**标签**（类型）：类型=互关求粉型｜默认用途=互关｜默认语气=亲和低姿态｜话题 #蓝V互关 #follow

**示例**：
```
蓝V新手一枚，每晚 9 点统一处理关注列表。
错过的朋友晚点再来，我会逐个回访。 #蓝V互关 #follow
```

**标签**（示例）：用途=互关｜语气=亲和低姿态｜话题 #蓝V互关 #follow

**示例2**：
```
新来的小松鼠，刚把蓝V松果藏好。
树林里还没几个邻居。
想认识一位爱囤干货的朋友，
我会带着坚果去串门。
```
**拆解**：拟人化（"小松鼠""带着坚果去串门"）+ 具体承诺（"我会去串门"），评论区更容易被带动。

**标签**（示例2）：用途=互关｜语气=亲和低姿态（拟人化）｜话题 #蓝V互关 #follow

## 3. 自嘲幽默型

**公式**：具体数字 + 反差自嘲 + 表情收尾

**标签**（类型）：类型=自嘲幽默型｜默认用途=互动、日常｜默认语气=自嘲幽默｜话题 #涨粉日记

**示例**：
```
粉丝数停在 2468 已经三天了
我一边刷新一边告诉自己要淡定
结果手指比脑子诚实
又点开了一遍后台
```
**拆解**：精确数字（2468）建立真实感；"要淡定"与"手指诚实"前后反差；自嘲收尾让人想安慰一句。

**标签**（示例）：用途=日常、互动｜语气=自嘲幽默｜话题 #涨粉日记

**示例2**：
```
怎样才能让帖子被更多人看到？
是不是得先给屏幕烧三炷香
```
**拆解**：提问 + 夸张的玄学答案，短到 2 行，评论区自然接梗。

**标签**（示例2）：用途=互动｜语气=自嘲幽默｜话题 #涨粉日记

## 4. 互动提问型

**公式**：假设场景 + 二选一 + 追问

**标签**（类型）：类型=互动提问型｜默认用途=互动｜默认语气=好奇追问｜话题 按话题取一个，如 #通勤方式

**示例**：
```
假如从下周起
只能选一种通勤方式
地铁 还是 自行车？
先说选择，再说理由
```
**拆解**：人人都有答案的二选一；"先说选择，再说理由"降低回复门槛；评论区天然站队。

**标签**（示例）：用途=互动｜语气=好奇追问｜话题 #通勤方式

## 5. 打卡日常型

**公式**：今日进展 + 心态金句 + 祝福收尾

**标签**（类型）：类型=打卡日常型｜默认用途=日常｜默认语气=温暖祝福｜话题 #日拱一卒

**示例**：
```
今日小结：新增 12 位关注，回复 30 条评论
慢一点没关系，只要每天往前挪一小步
内容先求稳，数据交给时间
晚安，明天继续，大家都早日上岸
```
**拆解**：先报数字再说心态，让打卡有凭据；"小步前进"是人设标签；"大家""上岸"这类圈内用语拉近距离；祝福收尾显得温暖。

**标签**（示例）：用途=日常、涨粉｜语气=温暖祝福｜话题 #日拱一卒

## 6. 新人报到型

**公式**：刚来 + 自我介绍一句 + 求带/求互关

**标签**（类型）：类型=新人报到型｜默认用途=互关、涨粉｜默认语气=亲和低姿态｜话题 #新人报到 #蓝V互关

写法参考第 2 节的拟人化示例。核心：**低姿态 + 具体行动承诺**（"我会带着坚果去串门"比单纯"求互关"更容易得到回应）。

## 通用技巧

- **#follow 标签**：英文标签能让帖子被中文圈以外的人看到，互关帖带上它，曝光面更宽。
- **发布时间**：中文区早 8-9 点、晚 8-10 点互动相对更高，可按自己账号的数据微调。
- **评论区运营**：每条评论都回，比再发一条新帖更有利于涨粉。

## 列表写法（X 不渲染 Markdown）

段子体完全不用 emoji：需要分点时（清单、步骤、对比）**不加任何符号**，一条一行、行间空一行，不写 `- ` / `1.`（规则见 [x-delivery-contract.md](x-delivery-contract.md)）。热点资讯型的「短文版」才用 emoji 列表符号。

**前后对照**（内容一致，只改排版）：

```text
✗ 不要这样写（X 里会原样显示符号）
今晚的互动清单：
- 回复 5 条评论
- 回访 3 个新关注
1. 睡前发一条

✓ 这样写（段子体）
今晚的互动清单：

回复 5 条评论

回访 3 个新关注

睡前发一条

#日拱一卒
```

步骤和对比也一样，靠顺序和措辞表达，不加序号 emoji 或对错符号：

```text
发帖前过一遍：

钩子在第一行吗

前 140 字讲完事实了吗

话题标签：话题段子 2 个、运营帖 1–3 个
```

**标签**（示例）：类型=执行清单型｜用途=日常、立人设｜语气=干货利落｜话题 #日拱一卒

## 配图公式（每类型 1 张）

### 干货忠告型 → 标语图 / 风景
- **标语图**：金句大字（如"先听，再开口"）+ 深色渐变底，白字，字占画面 60%
- **风景**：日出/远眺/山顶，配"格局""远方"感；prompt 加 "wide landscape, sunrise, minimalist"

### 互关求粉型 → 宠物 / 美女
- **宠物**：猫咪直视镜头，眼神无辜/期待；prompt："cute cat looking at camera, innocent eyes, soft light"
- **美女**：自然微笑，生活场景；不低俗，不网红脸

### 自嘲幽默型 → 宠物（搞笑） / 奇幻
- **宠物**：猫咪翻车现场/生无可恋表情包感
- **奇幻**：超现实反差（如猫咪宇航员），"我裂开了"的视觉版

### 互动提问型 → 标语图 / 风景
- **标语图**：二选一文字左右分栏，A vs B，大字对比色
- **风景**：岔路口/两条路，隐喻"选择"

### 打卡日常型 → 风景 / 宠物
- **风景**：日出/晨跑/登山，"小步前进"的视觉化
- **宠物**：猫咪陪伴工作/看书，温暖日常感

### 新人报到型 → 宠物（拟人化） / 美女
- **宠物**：小猫挥手/探头，"新来的"既视感
- **美女**：新人设，清新自然，"大家好我是新人"

## 7. 热点资讯型

**公式**：真实热点 + 段子化压缩 + 原图佐证

**标签**（类型）：类型=热点资讯型｜默认用途=追热点、引流｜默认语气=克制客观，点评另起一行｜话题 事件或产品通用名 + 1 个领域词，如 #AI

传闻类帖子的话题只用事件通用名，不用会让读者以为已证实的标签。

**结构**（段子版）：
```
首句点出场景（最抓人的事实 / 反差）
2-4 行核心事实（短句分行）
末行用一个动作完成反转（或一句神评论）
#相关话题
```

正文里用文字点出处（「官方称」「据传」），不贴 URL、不写来源行。另发：链接（来源名称｜发布时间｜URL）、1–2 张官方原图 / 资讯截图（注明来源）；内部标签放说明里（格式见 tags-and-topics.md），见 x-delivery-contract.md。

**结构**（短文版，300-800 字）：
```
导读句
事实（分点，每点有一手来源，链接另发；分点默认「·」，见 x-post-format.md）
需要时点评一句（写成「预计」「现在看起来」，不用「我认为」）
```

**选题**：AI / 科技 / 技能 / 工具 / 八卦 / 传闻，48 小时内优先。

**配图公式**：
- 第一优先：官方发布图（发布会截图、官方博客配图、GitHub README 图）
- 第二优先：权威媒体资讯截图（注明出处）
- 都没有：先问用户要不要配图，同意后走 topmind-cover 生成示意（注明"示意图"）
- 多图 2-4 张：核心事实图 + 细节图 + 对比图
- 图注：每张图一句说明 + 来源（写在另发的图片那一条里）

**事实（硬约束）**：读者分不清真假的帖子，再好笑也是在消耗信任。
- 传闻标「未经证实」，厂商数字标「厂商口径」
- 推测和事实分开写，推测用「可能」「大概率」或问句
- 不为效果改事实；幽默只加在评论层
- 怎么判断：把每句话单独拿出来，读者能分清哪句是事实、哪句是你的看法

**时空锚点示例**：
- ✅ "10 月 3 日，某航天公司一颗试验卫星升空"（时间+事件）
- ✅ "某连锁品牌在全国 1 万家门店试行智能定价"（地点+规模）
- ✅ "9 月 30 日，某 AI 公司发布新一代模型"（时间+主体）
- ❌ "最近有家公司发了个卫星"（无时间，无细节，不可信）
- ❌ "某地的连锁店涨价了"（无地点，无法核实）

## 8-14. 纯运营吸粉型

> 核心发现：**真诚 > 套路**，"不骗关"一类的真诚声明比单纯"求互关"更容易引发评论。
> 这 7 型是纯 X 运营/吸粉内容，**不蹭新闻热点**，按下面的公式和自编示例写。

## 8. 暴论型

**公式**：反常识论断 + 具体论据 + 短句分行

**标签**（类型）：类型=暴论型｜默认用途=互动、引流｜默认语气=反差暴论｜话题 #暴论 + 1 个主题词

**示例**：
```
做内容当副业，比想象中累
每天下班后还要写稿、剪图、回评论
周末也不敢断更
所谓自由，常常是自己给自己打工
```
**拆解**："下班后还要…"的具象场景制造共鸣；"自己给自己打工"一句收尾有反差；暴论天然容易引发讨论。

**标签**（示例）：用途=互动、引流｜语气=反差暴论｜话题 #暴论 #副业

**示例2**：
```
先抛一个暴论：
未来三年，会提问的人比会回答的人值钱
#蓝V互关 #follow
```
**拆解**："暴论"二字本身就是钩子；先标明是暴论，等于给自己留了退路，评论区更愿意来辩。

**标签**（示例2）：用途=互动｜语气=反差暴论｜话题 #暴论 #蓝V互关

## 9. 数据晒单型

**公式**：具体数字 + 反差/进度 + 配图实证

**标签**（类型）：类型=数据晒单型｜默认用途=立人设、涨粉｜默认语气=真诚笃定｜话题 #数据复盘 #曝光量

**示例**：
```
创作者收益的门槛里，有一项是曝光量。
但不是所有曝光都会被计入，常见口径有 3 种：
① 原创内容带来的
② 推荐流里的
③ 认证用户看到的
我 7 天后台总曝光 18K，计入口径的约 4K。
你的比例是多少？评论区报个数
#曝光量 #蓝V #蓝朋友
```
**拆解**："不是所有曝光都计入"制造悬念；"18K→4K"的落差让人想对照自己；结尾"报个数"让评论区变成数据接龙。（示例数字为虚构，使用时换成自己的真实数据。）

**标签**（示例）：用途=立人设、互动｜语气=真诚笃定｜话题 #曝光量 #蓝V #蓝朋友

**示例2**：
```
认真互动了大约 3 小时，
主页访问明显多了一截，
现在就算我没去关注别人，也陆续有新朋友来打招呼
```
**拆解**：后台截图是最好的信任状；"3 小时"这类具体时间点增强真实感。

**标签**（示例2）：用途=立人设｜语气=真诚笃定｜话题 #数据复盘

## 10. 真诚交友型（评论率较高）

**公式**：真诚声明 + 低姿态 + "不骗关"

**标签**（类型）：类型=真诚交友型｜默认用途=互关｜默认语气=真诚笃定｜话题 #真诚交友 #蓝V互关

**示例**：
```
先亮明身份：真人，蓝V，每天都在更新。
想认识几位聊得来的朋友，不为刷数字。
关注之后我会回访、点赞、留言，
不互相取关，说到做到。
#蓝V互关 #真诚交友
```
**拆解**："先亮明身份"开门见山；"真人""每天更新"强调真实活跃；"不互相取关，说到做到"是信任状，直接回应大家对取关党的顾虑。

**标签**（示例）：用途=互关｜语气=真诚笃定｜话题 #蓝V互关 #真诚交友

**示例2**：
```
最近的小目标：每周认识 3 位新朋友。
常更新的蓝 V，来评论区说句话吧。
不比数字，只想找几个观点有意思的人。
聊得来就继续聊
```
**拆解**："每周 3 位"把愿望变成可检验的小目标；"不比数字"是反套路表达；配生活照可以增加真实感。

**标签**（示例2）：用途=互关、互动｜语气=真诚笃定｜话题 #蓝V互关 #follow

## 11. 吐槽共鸣型

**公式**：平台痛点 + 自嘲 + 表情

**标签**（类型）：类型=吐槽共鸣型｜默认用途=互动、日常｜默认语气=自嘲幽默｜话题 #创作者日常

**示例**：
```
不是我不想回关
系统每天只让我操作一小批
排队的朋友请再等等，我一个都没忘
```
**拆解**：点出"系统每天有限额"这一具体原因；"一个都没忘"给对方吃定心丸；示弱的语气拉近距离。

**标签**（示例）：用途=互动｜语气=自嘲幽默｜话题 #创作者日常

**示例2**：
```
自从认真运营账号
睡前刷剧变成了回评论
周末逛街变成了写草稿
连通勤路上都在构思下一条
```
**拆解**：排比句式"变成了…变成了…"；用生活细节自嘲"上瘾"，容易引来同类接龙。

**标签**（示例2）：用途=日常、互动｜语气=自嘲幽默｜话题 #创作者日常

## 12. 干货技巧型

**公式**：实用技巧 + 原理 + 行动指令

**标签**（类型）：类型=干货技巧型｜默认用途=立人设、引流｜默认语气=干货利落｜话题 #运营技巧 #follow

**示例**：
```
晚上好，各位新朋友
分享一个很小的发帖习惯：
写互关帖时，顺手加上 #follow
英文标签能把帖子带到中文圈以外
被看到的机会多一点，认识的人也会更多元
#follow #蓝V互关 #真诚交友
```
**拆解**："晚上好"开场白拉近距离；技巧具体可执行；点明"英文标签扩大触达"的原理；"认识的人更多元"给出收益。

**标签**（示例）：用途=立人设、互关｜语气=干货利落｜话题 #follow #蓝V互关 #真诚交友

**示例2**（配信息图）：
```
本周涨粉小结（记录向）
周一到周五，每天新关注 10 位同领域账号
每天写 5 条有信息量的回复
每周发 3 条原创帖
两周下来，粉丝从 800 涨到了 1000 出头
```
**拆解**：数字清单体（示例数字为虚构，换成自己实测的数字）；"周期 + 结果"让读者看到因果；配一张执行清单信息图，干货可视化。

## 段子体排版（所有类型通用）

X 段子默认用**段子体**：一句一行，**行与行之间都空一行**。手机上每句都是一个独立的停顿，读起来像在说话。

- 一行一个意思；长句在逗号处断开，只断在意思完整的地方。
- 需要分点时不加任何符号，一条一行、行间空一行；不用 `- ` `1. `，也不用 emoji 列表符号。
- 开头钩子单独一行（「说个冷知识：」「妈的，」「问个问题：」）；结尾行动号召单独一行。
- **完全不用 emoji**：没有人设点缀、情绪表情和列表符号（emoji 体系只用于短文体，见 [emoji-system.md](emoji-system.md)）。
- 现成文字要转段子体，交给 `topmind-format`（只排版不改字）。

## 15. 冷知识揭秘型

**公式**：「说个冷知识：」→ 一个反直觉的机制（2–3 行）→ 一个具体数字的后果 → 「难怪……」点出现象 → 互关 / 评论钩子

**标签**（类型）：类型=冷知识揭秘型｜默认用途=互关、引流｜默认语气=好奇追问｜话题 #蓝V互关 #创作者收益

**示例**（原创演示；机制描述须先核实，未核实时加「据我观察」或「（传言）」）：
```
说个冷知识：

蜂蜜几乎不会变质。

它太甜了，水分又少，

细菌在里面活不下去。

所以一罐没开封的蜂蜜，

放上好几年也照样能吃。

难怪厨房里它总待在最里面

你还知道哪些放不坏的食物？
```
**拆解**：开头四个字定调；机制拆成三四行，每行一个信息点；「同样十万浏览」用具体数字造反差；「难怪」把冷知识接到读者身边的现象；最后一行直接给动作。

**标签**（示例）：用途=互关｜语气=好奇追问｜话题 #蓝V互关

## 16. 差额冲刺型

**公式**：情绪开场（吐槽 / 卖惨）→ 自己的努力（天数）→ 精确的当前数字 → 差额（「就差 N 个」）→ 求助 → 回馈承诺 → **后台截图作证据**

**标签**（类型）：类型=差额冲刺型｜默认用途=涨粉、互关｜默认语气=自嘲幽默｜话题 #蓝V互关 #涨粉日记

**示例**（原创演示，数字为虚构）：
```
别人随手一条就上热门，

我认认真真写了十几天，

才攒到 2904 个关注。

就差 96 个破 3000 了。

朋友们，今天能帮我冲一把吗？

关注我的，评论区留个言，我挨个回！
```
配图：自己的主页截图（粉丝数清晰可见），打码其他人的头像和昵称。

**拆解**：差额比总数更有号召力（「差 96」比「2904」更让人想帮一把）；截图让数字可信；「挨个回」是具体回馈。语气可以自嘲，但不攻击具体的人。

**标签**（示例）：用途=涨粉｜语气=自嘲幽默｜话题 #蓝V互关

## 17. 反差对照型

**公式**：A 的情况（一行）→ B 的情况（一行）→ 差距的数字 → 一句自嘲或提问

**标签**（类型）：类型=反差对照型｜默认用途=互动｜默认语气=自嘲幽默｜话题 #创作者日常

**示例**：
```
别人：发一张猫片，三百个赞。

我：写了两千字教程，十一个赞。

其中三个是我小号。

所以下一条，我也发猫
```
**拆解**：「别人：/ 我：」对仗；第三行补一刀把自嘲拉满；最后一句给出好笑的结论，顺带引出下一条。

**标签**（示例）：用途=互动、日常｜语气=自嘲幽默｜话题 #创作者日常

## 18. 自问自答型

**公式**：一个读者常问的问题 → 「答：」一句结论 → 两三行理由 → 「你们怎么看？」

**标签**（类型）：类型=自问自答型｜默认用途=立人设、互动｜默认语气=干货利落｜话题 #运营心得

**示例**：
```
总有人问：新号要不要买会员？

答：先发满 30 天再说。

前 30 天的问题是没人看，

不是看了没奖励。

你们当时是第几天开的？
```
**拆解**：用读者的问题开头，天然有代入感；「答：」后面只给一个可执行的结论；结尾把问题抛回去，带评论。

**标签**（示例）：用途=立人设、互动｜语气=干货利落｜话题 #运营心得

## 组合玩法（钩子 × 主体 × 收尾）

一条段子 = 一个钩子 + 一个主体 + 一个收尾。同一个主题换一种组合，就是一条新帖。

| 钩子（第 1 行） | 主体（中间 3–5 行） | 收尾（最后 1 行） | 典型组合 |
|---|---|---|---|
| 说个冷知识： | 机制 + 数字后果 | 互关报到 | 冷知识揭秘 + 互关求粉 |
| 妈的， / 救命， | 努力 + 精确数字 + 差额 | 求助 + 回馈承诺 + 截图 | 吐槽共鸣 + 差额冲刺 |
| 别人： / 我： | 两种情况对照 | 自嘲结论 | 反差对照 + 自嘲幽默 |
| 总有人问： | 「答：」+ 理由 | 你们怎么看？ | 自问自答 + 互动提问 |
| 刚刚看到： | 真实热点（来源另发） | 一个动作完成反转 | 热点资讯 + 段子配方 |
| 第 N 天打卡： | 今天做了什么 + 数字 | 明天见 | 打卡日常 + 进度条 |
| 新人报到： | 我是谁 + 写什么 | 求带 / 求互关 | 新人报到 + 真诚交友 |
| 后台数据给大家看看： | 截图 + 两个关键数字 | 你们涨得快吗？ | 数据晒单 + 互动提问 |

组合规则：

1. 一条只用一个钩子、一个收尾；主体不超过 5 行。
2. 有数字就要真实：用户给的数字才写，截图里的数字和正文一致。
3. 有事实就要来源：热点、机制类说法在正文里用文字点到出处（或标「（传言）」「据我观察」），链接另发。
4. 同一天连发时，相邻两条换钩子和收尾，避免一个模板刷屏。
5. 话题段子（热点、产品）按 `core-voice.md` V31 的段子配方：具体产品 + 可信场景 + 它的典型特点 + 末行动作反转；互动钩子只给运营引流类。

示例（虚构）：

```text
让某 agent 帮我清理订阅

它翻完账单，列了三个用不上的

问我要不要全部取消

我说行

结果第一个取消的就是它自己

#AI #智能体
```
