# 段子类型：12 类话题段子 + 2 类关系帖

本文所有示例都是自写的，产品名、人名、数字全部虚构，只演示写法。旧版 18 类和附录 A–O 的对应关系见文末「旧编号对照表」。

## 先想清楚：你想让哪种人来评论

选类型之前先回答这一个问题，它比套公式重要：

| 想要的评论 | 把自己放在哪 | 对应类型 |
|---|---|---|
| 懂行的人来解释、补充 | 真没搞懂的位置 | A1 不懂就问、A2 扒料求证、A3 故障求证 |
| 读者接梗、玩梗 | 留一个没讲完的画面或故事 | A6 群聊体、A7 连续剧、A10 荒诞自嘲、A11 产品反转 |
| 两边各执一词 | 给一个对立轴，站一边但不站满 | A9 站边轻判断、A12 借热点 |
| 被震到、愿意转发 | 一个换算后的反差数字 | A4 卧槽体、A8 算账 |
| 「我也是 / 我才知道」 | 和读者一起踩坑 | A5 冷知识、A10 荒诞自嘲 |

以下方向来自既有写作经验，当前仓库没有可重现的对照数据，不能据此承诺流量。真问题、群聊、算账、平铺信息、句号或省略号都有合适场景；可用同事实候选比较，再按作者选择调整。当前用户的体裁、表情与篇幅要求优先。

## 总表

| 类型 | 一句话 | 典型钩子 | 收尾 |
|---|---|---|---|
| A1 不懂就问 | 装傻式真疑问，问自己真拿不准的事 | 难道没人…吗？/ 一直没想明白 | 「...」或另一个真问题 |
| A2 扒料求证 | 线索 + 上次的结果 + 猜测问句 | XX 要上新了？！ | 「？！」或「...」 |
| A3 故障求证 | 第一时间问「挂了吗」，加一句梗 | XX 挂了吗？/ 是不是就我这样？ | 梗 |
| A4 卧槽体 | 真实反应 + 换算后的数字反差 | 卧槽，算完我人傻了 | 偏正面或自嘲，「...」 |
| A5 冷知识 | 「我才知道」的懵逼口吻，不当老师 | 我才知道… | 自嘲动作 |
| A6 群聊 / 拟人对话 | 每家一句「xx：」，最后一句是包袱 | 今日 XX 群： | 最后一家的话 |
| A7 连续剧 | 同一个主角的连续进展，固定栏目名 | 栏目名 + Day N | 押注、竞猜、出主意 |
| A8 算账 / 额度侦探 | 自己的真实数字换算成钱、时间、次数 | 一个 XX 干掉我 N% 额度 | 自嘲或站边 |
| A9 站边轻判断 | 承认一方，给一个内行的轻判断 | 确实…但… | 判断本身 |
| A10 荒诞自嘲 | 集体痛点写成荒诞画面 | 我以为…已经是极限了 | 荒诞动作 |
| A11 产品反转 | 具体产品 + 可信场景 + 它的典型特点 | 一个生活场景 | 末行动作反转 |
| A12 借热点 | 新事套上大家熟悉的旧梗，一句带过 | X 版「某某」来了 | 情绪或关键事实 |
| B1 关系帖 | 互关、新人、打卡、差额冲刺、真诚交友 | 真实进展 | 行动号召（按互动目标选择） |
| B2 互助帖 | 求码、送码 | 真实需求 | 回馈承诺 |

**A 组**是内容，**B 组**是维护关系。B 组每周 1–2 条就够，不算进内容配比，复盘时单独统计（回复多不等于有讨论）。

原来的干货类（干货忠告、干货技巧、经验忠告、执行清单、自问自答的答案部分、划重点、顿悟揭秘）不再算段子，交给 `topmind-briefs` 的「观点 / 经验一句话」短文。

## 段子排版选项

一句一行适合按节拍展开，紧凑对话和短段也成立；表情、对仗、问句可为情绪或笑点服务。更多见 `x-layout-patterns.md`。下面每类的“反例”只说明该例哪里可能没效果，不作为句式黑名单。

## A1 不懂就问（装傻式真疑问）

- **适用题材**：新功能、怪现象、赚钱模式、版本号、定价，也就是你确实拿不准的事。
- **怎么判断是真问题**：换一个懂行的读者来答，他能给出具体答案，就是真问题；只能回「是啊」「看情况」的，是钩子。
- **钩子**：「难道没人…吗？」「一直没想明白」「我就纳闷了」「到底是…？」
- **结构**：问句一行 → 一两行你看到的具体现象或体验 → 可以接一句真心推荐或吐槽。
- **收尾**：「...」或者另一个真问题。
- **反例**：
  - 明知故问：「你还不知道 XX 吗？」
  - 问大家的感受：「大家是不是已经没新鲜感了？」（谁都能答，等于没问）
  - 同一个问法一周用好几次，读者会识破。

```text
难道没人觉得 Nova 的语音模式比打字好用吗？

开车时说一句，它就把明早的会挪好了

我是不是用错了打开方式...
```

```text
一直没想明白

这么多模型都免费挂着

平台到底靠什么赚钱？
```

## A2 扒料求证

- **适用题材**：代码提交、配置文件、模型列表里闪现的名字、客户端里冒出的新入口。
- **钩子**：「XX 要上新了？！」「又被扒到一点...」
- **结构**：线索一行（在哪看到什么）→ 上一次类似线索后来怎样 → 猜测写成问句。
- **收尾**：「？！」或「...」。
- **反例**：
  - 把「网传」直接当事实写；
  - 人事八卦、负面传言；
  - 文案里写自己的查证过程（查证只给自己看）。

```text
青鸟要上新了？！

它家接口文档里多了一个 bird-pro-1105

上次多出来的名字，三天后就官宣了...
```

```text
某编辑器设置页里多了一个灰色开关

名字叫「后台 agent」

点不动，但我已经开始期待了...
```

## A3 故障求证

- **适用题材**：服务卡顿、报错、额度异常。时效以分钟计，晚一小时就没意义了。
- **钩子**：「XX 挂了吗？」「是不是就我这样？」
- **结构**：问句 → 自己的症状一句 → 一句梗。
- **收尾**：梗，或者「...」。
- **反例**：事后很久再发；写成故障分析；嘲讽厂商。

```text
Nova 挂了吗？

我这转圈转了五分钟

服务器是不是也在排队领额度...
```

## A4 卧槽体（震惊 + 换算 / 反差）

- **适用题材**：大数字、大投入、离谱对比（算力、价格、用量）。
- **钩子**：「卧槽，算完我人傻了」「我靠，算了一下」，后面必须马上跟一个具体事实。只有情绪没有数，就是空喊。
- **结构**：反应一句 → 原始数字 → 换算成读者熟悉的单位 → 拿自己或身边的处境对比。
- **收尾**：偏正面或自嘲，用「...」收。
- **反例**：只有情绪；「史上最狠」这类空形容词；一条里堆三组换算。

```text
卧槽，算完我人傻了

某公司一个新机房要放 20 万张卡

按一张卡一台电脑算，差不多是一个小县城每家一台

我这边还在为一个月 20 块的订阅犹豫...
```

```text
我靠，算了一下

一个视频生成一次的钱

够我点三天外卖了...
```

## A5 冷知识（我才知道 / 白干了）

- **适用题材**：平台规则、计费口径、工具的隐藏机制。必须先核实，没核实就不写。
- **钩子**：「我才知道…」「说个冷知识：」（同一个钩子一周别超过两次）
- **结构**：反直觉的事实 → 你之前是怎么做的 → 一个后果。
- **收尾**：自嘲动作，比如「白干了？」「明天开始改」。不加「你还知道哪些？」。
- **反例**：科普老师口吻（「很多人不知道…其实…」）；结尾求补充；没核实。

```text
我才知道，Nova 的深度模式是每一轮单独计费的

我开着它聊了一整天

白干了？
```

```text
说个冷知识：

草稿箱里的定时帖，改过一次就重新排队

我昨晚改了三次错别字

难怪到现在还没发出去...
```

## A6 群聊 / 拟人对话体

- **适用题材**：同一天几家都有动静，或者同一件事各家的反应。
- **钩子**：「今日 XX 群：」
- **结构**：每家一句「xx：」，用大家公认的性格；最后一行就是包袱。
- **收尾**：最后一家的那句话，不另加总结。
- **反例**：编造某家的真实表态；超过 6 家；每句一样长、像对仗。

```text
今日模型群：

青鸟：新版本上线了，价格没动

Nova：我们也上线了，价格动了

小甲：你们上线前能不能先说一声

用户：我只想知道今天哪家不排队
```

```text
今日编辑器群：

A：我加了个 agent

B：我也加了个 agent

C：我把编辑器删了，只剩 agent

用户：那我的快捷键呢？
```

## A7 连续剧

- **适用题材**：同一个主角的连续进展，比如某人的上线挑战、某产品的发布倒计时、自己的冲刺计划。
- **钩子**：固定栏目名 +「Day N」，或「XX 之番外」。
- **结构**：这一集发生了什么（一句）→ 你的反应 → 押注，或给主角出个主意。新读者要能看懂，前情一句带过。
- **收尾**：竞猜（先给自己的押注），或「明天见分晓...」。
- **反例**：写成进度播报；没交代前情；每集模板一模一样。

```text
阿柚的 30 天上线挑战 Day 18

说好今天发测试版，到现在还没动静

我押今晚十一点，不然他又要熬到天亮了...
```

```text
阿柚 30 天挑战之番外

他说今天休息

然后提交记录里多了 40 条...
```

## A8 算账 / 额度侦探

- **适用题材**：订阅、额度、token 账单、羊毛到底值不值。
- **钩子**：「一个 XX 干掉我 N% 额度」「相当于每个月白得…」
- **结构**：自己的真实数字 → 换算（钱、时间、次数）→ 值不值的一句判断。数字必须是作者自己的，不编。
- **收尾**：自嘲（「我是不是冤大头...」），或者站一边。
- **反例**：转述官方价格表；编用量；写成表格。

```text
一上午跑了 3000 万 token，账单 9 块

缓存命中了一大半

这个价，我都不好意思关电脑了...
```

## A9 站边轻判断

- **适用题材**：工作流、工具选择、行业习惯。
- **钩子**：一句内行的轻判断，比如「有点装」「过时了」「大概率会赢到最后」。
- **结构**：先承认一方 → 下判断 → 给反驳留一点余地（「至少我是这样」）。一帖一个对立轴。
- **收尾**：判断本身，或「...」。不加「你们怎么看」。
- **反例**：「说实话」加中立表态（「各有优劣，看场景」）；外行判断（会被骂，不会被讨论）；一条里两个对立轴。

```text
终端里用编程 agent 确实快

但天天晒命令行截图，多少有点装

至少我还是开着编辑器...
```

## A10 荒诞自嘲（集体痛点）

- **适用题材**：注册门槛、支付、网络、账号风控这类每个人都有一段经历的事。不写自己的具体渠道。
- **钩子**：「我以为…已经是极限了」「最稳的办法是…」
- **结构**：真实痛点一句 → 荒诞的解决办法或荒诞画面。
- **收尾**：一个荒诞动作。
- **反例**：写成教程；暴露自己的渠道和隐私；骂某地用户。

```text
我以为换了三张卡才订上 Nova，已经是极限了

今天看到有人为了过验证，专门去学了一门外语

这届用户，是真爱...
```

## A11 产品反转段子

- **适用题材**：某个具体 agent 或工具的典型特点。
- **钩子**：一个生活场景。
- **结构**：具体产品（点名，不说泛称「AI」）+ 可信场景 + 它照章办事的特点。场景一句交代，不并列堆细节。
- **收尾**：末行用动作完成反转。
- **反例**：泛称「AI」；并列堆细节；凭空编的离谱情节。

```text
让 Nova 帮我砍掉用不上的订阅

它翻完账单列了三个

我说都退了吧

它先把自己退订了
```

```text
让编程 agent 把项目里的警告清干净

十分钟后零警告

它把检查规则关了
```

## A12 借热点

- **适用题材**：一件新事，正好能套上读者熟悉的旧梗。
- **钩子**：「X 版『某某』来了」
- **结构**：主角一句（新事）→ 借来的梗一句带过 → 一句口语情绪。一帖一个主角，借来的梗不展开。
- **收尾**：情绪，或一个关键事实，用「...」收。
- **反例**：把借来的梗也展开讲；两个主角平分篇幅。

```text
模型界的「双十一」来了

三家同一天降价，降完还是比去年贵

我的钱包已经不想过节了...
```

## B1 关系帖（互关、新人、打卡、差额冲刺、真诚交友）

- **适用场景**：维护关系、里程碑。每周最多 1–2 条，不算进内容配比。
- **钩子**：真实进展，比如「就差 37 个破 4000」。数字必须是真的。
- **结构**：进展 → 一句自嘲 → 回馈承诺，承诺要做得到。
- **收尾**：行动号召。只有这一类允许号召。
- **反例**：天天发；承诺「必回关」；编粉丝数；同一段文案批量重复发。
- **话题标签**：可以带 1–3 个关系类标签。

```text
就差 37 个破 4000

这周写得最用心的一条只有 200 浏览

路过的朋友帮冲一把，评论我都会回
```

**写法变体**（旧附录压缩，按需选一个，不要叠）：

| 变体 | 写法要点 |
|---|---|
| 出摊体 | 「出摊了」+ 今天准备聊什么，像开店打招呼 |
| 目标打卡 | 今天的目标数字 + 昨天的结果，第二天接着报 |
| 进度条体 | 同一个目标连续几天报进度，写法同 A7 连续剧 |
| 新人报到 | 拟人化自我介绍 + 想认识什么样的人 |
| 真诚交友 | 说清自己写什么、为什么值得关注，不承诺回关 |
| 差额冲刺 | 吐槽开场 + 精确差额，见上面示例 |
| 评论区报名 | 「想要 XX 的评论区留个言」，只在真的会兑现时用 |

## B2 互助帖（邀请码、求码）

- **适用场景**：真的需要码，或手里有码要送。回复会很多，但不是讨论，复盘时单独算。
- **写法**：需求一句 + 回馈一句，不夸张，不承诺做不到的事。

```text
某工具额度又被我干光了

有邀请码的兄弟救一下，回头我的码也分出来
```

## 组合规则

- 一条只用一个钩子、一个对立轴、一个主角。
- 同一天连发时，相邻两条换类型、换钩子。
- 同一个钩子词（「说个冷知识」「难道没人」）一周不超过两次。
- 可以叠的只有「钩子类型 + 收尾类型」：比如 A1 的问句开头 + A10 的荒诞画面收尾。两个完整类型硬拼在一条里，读者抓不到重点。
- 写完做一次**删尾测试**：把最后半句删掉读一遍，删掉更好就删。

## 配图（按类型）

| 类型 | 默认 | 什么时候配 |
|---|---|---|
| A1、A5、A6、A7、A9、A10、A11、A12 | 纯文字 | 基本不配 |
| A2 扒料、A3 故障、A8 算账 | 纯文字 | 截图本身就是证据时配一张（代码、报错、账单，打码他人信息） |
| A4 卧槽体 | 纯文字 | 原始数字来自一张图（发布会截图、榜单）时配原图 |
| B1、B2 | 纯文字 | 自己的主页或后台截图；用户要求时才生图 |

需要生图时先问用户，同意后走 `topmind-cover`；图库和提示词写法见 SKILL.md「配图」。
