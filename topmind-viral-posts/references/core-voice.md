# 措辞与口吻：作者声音画像与场景经验（V01–V40）

本库默认写得清楚、自然、有人味，但不把所有作者锁进同一种人设。当前用户的要求、作者历史样本、目标读者和具体稿型决定最终声音。没有作者样本时，保持输入语域自然干净；有作者样本时，优先对齐样本的节奏、称呼与标点习惯。

---

## 一、高辨识度中文社交作者声音参考（有样本或同类风格时取用）

### 1. 语气与身位：群里聊天的熟人，不是客观评论员
- **口语直给**：像在群里跟熟人说话。能站边时鲜明站边，不两头讨好；有槽点可以犀利调侃（两三句毒舌 + 一个画面型反差，如「先交 8 刀保护费」），但不写人身攻击，也不排比论证。
- **情绪真实**：真吃惊就吃惊，真想不通就问，不把自己收拾成四平八稳的「行业观察员」。
- **具体点名**：常用称呼是「兄弟们」「兄弟」「大家」（较少用客套的「朋友们」），而且优先**把对象点具体**——如「20 美元档的兄弟」「用某模型 5.2 的兄弟」「做评测、跑榜单的兄弟们注意了」。虚指的群体（「中文区好几个人在喊」）直接删掉；圈内熟知的外号直接叫外号。

### 2. 六种经过实战验证的句式思路（是思路，不是填空模板）
1. **意外细节 + 愣一下 + 顺手算账**：先把反常细节抛出来，跟读者一起愣一下，再换算成日常账单（如「等一下，给部分工程师的 AI 额度是按天算的？？？……第一反应是写错了，应该是每月吧……一天 300，够订 15 个月会员！！！」）。
2. **带态度的定性先行 + 实用清单在后**：纯清单能用但像说明书；先给一句带判断的定性（「这定位是成为匿名模型首秀和数据收集平台了吧...」），再落今天的新变化和 `1）2）` 清单。
3. **具体名字与反差放开头，「意味」留到最后当反转**：不要拿「终于有个榜单，第一名谁都不想要」这种抽象意味在开头卖关子；先把谁、干了什么、多离谱的数字砸出来。
4. **用对话和动作场面代替评论**：「一个进门，一个下楼。」一句画面顶十句行业分析。
5. **给事件起一个记得住的短称呼**：如「分手倒计时」「白送一次重置」，比公文式的「拟议终止日就是今天」更像帖子。
6. **命令改商量**：把讲师式的「别无脑开最高档！！！」改成邻座商量的「都开最高档吗？可能大多数时候次高档就够了...」，判断还在，爹味没了。

### 3. 标点与情绪妆：力气活要用在刀刃上
`？？？`、`！！！`、`！！？`、`……` 是传递语气的重要工具，在短帖、段子、回复中**不是格式错误**，但也不要给每条平淡稿都硬戴：
- `？？？`：真吃惊，或真想不通背后的逻辑。
- `！！！`：数字或场面本身已经够冲，顺势加重语气。
- `！！？`：惊叹里带着怀疑（如「某平台被黑了！！？」），**随后紧接一句澄清真实范围**，绝不靠标点骗点击。
- `……` / `...`：话点到为止，留白给读者自己品或接话。
- **表情克制**：不用满屏 emoji 硬妆；仅在确实贡献情绪或视觉节奏时少量点缀。

### 4. 回帖与原创的边界隔离
- **引用转发（Quote）**：是一条独立新帖，去掉原帖已有的信息后，必须剩下自己的一句实质判断或增量视角；忌「官方公告中文版」「几个意思？？？」这类薄引用。
- **评论区回复（Reply）**：是聊天接话，不是写点评综述。中文回帖通常极短（常见中位约十来个字），**不复述原帖、不套「跟……一个道理」的类比、不端总结腔、不替作者编经历**；英文大号下常为 3–6 个词的自然口语。
- **切勿串层**：回帖的「极短」与「硬禁类比」只针对评论区回复，**不要套到原创干货短帖或公众号长文上**。

## 二、场景经验索引（V01–V40）

V 编号供参考与脚本定位使用；它们是可选经验，不是逐条合规门槛。

| 编号 | 经验与可选写法 | 判断时留意 |
|---|---|---|
| V01 标题 | 直陈、真问题、反差数字、短称呼、工具点名均可 | 主题可辨、定性准确；工具介绍可直接在标题点名插件/工具 |
| V02 副标题 | 补适用范围、读者收益或另一层信息 | 是否增加理解，而非换词重复主标题 |
| V03 封面文字 | 核心主题词、判断短语或关键数字 | 缩略图清晰可读，配合画面层次 |
| V04 摘要 | 概括核心结论、关键变化或一个核心问题 | 让读者一眼判断值不值得点开 |
| V05 开头 | 结果/反差前置、具体场景、真疑问、态度定性 | 能否让读者停下或拿走价值；不设死板字数上限 |
| V06 小标题 | 结论式、问题式、功能点式、编号或不编号 | 读序清楚，同篇体例一致 |
| V07 过渡 | 直接进下一节，或用一句话接住因果 | 删掉「说完 A 再看 B」式报幕；保留必要逻辑转折 |
| V08 观点句 | 「我倒觉得」「感觉……更有利」或直接判断 | 保留个人口吻与主观温度，同时减弱无依据的绝对因果 |
| V09 对照与排比 | 用于辨析真差异、推进节奏 | 有实质信息差时保留；凑字数的工整排比删去 |
| V10 收尾 | 停在事实、适用边界、真问题或「……」留白上 | 执行删尾测试，不强加升华金句或漂亮比喻 |
| V11 对比 | 表格、分行 `1）2）`、对照块、自制图 | 同维度对齐，口径一致 |
| V12 数字与体感 | 精确值与「约/左右」按信源保留；参数译成体感 | 「41 克」译为「跟普通眼镜差不多重」；大数按中文习惯写「39 万」 |
| V13 引语与对话 | 引语核对原意；段子对话可直接写「人名：」 | 「考虑」不改成「宣布」；引述中的原词（如「真正追上」）正常保留 |
| V14 来源 | 长文可文内点明或文末列参考；X 短帖来源链接放块外 | 读者能辨别信源分量；查证流水账不进正文 |
| V15 图文配合 | 一图讲清变化/边界/建议；简单直观功能用标题+例子+截图 | 证据与作者建议分区；不为凑字数把图里每行字再抄一遍 |
| V16 链接 | 公众号/长文可随文放安装命令与链接；X 短帖默认另列 | 按平台习惯与读者使用便利安排 |
| V17 段长与换行 | X 短帖按段落空行；长文短段与完整推演自然交错 | 不搞「每句空行」或「所有稿三五行」；110 字仅为长文扫读提醒线 |
| V18 概念与术语 | 圈内常用词直呼；复杂概念翻成人话或日常场景 | 英文提示词原句、命令、参数名保留原文，后附一句中文大意 |
| V19 梗与外号 | 圈内熟知外号、事件短称呼、画面反差 | 贴合目标受众语境，不堆砌过时自媒体套话 |
| V20 力度 | 语气强度由数字、反差和事实本身支撑 | 不靠「重磅」「炸裂」硬撑场面 |
| V21 厂商与评测 | 保留作者实测数据、个人褒贬与具体观察维度 | 即使外部在「吹爆」，也按具体维度客观展开，不改成四平八稳综述 |
| V22 状态与边界 | 区分已发布、灰测、传闻、开源代码变动与网上观察 | 长文写清限定；短帖用自然人话或真问句+紧接澄清，不塞播报作业词 |
| V23 经验与推介 | 结果前置 + 可直接照做的原件 + 适用对象 + 何时别用 | 明确「什么情况下别用」，不凭空补方法或保证结果 |
| V24 教程与插件文 | 工具/插件介绍可把安装方式与解决痛点放开头 | 简单直观的功能用「小标题 + 例子 + 截图」，不长篇讲道理 |
| V25 列表 | X 短帖有列表优先用紧凑 `1）2）`（或 `·`） | 没有并列内容不硬加列表；Markdown 列表在普通帖可按需转纯文本 |
| V26 emoji | 按作者习惯克制使用，承载情绪或结构 | 无封闭白名单，也不强制每帖加表情 |
| V27 话题标签 | X 短帖默认不带（特定榜单等除外）；国内平台按上限用 | 平台习惯归平台层，不当成写作质量标准 |
| V28 发版与规则变化 | 钩子抓核心反差，紧接对用户的实际影响与操作建议 | 代码参数变化不写成线上已全面生效 |
| V29 回复 | 接住话头，给一句态度、具体做法或短追问 | 不复述原帖，不套类比，不端架子 |
| V30 引用转发 | 亮出自己的增量判断、吐槽或使用切口 | 去掉原帖内容后仍能独立成立 |
| V31 段子 | 观察、反差、群聊拟人、产品反转、算账、自嘲 | 包袱落在最后一句动作或对话上，说完即停 |
| V32 自然语流 | 顺着口语呼吸感写，主谓利落 | 不机械压缩双音词，也不堆叠名词化短语 |
| V33 具体性 | 点名具体对象、具体场景、具体数字 | 删掉「某网友」「好几个人」等虚指铺垫 |
| V34 问句与装傻 | 真困惑 + 切身痛点 + 一句话能接 + 后半句不说完 | 问号本身不涨流量；忌空壳提问、自问自答与文末假互动 |
| V35 情绪标点 | `！！！` `？？？` `！！？` `……` 随真实情绪与反差出现 | 贴合内容张力，不给平淡信息强行化妆 |
| V36 立场 | 有依据时鲜明表态，有条件时说清条件 | 不为讨好两边写「各有千秋」，也不为博眼球硬造极端对立 |
| V37 回复长度 | 随交流目的自然长短 | 短评一句到位；对方请教方案时可具体展开 |
| V38 中英混排 | 保留必要的模型名、档位名、命令与提示词原文 | 不必生硬汉化圈内通用词，也避免无意义的英文小词堆砌 |
| V39 信息信噪比 | 砍掉购买门槛、到货日、致谢花絮、查证流水账 | 留下读者真正关心、能复述或能照做的干货与反差 |
| V40 口径一致 | 预告、灰度、个人观察、官方正式公告的动词分清 | 不把网上零星反馈写成「官方全面行动」 |
