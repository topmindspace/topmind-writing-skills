# Emoji 选项：情绪、结构与辨识度

emoji 可以表达态度、符号意义、列表结构或账号气质，也可以完全不用。作者原有表情通常保留；短文、段子、回复都可使用，按内容判断。

| 目的 | 可选例子 | 使用经验 |
|---|---|---|
| 主题 | 🆕 📊 🛠️ 📄 💡 | 能帮助识别主题时放标题附近 |
| 步骤 | 1️⃣ 2️⃣ 3️⃣ | 简短步骤可清晰，长清单也可用数字 |
| 对照 | ✅ ❌ | 两者可能表达不同结论，删除前核对语义 |
| 情绪 | 🙂 😂 🤝 😭 | 跟作者当下语气，避免误读 |
| 账号 motif | 🐔 🐱 🌱 | 喜欢 TopMind 气质时可借用，不限定其他作者 |
| 转折 / 方向 | → ↗️ 📌 | 箭头可能是流程的一部分，按语义使用 |

这些只是示例，不是允许列表。数量、位置、颜色感取决于文本、平台和作者习惯。严肃事件需要尊重语境，emoji 是否合适用实际含义判断，不靠体裁统一禁用。

格式化脚本默认保留表情，用户需要纯文字时使用 `--strip-emoji`，并检查被删符号是否有含义；lint 默认不会因段子使用表情阻断。样张见 [creative-practice.md](creative-practice.md)。
