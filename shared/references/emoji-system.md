# TopMind emoji 体系（账号人设 · 标题 · 列表）

> 交付与列表规约见 `x-delivery-contract.md`（必读必守）。
> 适用：`topmind-briefs`（短文）、`topmind-viral-posts`（段子）、`topmind-format`（格式化）的 X 稿，以及其他技能派生 X 纯文本稿时。
> 公众号稿正文不用人设点缀。列表符号的细则见 `x-post-format.md`，本文只定「用哪些、用几个、放哪里」。
> **唯一真源**：本文是 TopMind emoji 体系的唯一出处（仓库 `shared/references/emoji-system.md`，各技能目录里是逐字节副本）。各技能 SKILL.md 只引用本文，不另写一套 emoji 规则；要改体系只改这里。

## 一、三类 emoji，各管一件事

| 类别 | 作用 | 位置 | 每帖数量 |
|---|---|---|---|
| 人设点缀 | 账号辨识度：一只鸡、一只猫、一点植物 | 开头一行或结尾一行 | 0–2 个（开头 1 + 结尾 1） |
| 标题 emoji | 一眼看出这帖讲什么 | 标题行行首 | 0–1 个 |
| 列表符号 | 分点、步骤、对比 | 每条列表项行首 | 一套，见 `x-post-format.md` |

三类之外的情绪表情（😂 🤝 😭）每帖最多 1 个，放在钩子或吐槽那一句的句尾。

## 二、人设点缀（账号 motif）

主角是鸡和猫，配角是小动物和植物。同一帖只选一个主角，开头和结尾可以呼应（🐔 开头、🌱 收尾）。

| 角色 | emoji | 适合的语气 |
|---|---|---|
| 主角 · 鸡 | 🐔 🐣 🐥 | 日常、打卡、自嘲、冲粉 |
| 主角 · 猫 | 🐱 🐈 🐾 | 冷知识、观点、慢一点的分享 |
| 配角 · 小动物 | 🐰 🐶 🦊 🐻 | 互关、新人报到、轻松话题 |
| 配角 · 植物 | 🌱 🌿 🍀 🌸 🌼 🍃 | 收尾、祝福、成长、坚持 |

用法：

1. **开头**：放在第一行行尾，或单独一行（段子可以单独一行）。例：`说个冷知识 🐱`
2. **结尾**：放在最后一句行尾（话题标签之前）。例：`明天见 🌱`
3. **不进正文和列表**：正文中间、列表项里不放人设 emoji。
4. **严肃内容不放**：事故、伤亡、争议、监管处罚类帖子不用人设点缀，也不用情绪表情。
5. **不连用**：不写 🐔🐔🐔 或 🌸🌸；一个位置只放一个。

## 三、标题 emoji：跟着关键词走

标题 emoji 必须和标题的关键词或意思对得上；对不上就不放，不拿 🔥 🚀 凑数。

| 标题关键词 | emoji | 例 |
|---|---|---|
| 发布、上线、新版本 | 🆕 | 🆕 某模型 2.0 发布 |
| 数据、榜单、排名 | 📊 | 📊 编程榜单本周变化 |
| 速报、快讯、刚刚 | ⚡ | ⚡ 两家公司宣布合作 |
| 教程、上手、步骤 | 🛠️ | 🛠️ 三步装好本地模型 |
| 论文、研究、报告 | 📄 | 📄 一篇关于长上下文的新论文 |
| 模型、AI、智能体 | 🤖 | 🤖 智能体怎么接工具 |
| 代码、开发、开源 | 💻 / 🔓 | 🔓 权重开源了 |
| 图像、设计、生图 | 🎨 | 🎨 封面提示词更新 |
| 视频、直播 | 🎬 | 🎬 新视频模型试用 |
| 优惠、免费、价格 | 💰 / 🆓 | 🆓 限时免费一周 |
| 冷知识、技巧、提示 | 💡 | 💡 收益和互动权重的关系 |
| 观点、讨论、提问 | 💭 | 💭 长上下文还需要检索吗 |
| 注意、风险、限制 | ⚠️ | ⚠️ 新条款有一处变化 |
| 日期、活动、截止 | 📅 | 📅 报名周五截止 |

一个标题只放一个 emoji，放在行首，后面空一格。

## 四、只用 TopMind 的，不跟风

参考帖里常见的 🔥 😍 🚀 💥 开头、6–10 个话题标签、同一列表 🔸 🔹 混用，是别人的个人风格，TopMind 不照搬：

- 标题行首只放第三节对照表里的标题 emoji；对不上关键词就不放，不用 🔥 😍 🚀 凑热度。
- 账号辨识度只靠人设点缀（🐔 🐱 + 小动物 / 植物），放首尾。
- 信息密度高的长帖（分【小标题】的那种）可以完全不用 emoji，靠空行和【】小标题分层——这也是 TopMind 风格。
- 版式规律见 `x-layout-patterns.md`。

## 五、列表 emoji：统一、克制

- 默认 🔹（二级 ▫️），步骤 1️⃣ 2️⃣ 3️⃣，对比 ✅ / ❌ 成对，严肃内容用 • ▪。
- 一帖一套，不在同一层级混用；列表项里不再加第二个 emoji。
- 数据型列表可以用一次 📌 标最关键那一条，其余仍用 🔹。
- 列表前写一句「xx：」引导语（如「三处变化：」），引导语本身不加 emoji。

## 六、按体裁的配额

| 体裁 | 人设点缀 | 标题 emoji | 列表符号 | 情绪表情 |
|---|---|---|---|---|
| 段子（topmind-viral-posts / 转段子） | 0–2 | 不用（段子没有标题行） | 分点时一套（条目间空一行） | ≤1 |
| 短文（topmind-briefs / 格式化成短文） | 0–2 | 0–1 | 一套 | 0 |
| 严肃资讯 | 0 | 0–1（只用 ⚡ 📄 ⚠️ 📅） | • ▪ 或 🔹 | 0 |
| 长帖资讯（【小标题】分节） | 0–1（只放结尾） | 0–1 | 一套或不用 | 0 |

合计：一帖的点缀类 emoji（人设 + 标题 + 情绪）不超过 3 个，`lint_x_post.py` 超过 4 个会给 W8 警告。

## 七、示例（原创）

段子：

```text
说个冷知识 🐱

X 的创作者收益，看的不只是浏览量。

付费蓝V用户的互动，权重明显更高。

所以同样十万浏览，收益可能差很多。

难怪大家都在找蓝V互动😂

蓝V互关，评论区报到 🌱
```

短文：

```text
🆕 某编辑器 3.0 发布，三处变化 🐔

🔹 补全延迟降到 200ms 内（厂商口径）
🔹 支持多文件同时修改
🔹 免费版每月 50 次

来源：官方更新日志 https://example.com/changelog

#AI编程
```
