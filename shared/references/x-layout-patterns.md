# X 短帖版式选项

下面是起步骨架，顺序、条数和节拍可随内容改变。想看完成稿，读 [creative-practice.md](creative-practice.md)。

| 方向 | 一种展开方式 | 适合 |
|---|---|---|
| 快速信息 | 变化 → 关键条件 → 影响 | 新闻、版本更新 |
| 场景推荐 | 需求场景 → 怎么解决 → 谁适合 | 工具、方法 |
| 判断 | 观察 → 依据 → 取舍 | 评论、复盘 |
| 清单 | 主题 → 并列项 → 必要说明 | 盘点、备忘录 |
| 求证 | 已知线索 → 不能确定的点 → 具体问题 | 讨论、故障 |
| 反转 | 预期 → 行动 / 回答 → 意外结果 | 段子、对话 |
| 分节 | 主信息 → 小标题分区 → 结论或问题 | 信息较多的普通帖 |

分段以语义为界：一个意思一段、一句一行、紧凑对话都可以。长条目可留空行，关联紧密的条目可连续排。无需统一每段行数、列表条数和收尾标点。

混排保留准确专名，空格与标点以易读、一致为目标，不为一个空格重写全文。链接可放正文或另列，详见 [x-delivery-contract.md](x-delivery-contract.md)。话题标签可以省略，活动标签按任务用。表情看 [emoji-system.md](emoji-system.md)，不将 motif 当所有作者的身份。
