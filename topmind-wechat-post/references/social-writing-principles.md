# 社交写作经验：先扩大可用选择

这些经验帮助 agent 更好地理解内容和读者，供任务中选择使用。当前用户的明确要求优先，作者样本和实际参考作品帮助校准；不同体裁可以采用不同解法。

## 实际边界与创作偏好

| 层次 | 内容 | 如何使用 |
|---|---|---|
| 事实、授权与完整性 | 事实与引用准确、隐私、发布授权、已有文件可恢复、输出可用 | 明确核对；修复具体问题，不以风格分数替代 |
| 任务协议 | 只排版、特定尺寸、单源导出、指定文件结构 | 在当前任务采用时遵守，不外推成所有任务要求 |
| 创作经验 | 结论先行、口语、短句、留白、emoji、人物、图表 | 根据内容与读者选择，可混合、改造或另辟方向 |

默认中文，用户需要其他语言或保留原文时跟随任务。当前用户的风格要求优先于库中默认；单个案例或一轮修改意见只说明相应场景。

## 让经验给出方向

| 经验 | 为什么有用 | 也成立的其他选择 |
|---|---|---|
| 想清读者带走什么 | 帮助组织证据、删去分心内容 | 草稿探索、研究中写作也能帮助想清楚 |
| 重要信息前置 | 扫读者能快速进入主题 | 故事、悬念、场景可渐进展开 |
| 具体事实与场景 | 让判断可理解、可核对 | 抽象总结、类比和情绪可承接更大意义 |
| 形式跟内容走 | 对比、流程、趋势可更直观 | 简单问题一段话就够，图表不设配额 |
| 清楚自然 | 减少读者理解成本 | 专业读者需要精确术语，文学表达需要节奏 |
| 看原文、原图与真参考 | 获取语气、上下文与证据 | 原图不是唯一选择，自制图可承载新综合 |
| 尊重读者已有知识 | 调整背景与解释长度 | 新读者或复杂论证仍需要铺垫与必要重复 |
| 事实强度与语气一致 | 保持可信度 | 有出处的强判断、批评与热情都可用 |

“信息”也包括情绪、画面、节奏、关系和理解路径。删一句后事实没少，不代表那句一定多余；看它是否帮助当前读者。

## 看样张、尝试、再判断

写法探索可从 [creative-practice.md](creative-practice.md) 开始：有实际样张、如何看参考、怎样比较候选。简单任务直接完成，复杂或审美不确定的任务用小样降低试错成本。候选的意义是打开方向，不是增加固定交付数量或让用户反复审批。

结构看 [information-design.md](information-design.md)，措辞看各写作技能随包的口吻经验，定位具体问题再查相应诊断表。按需阅读，不默认把整套参考加载完。脚本识别可核对现象，质量仍由事实、读者效果和作者判断共同决定。

## 扩大选择的知识入口

需要新的写法、视觉关系或具体示例时，看 [知识使用与增补](knowledge-library.md)。先查摘要，再读相关卡片；参考帮助打开方向，不把经验升级为统一禁令。排版、保真和工具协议在采用对应链路时继续遵守。
