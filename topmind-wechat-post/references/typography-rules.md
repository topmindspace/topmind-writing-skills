# 公众号排版经验

只排版时保留措辞与事实；用户授权改稿时可按目标调整结构和节奏。必要归因、范围和近似值留在正文。

| 目的 | 可选处理 |
|---|---|
| 扫读 | 短段、信息前置、清楚的小标题 |
| 完整论证 | 较长段落、过渡、例子与反例 |
| 并列与对照 | 列表、表格、分行、卡片 |
| 情绪与故事 | 留白、长短段交替、场景铺垫 |
| 图文 | 图邻近相关文字，保留来源和必要概述 |

110 字段落、70 字列表项、45 字句子是旧提示线，实际可读时无需为了过线拆散。结尾可停在事实、判断、问题或邀请；表情和小标题编号按作者习惯选择。

## 转换链路

使用本包单源导出时以标准 Markdown 为起点；`:::`、callout、wikilink 在不同渲染器支持不同，使用前看当前工具。旧交付包仍兼容部分容器，新包检查可能报格式问题，这是工具协议而非审美禁令。

`md2wechat.py` 原样保留手写编号；自动编号设置见 `element-spec.md`，注意避免重复。图片与图注、表格和代码块实际导出后看预览，平台复制结果要验证。

16px、1.75 行距、22px 段间距可作主题起点，颜色、圆角、衬条与字体按内容调整；主题字段与内联样式要求见 `wechat-constraints.md`。

```bash
python3 scripts/lint-wechat.py --input <文章名>.md
# 需要自动调整空格等时再加 --fix，先保留恢复版本
```

缺图、实际截断等问题修复；段长和审美提示回到上下文判断，不要求清零。
