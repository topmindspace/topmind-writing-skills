# 创作系统与发布架构说明

本页汇总平台封面规范、创作四层架构、8 大技能演进与按需知识包机制。发行版本以根 `package.json`、各技能元数据和 [CHANGELOG](../CHANGELOG.md) 为准；发布状态以 GitHub Release 与 npm 实际状态为准。

## 一、核心设计原则与边界

事实保真、排版兼容与工具协议是工程底座；句式、口吻、标点力气活、字高、配色、篇幅与视觉流派均为服务表达的灵活选项，不设机械死门禁。真正不可逾越的硬边界仅四条：
1. **不代编事实、引语和第一人称「我」**；
2. **不过度断言，但保留作者个人口吻与真实褒贬**；
3. **只出稿与导出产物，不擅自外发**；
4. **跨平台习惯按场景隔离**（如 X 短帖默认无外链/无话题，公众号与长文正常保留链接与命令）。

## 二、封面体系与全平台尺寸适配

`topmind-cover`（`0.5.2`）构建了完整的高点击率封面设计体系：
- **5 大现代流派（22 款风格）**：Swiss 社论与数据反差、原文证据高亮拼贴、Bento 模块化信息卡片、微距触感材质与工业静物、手绘白板与批注洞察。
- **16 种构图动线（`X1`–`X16`）与 24 组跨媒介配方（`C01`–`C24`）**：聚焦第一眼视觉焦点与移动端缩略图 0.5 秒可读性。
- **双路径提示词体系**：区分 **Path A（原生文字直出，适合渲染 2–6 字短词/数字/印章）** 与 **Path B（纯净负空间留白底图 + `title-engine.py` 精准叠字）**。
- **全平台真实尺寸与安全区裁切**：[平台封面参考](../shared/references/platform-cover-specs.md) 与 `crop-cover.py` 支持公众号头条（`900×383` `2.35:1` + `900×900` `1:1`）、公众号图片消息/小绿书与小红书（`1080×1440` `3:4`）、X Article（`1500×600` `5:2`）、X 普通帖（`1200×675` `16:9`）、抖音/视频号（`1080×1920` `9:16`）以及横版双尺寸（`landscape-pair` `16:9 ⇄ 4:3`）与竖版双尺寸（`vertical-pair` `9:16 ⇄ 3:4`）独立派生。

## 四、可扩展按需知识包（`v1.1.0`，45 张卡）

- 知识真源位于 `shared/knowledge/`（共 45 张卡片），涵盖去 AI 味机制、邻座身位、价值前置、新闻转短帖、装傻真提问、向改稿学习、工具推荐与评测结构、视觉证据密度以及 12 张现代封面卡片。
- 支持通过 `python3 scripts/knowledge.py search/show/add` 按需检索或随时扩展新经验，并通过 `npm run sync:shared` 同步至全部 8 个技能。详见 [知识包说明](./knowledge-packs.md)。
