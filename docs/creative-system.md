# 创作系统与 v0.9.0 发布审查

日期：2026-10-27。本页合并平台封面审计、整改方案与执行记录，提供一个维护入口。发行版本以根 package.json、各技能元数据和 [CHANGELOG](../CHANGELOG.md) 为准；发布结果以 GitHub Release 与 npm 实际状态为准。

## 设计与边界

事实、排版、保真和工具协议继续作为约束；字体、字高、颜色、装饰、角色、篇幅与修辞按任务选择。简单任务直接完成，需要探索时比较有实质差异的方案，不强制多稿、配图配额或自评分。知识与参考不能扩大目标、联网、修改、发布或长期记忆权限。

## 封面与图文

cover 0.5.0 整理了 22 个可变风格入口、16 类构图关系、24 个组合方向、12 份完整教学简报，扩展编辑、字体、摄影、文化、材料、抽象和场景方向。标题工具默认建议，结构错误仍失败；长标题、繁体和编码范围不作默认失败条件。

[交互图册](../topmind-cover/assets/examples/creative-atlas.html) 提供 8 组横竖排版研究，另有 4 份新标题 spec。历史 PNG 保留主样张与变体，删除 26 张可再生的公众号尺寸副本，减少约 5.4 MB 的重复资产；生成命令和说明同步更新。

小红书图文、抖音普通图文 / 商城 / 商品主图、公众号普通文章 / 图片消息、X Article / 主页 banner 分开处理。[平台参考](../shared/references/platform-cover-specs.md) 区分官方建议、本包预设、第三方资料和待实测项，不把旧商城条款或固定遮挡比例当成通用规则。宽图、方图各自从原图等比裁切，支持裁切位置和 EXIF，并拒绝覆盖原图或其硬链接。

## 按需知识与维护

37 张卡包括 35 张原创教学示例、2 条本次有依据的技术 / 局部视觉经验；每卡包含范围、例外、来源、证据性质和状态。检索先返回摘要，再读选中的正文；无脚本宿主可使用导航。候选默认不检索，退役项退出默认检索；新增仅写明确指定的私有包，不覆盖、不自动激活，失败回滚并拒绝并发写入。

共享真源及各技能的副本用于独立安装。新卡随目录分发，无需重写所有入口；更新后校验完整性并同步。增补与贡献见 [知识包说明](./knowledge-packs.md)。

## 验证范围

全仓技能门禁覆盖排版、保真、异常输入、路径与文件输出；新增知识检索 / 状态 / 增补 / 回滚、标题自由与结构、裁切、打包和目录分发回归。494 份共享副本保持一致，8 个入口通过规范校验；126 条评测用例进行结构与路由检查，不等于执行模型盲评。

HTML 图册横竖版已实际渲染查看，浏览器验证比例切换、390px 布局与标题边界；局部辅助字问题已修正。本地安装保持 8 个技能及 24 个共享入口一致。

这些检查证明工具、文档、分发与已查看样张的状态。平台后台未做真实发布预览，生成模型效果与作者偏好仍需实际任务反馈；新经验保留范围与证据，不能自动变成统一禁令。
