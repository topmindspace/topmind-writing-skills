# X 纯文本帖排版规则（列表 · 缩进 · 换行）

> 适用：`topmind-briefs` 与 `topmind-viral-posts` 的 X 稿，以及 `topmind-x-article` 的 `X发布稿.txt`（纯文本兜底）；`topmind-wechat-post` 在派生 X 稿时也按本文执行。
> 公众号稿不受影响，继续用 Markdown 标题、加粗和列表。
> X 长文的富文本 HTML（`X长文.html`）走 X Article 编辑器的原生列表，以 `x-html-format.md` 为准。

## 为什么要单独排版

X 的普通帖子不渲染 Markdown：`-`、`*`、`1.` 会原样显示成符号，`#` 标题和 `**加粗**` 会把星号与井号一起发出去。
所以 X 稿里没有 Markdown 列表、标题和加粗，列表用 emoji 项目符号，层次靠换行和缩进。

## 推荐符号集

| 用途 | 符号 | 说明 |
|---|---|---|
| 并列要点（默认） | 🔹 | 一级条目的首选，中性、不抢戏 |
| 二级条目 | ▫️ | 与一级配合，缩进两个空格 |
| 步骤 / 先后顺序 | 1️⃣ 2️⃣ 3️⃣ … | 最多 9 条；也可用 ① ② ③（最多 20 条）；更多条目拆成两帖 |
| 结论 / 已确认 | ✅ | 结论、已完成、可用 |
| 对比的另一面 | ❌ | 与 ✅ 成对出现，不单独用 |
| 重点 / 数据 | 📌 📊 | 一帖里最关键的一两条 |
| 提示 / 注意 | 💡 ⚠️ | 小技巧用 💡，需要留意的限制用 ⚠️ |
| 价格 / 福利 | 💰 🆓 | 降价、限免、优惠类 |
| 纯文本替代 | • ▪ → | 不想用 emoji、或语气偏严肃时使用 |

## 使用规则

1. **同帖风格一致**：同一层级用同一个符号。对比用的 ✅ / ❌ 是唯一允许同层混用的组合。
2. **每条一行**：一条一个意思，尽量一行读完（中文约 30 字内），不手动折行。
3. **层级最多两层**：二级条目前加两个半角空格，再接 ▫️ 或 •。X 若吞掉行首空格，改用全角空格（`　`）；仍对不齐就压成一层。发布前在 X 预览里看一眼缩进。
4. **数量适中**：一个列表 3–5 条，不超过 7 条；只有 2 条时直接写成两行短句，不必加符号。
5. **不滥用 emoji**：列表符号之外，点缀表情每帖 1–3 个；严肃资讯、事故、争议类帖子只用 • ▪ 或 🔹，不用 ✅ 🎉 之类的庆祝符号。
6. **语气适配**：干货和数据用 🔹 📌 📊；轻松段子可以多一点表情，但列表符号仍保持统一；英文区帖子也可以用 • 或 → 代替 emoji。
7. **不用 Markdown 语法**：不写 `- ` `* ` `1. ` 列表、`#` 标题、`**加粗**`、`> 引用`、`[文字](链接)`、表格。需要强调就换行前置，或用「」；链接直接贴 URL。
8. **话题标签放最后**：列表之后空一行，单独一行写 `#标签`，不插进列表中间。

## 公众号稿 → X 稿的派生

同一选题的两个版本，**只允许排版差异，内容一致**：数字、结论、条数、顺序、来源都不变。

| 公众号稿（Markdown） | X 稿（纯文本） |
|---|---|
| `- 要点` | `🔹 要点` |
| `  - 子要点`（缩进） | `  ▫️ 子要点` |
| `1. 步骤` | `1️⃣ 步骤` |
| `## 小标题` | 单独一行文字（必要时加 📌 ） |
| `**重点**` | 去掉星号；需要强调就放到行首或用「」 |
| `> 引用` | 去掉 `>`，引文用「」括起来并写明出处 |
| `[文字](url)` | `文字 url`，或只贴 url |
| 表格 | 拆成“项：值”的列表行 |

## 前后对照（示例为原创）

公众号稿里的写法：

```markdown
## 这次更新的三个变化

- 响应时间：中位数从 2.4 秒降到 1.1 秒
- 价格：输入每百万 token 降 30%
- 限制：单次上下文仍是 128K
  - 超出部分需要分段处理
```

直接发到 X 会变成一堆符号和星号。X 稿写成：

```text
这次更新有三个变化：

🔹 响应时间：中位数从 2.4 秒降到 1.1 秒
🔹 价格：输入每百万 token 降 30%
🔹 限制：单次上下文仍是 128K
  ▫️ 超出部分需要分段处理

来源：官方更新日志
```

步骤型写法：

```text
上手只要三步：

1️⃣ 装好命令行工具
2️⃣ 登录并选一个工作区
3️⃣ 把示例文件拖进去跑一遍
```

## 自检与工具

- 清单：无 Markdown 列表 / 标题 / 加粗；同层符号一致；层级 ≤2；列表 ≤7 条；话题标签在末行。
- 工具：`python3 scripts/lint_x_post.py X稿.txt` 检查；加 `--fix` 把 Markdown 列表、标题、加粗等自动改成 X 写法（输出到 `--out`，不覆盖原文件）。
  文件里有多条帖子时，用单独一行 `---` 分隔；长文兜底稿（`X发布稿.txt`）加 `--long`。
