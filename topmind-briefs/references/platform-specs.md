# 平台规格 · 公众号 vs X

同一件事，写两版。内容一致，篇幅和格式按平台调整。

## X 版

- 长度：280 字符内（一条）。超了就拆 thread，最多 3 条，每条都按单帖规格写（首条最重要，时间线上只显示首条和首图）。
- 语言：默认中文。英文是例外：只有受众明确是英文区、或素材本身就是英文速报时才用英文（参考 @ArtificialAnlys 风格）；中文参考 @arena 风格。
- 图片：1–4 张，首图最重要（时间线上只显示首图）。
- 格式：纯文本 + 图片。不用 Markdown 标题（X 不渲染）。
- **列表符号**：X 不渲染 Markdown，列表不用 `- ` / `1.` 这种 Markdown 语法，
  用纯文本符号开头：`• ` 或 `▪ `，中文帖也可用 emoji（📌 📊 💡）开头。
  Markdown 列表语法只用在公众号版。
- 结尾：来源链接（缩短）。不加 hashtag，除非是榜单/活动官方 tag。
- 交付：`scripts/md2x-html.py` 生成一键复制 HTML（`--images-from 公众号短文.md`
  按公众号稿的文档顺序派生 [图N] 配图，禁止手工拼 `--images`；无封面），另附纯文本版方便直接粘贴。
- 示例结构（注意列表符号是纯文本的 `•`，不是 Markdown）：
  ```
  [结论一句话]

  • 数据 1
  • 数据 2

  [图1：榜单截图]

  来源：链接
  ```

## 公众号版

- 长度：约 300–800 字（与 SKILL.md 同一口径）。比 X 版多 1–2 句背景（"这是什么榜单""为什么重要"）。
- 标题：15 字内，带数字或结论。"[模型] 登顶 [榜单]：[分数]"。
- 图片：1–4 张，base64 内嵌（`scripts/md2wechat.py --embed-images`）。
- 格式：走 `topmind-wechat-post` 链路。标题 + 导语（一句话） + 列表 + 图 + 来源。
- 不写"前言导读""小结"这种长文结构——短文不需要。
- 交付：`scripts/md2wechat.py` 直接出 HTML（含「复制正文」按钮），原文件即发布用文件，不二次生成。
- 示例结构：
  ```markdown
  # [标题]

  > [一句话导语]

  [结论段，2–3 句]

  - 数据 1
  - 数据 2
  - 数据 3

  ![图注](图)

  来源：[链接]
  ```

## 对照表

| | X 版 | 公众号版 |
|---|---|---|
| 长度 | 每条 ≤280 字符（thread 最多 3 条） | 约 300–800 字 |
| 标题 | 无（首句即标题） | 15 字内 |
| 背景 | 不写 | 1–2 句 |
| 图片 | 1–4 张 | 1–4 张（内嵌） |
| 来源 | 链接 | 链接 |
| 语气 | 更短更冲 | 稍完整 |
