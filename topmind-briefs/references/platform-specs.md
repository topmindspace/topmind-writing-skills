# 平台规格 · 公众号 vs X

同一件事，写两版。内容一致，篇幅和格式按平台调整。

## X 版

- 长度：280 字符内（一条）。超了就拆 thread，最多 3 条，每条都按单帖规格写（首条最重要，时间线上只显示首条和首图）。
- 语言：默认中文。英文是例外：只有受众明确是英文区、或素材本身就是英文速报时才用英文（沿用数据榜单型的英文起手）；中文写作沿用榜单速报型的结构。
- 图片：1–4 张，首图最重要（时间线上只显示首图）。
- 格式：纯文本 + 图片。不用 Markdown 标题、加粗和列表（X 不渲染）。
- **列表符号**：X 版一律用 emoji 项目符号，不用 `- ` / `1.` 这种 Markdown 语法：
  并列要点 🔹（二级 ▫️，缩进两格），步骤 1️⃣ 2️⃣ 3️⃣，结论/对比 ✅ / ❌，重点数据 📌 📊，
  严肃资讯也可用纯文本 • ▪。同帖风格一致，每条一行，最多两层，一个列表 3–5 条、不超过 7 条。
  完整规则见 [x-post-format.md](x-post-format.md)。Markdown 列表只用在公众号版。
- **公众号稿 → X 稿**：X 稿由公众号稿派生，列表从 Markdown 改成 emoji 项目符号，只允许排版差异，
  数字、结论、条数、顺序一致。
- 结尾：来源链接（缩短），之后空一行，单独一行写话题标签。
- **话题标签（hashtag）**：每条 0–2 个，最多 3 个；另给 1 个备选。
  - 取法：榜单/基准/发布类用榜单名或产品通用名，再加 1 个领域词（如 `#AI`）；论文类用主题词；机制类用技术名词。
  - 位置：放在最后一行，不夹在正文或列表中间。
  - 中英文：中文帖用中文话题，英文帖用英文驼峰（如 `#PromptCaching`），不加空格和标点。
  - 不堆砌：不叠同义词，不蹭无关热点；不用诱导互动、刷量或敏感话题的标签；传闻类不用会让人以为已证实的标签。
  - 公众号稿不加话题标签。
- 交付：`scripts/md2x-html.py` 生成一键复制 HTML（`--images-from 公众号短文.md`
  按公众号稿的文档顺序派生 [图N] 配图，禁止手工拼 `--images`；无封面），另附纯文本版方便直接粘贴；
  交付前跑 `python3 scripts/lint_x_post.py X短文.md`（没有 Markdown 列表/标题/加粗，话题标签在末行）。
- 示例结构（列表是 emoji 项目符号，不是 Markdown）：
  ```
  [结论一句]

  🔹 数据 1
  🔹 数据 2

  [图1：榜单截图]

  来源：链接

  #话题1 #话题2
  ```

## 公众号版

- 长度：约 300–800 字（与 SKILL.md 同一口径）。比 X 版多 1–2 句背景（"这是什么榜单""为什么重要"）。
- 标题：15 字内，带数字或结论。"[模型] 登顶 [榜单]：[分数]"。
- 图片：1–4 张，base64 内嵌（`scripts/md2wechat.py --embed-images`）。
- 格式：走 `topmind-wechat-post` 链路。标题 + 导语（一句） + 列表 + 图 + 来源。
- 不写"前言导读""小结"这种长文结构——短文不需要。
- 交付：`scripts/md2wechat.py` 直接出 HTML（含「复制正文」按钮），原文件即发布用文件，不二次生成。
- 示例结构：
  ```markdown
  # [标题]

  > [导语一句]

  [结论段，2–3 句]

  - 数据 1
  - 数据 2
  - 数据 3

  ![图注](图)

  来源：[链接]
  ```

## 对照表

| | X 版 | 公众号版 |
|---|---|---|
| 长度 | 每条 ≤280 字符（thread 最多 3 条） | 约 300–800 字 |
| 标题 | 无（首句即标题） | 15 字内 |
| 背景 | 不写 | 1–2 句 |
| 图片 | 1–4 张 | 1–4 张（内嵌） |
| 来源 | 链接 | 链接 |
| 列表 | emoji 项目符号（🔹 / 1️⃣） | Markdown 列表 |
| 话题标签 | 0–2 个，末行 | 不加 |
| 语气 | 更短更冲 | 稍完整 |
