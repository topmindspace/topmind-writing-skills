# X 短帖版式与按稿型选策略

短帖不是只有一种写法。动笔前先判断这条内容**靠什么让读者停下来、拿走什么**，再选对应的版式与开口策略。想看完成稿和更多体裁对照，读 [creative-practice.md](creative-practice.md) 与 [knowledge-library.md](knowledge-library.md)。

## 一、六种高频短帖版式（起步骨架，可自由组合）

| 稿型方向 | 开口与展开方式 | 核心发力点 |
|---|---|---|
| **1. 经验技巧 / 提示词干货** | 结果或反差数字直接做第一句问句 → 放上能直接复制的原件（提示词/命令）+ 一句中文大意 → 谁适合用 + **什么时候别用** | 价值前置 + 可复用原件 + 清醒边界（收藏驱动） |
| **2. 新闻发版 / 规则变化** | 最意外的数字、体感换算或带态度的定性放第一句 → 紧接对普通用户的实际影响与操作建议（`1）2）`） | 砍掉门槛与花絮，参数译成日常体感 |
| **3. 意外细节 + 顺手算账** | 「等一下，……？？？」抛反常细节 → 第一反应愣一下 → 换算成会员费、工时或日常开销 → 点到为止 `……` | 算账反差 + 七分留白 |
| **4. 装傻提问 / 真困惑互动** | 切身痛点或两难处境 + 一句话就能接的真问题 + 后半句忍住不说完 | 邻座身位，留出评论区接话空间 |
| **5. 观察反差 / 场面段子** | 具体画面、一进一出动作对照（「一个进门，一个下楼」）或群聊拟人对话 → 最后半句抖包袱即停 | 画面感代替行业评论，绝不解释笑点 |
| **6. 引用转发 / 评论回复** | 引用：去掉原帖信息后亮出自己的一句判断或使用切口；回复：一句话接话、给态度或追问 | 不复述原帖、回帖不套类比、不端架子 |

## 二、分段与细节处理

- **语义分段**：一个意思一段，段间空一行；关联紧密的 `1）2）` 列表连续排，不句句空行。
- **具体点名**：把受众叫具体（如「20 美元档的兄弟」「做评测跑榜单的兄弟们」），少用空泛的「所有人」「朋友们」。
- **链接与标签**：X 短帖默认正文不放 URL 和话题标签，来源链接放块外另附（见 [x-delivery-contract.md](x-delivery-contract.md)）；表情按作者习惯克制点缀（见 [emoji-system.md](emoji-system.md)）。
