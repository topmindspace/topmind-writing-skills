## 例 4：机制讲解型（步骤）

```text
💡 提示缓存怎么帮你省 API 钱

每次请求都在为同一段长前缀重复付费，缓存把这段前缀存下来，重复调用就不再全价计费。

1️⃣ 把固定不变的内容放在最前面
2️⃣ 把会变的部分放在最后
3️⃣ 在用量报表里看缓存命中率

简单来说：前缀命中缓存就便宜，尾部照常计费。

来源：官方文档 https://example.com/docs/caching

#提示缓存
```

## 反例

- 「众所周知，AI 发展日新月异……值得一提的是……」→ 铺垫三段、结论藏在最后、没有数字。
- 「大幅提升」「表现优异」→ 没有数据的形容词，换成数字或删掉。
- 正文块里写 `[图：柱状图]`、`配图：`、`话题标签建议：` → 这些都在正文块外另列。
