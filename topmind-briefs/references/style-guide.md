# 风格指南 · 干货短文

目标：读者划过去，3 秒内抓住那个数字/结论，心想"这篇有料"。

## 三原则

**短**：一件事讲完就停。X 版每条 280 字符内（超了拆 thread，最多 3 条）；公众号版约 300–800 字
（与 SKILL.md、`platform-specs.md` 同一口径）。
**干**：每个字都承载信息。删掉所有"众所周知""值得一提的是"。
**准**：数字有来源，判断有依据。不确定的写"据 X 报道"，不编。

## 开头：四种起手

- 数据榜单型："[反直觉判断一句话]。On [基准], [最扎眼数字]。"
- 榜单速报型："Big news: [模型] just landed #1 in [榜单] with [分数]!"
- 论文解读型："‼️[加粗判断]: [一句话]! Introducing [X]"
- 机制讲解型："[X], clearly explained! [痛点一句话]"

## 正文：列表 > 段落

能用列表就不用段落。X 版用纯文本符号（`• ` / `▪ ` / emoji），
不要用 Markdown 的 `- `（X 不渲染，见 platform-specs.md）。公众号版用 Markdown 列表。

X 版参考格式：

```
[结论一句话]

• 关键数据 1
• 关键数据 2
• 关键数据 3

[图]

来源：[链接]
```

## 禁止清单

- 禁止"首先、其次、最后""总而言之""值得一提的是""值得注意的是"
- 禁止"赋能""抓手""闭环""底层逻辑"
- 禁止铺垫三段再说结论
- 禁止没有数据的形容词："大幅提升""显著改善"（改成具体数字）
- 禁止感叹号连用
- 禁止"家人们""老铁"式直播腔
- 禁止正确的废话

## 鼓励

- 数字代替形容词："快 3 倍"不说"大幅提升"
- 对比代替孤立数字："58 分，比 Opus 5.5 高 2 分"不说"58 分，很高"
- 一句话判断收尾（可选）："这意味着 [对读者的意义]。"——只写一句，不展开
- 来源链接放在最后，不打断阅读
- 允许短句和碎片化断句，像人说话一样写，不追求完整长句（去AI味）
- 标题可以冲，但正文必须有真东西支撑，不做空转标题党

## 自检三问

1. 删掉一半字，核心结论还在吗？（在→删）
2. 每个数字都能说出来源吗？（不能→删或补来源）
3. 不看图，文字本身成立吗？不看文字，图本身有信息吗？（都成立→图和文各司其职）
