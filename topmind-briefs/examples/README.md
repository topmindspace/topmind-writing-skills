# topmind-briefs 原创示例（高价值干货短文）

本目录收录三组原创教学示例（产品、城市与数字均为虚构演示，展示不同平台与题材的短文结构）：

- [`01-X短文-编辑器发布.txt`](./01-X短文-编辑器发布.txt) + [`01-链接与配图.txt`](./01-链接与配图.txt)：新品与工具速递，示范**一手实用价值优先**（硬件门槛、实测变化、开启方式）及正文与链接分离的可选交付模式。
- [`02-X短文-城市公园.txt`](./02-X短文-城市公园.txt)：资讯盘点短文，结论先行 + `·` 列表提炼对读者真正有用的细节。
- [`03-公众号短文-番茄工作法.md`](./03-公众号短文-番茄工作法.md)：方法论短文，不仅讲规则，更讲清适用边界与实操改法。

**短文核心心法**：首行直给核心结论或最值得关心的变化；聚焦读者能直接用上的干货（怎么用、成本多少、有什么坑）；不堆砌播报套话，讲完即停。
