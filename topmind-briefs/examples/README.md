# topmind-briefs 原创示例（短文）

全部为我们自己写的示例，产品、城市和数字都是虚构演示，不当作事实引用。

- [`01-X短文-编辑器发布.txt`](./01-X短文-编辑器发布.txt) + [`01-链接与配图.txt`](./01-链接与配图.txt)：新品速递，正文与链接、配图分开交付
- [`02-X短文-城市公园.txt`](./02-X短文-城市公园.txt)：数据型短文，用「·」分点，人设 emoji 只在结尾（单独一行）
- [`03-公众号短文-番茄工作法.md`](./03-公众号短文-番茄工作法.md)：公众号 Markdown 短文

X 短文要点：首行一句话题陈述；段落合理；事实讲完就停；emoji 可选，只用 TopMind 体系（人设 emoji 只放开头或结尾）；分点默认「·」；末行默认 2 个话题标签；正文不放网址和来源行，链接与图片另列。
