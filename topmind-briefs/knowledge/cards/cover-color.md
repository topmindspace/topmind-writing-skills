# 封面色彩张力：克制配比与高对比可读

封面的高级感往往来自**克制的色相数量 + 强烈的明度反差**。在手机信息流里，模糊暧昧的中间调最容易被划过去。

## 六组经过实战检验的高辨识度色板
1. **瑞士编辑白橙**：暖纸白 `#F4F2ED` + 墨黑 `#111111` + 国际橙 `#FF4F00`（测评、榜单、方法论首选）
2. **刊物波尔多红**：骨白 `#FAF8F5` + 炭黑 `#1E1E1C` + 深酒红 `#6E1D2A`（深度特稿、行业评论）
3. **硬核暗黑翠绿**：近黑 `#0A0D14` + 银白 `#F8FAFC` + 信号绿 `#10B981`（AI 工具、工程架构、安全）
4. **日光档案绿米**：奶油米 `#F5EFE0` + 深松绿 `#1B4332` + 琥珀黄 `#D97706`（知识整理、人文随笔）
5. **高光证据黄黑**：深石板灰 `#1E293B` + 纯白 `#FFFFFF` + 荧光黄 `#FACC15`（论文扒料、源码复盘）
6. **清透蓝白网格**：雾灰蓝 `#F1F5F9` + 深海蓝 `#0F172A` + 钴蓝 `#1D4ED8`（Bento 信息卡、教程指南）

## 缩略图文字可读性铁律
当文字跨过背景时，不要靠“给文字加一圈脏兮兮的发光”来救场——直接**换用干净负空间、加深/提亮局部底色，或垫一块利落的实色衬条**。
