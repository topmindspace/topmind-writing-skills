# 图源与视觉材料：证据、解释、表达

先判断图的任务：证明事实、解释结构、展示作品、营造氛围，还是根本无需图。找图、查资料、写稿可交替进行，不因缺一张装饰图挡住文字任务。

| 任务 | 合适材料 | 核对重点 |
|---|---|---|
| 事实与产品行为 | 官方原图、论文图、原帖、实际截图 | 日期、范围、上下文、处理痕迹 |
| 比较与综合 | 自制图、数据图、表、拼版 | 数据来源、量纲、误差、是否误导 |
| 机制与判断 | 示意图、架构图、流程 | 标“示意 / 自制”，分清推断与实证 |
| 氛围与创作 | 摄影、插画、抽象图、文字封面 | 贴题、可用权利、与事实图区分 |

原图擅长保留证据；自制图擅长重新组织信息，不必等所有外图都失败才做。生成图可作示意或创作素材，不冒充真实截图、实测结果或数据来源。使用官方素材也需留意许可和上下文。

有用户参考或作品时实际打开看：布局、读序、尺度、取景，见 [creative-practice.md](creative-practice.md)。图与正文相互支持，必要时保留文字概述关键数字，照顾扫读和无障碍阅读。

长文或数据任务可在作者目录记来源：文件、URL、读取与事件日期、处理方式、数据口径。公共引用可以公开，私人素材、未发布稿、身份信息按授权处理；不把作者私有文件混进技能包。

导出后实际看图文顺序、内容对应与裁切。压缩 / 重编码文件可能不同字节，按源图映射、视觉内容与顺序核对；同编码无变换场景再用逐字节比对。

用户要图时继续完成授权任务，文字任务图无益时直接交稿；需要关键信息而无法合理推断时再询问。
