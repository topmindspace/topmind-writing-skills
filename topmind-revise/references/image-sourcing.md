# image-sourcing.md · 原图优先（写稿前就找图）

> 适用：topmind-briefs / topmind-viral-posts / topmind-x-article / topmind-wechat-post / topmind-revise。
> 顺序固定：**先找原图、记来源，再写字**。写完再找图，文字会把图该说的话说一遍。

## 一、找图顺序

1. **官方**：公告页、产品页、更新日志、官方帖子、发布会截图、官方文书（判决、诉状、监管文件）、论文原图。
2. **原帖**：当事人原帖截图（用平台官方嵌入渲染后截图，保留时间与互动数），不用转述帖。
3. **第三方原图**：数据平台、榜单、研究机构图表（注意许可，能链回原页）。
4. **自制图（兜底）**：只在前三类都找不到、而数据有出处时用。

## 二、自制图规则

- 图内或图注写明「自制」和数据来源，例如「自制，数据：xx 官方 2026-09」。
- 公众号稿 / X长文.md 的图片行写成 `![自制，数据：xx](images/NN-xx.png)`；`lint_x_post.py --md` / `--long` 会对没标清的自制图报 W18。
- 不用 AI 生成的图冒充原图或数据图；示意图标「示意」。

## 三、私有信源清单（不进公开仓库）

每篇在**发布包**（用户工作区，不在本仓库）里维护 `素材来源.md`：

| 列 | 内容 |
|---|---|
| 图号 | 与正文 `[图N]` 一致 |
| 文件 | `images/NN-xx.png` |
| 类型 | 官方 / 原帖 / 第三方 / 自制 |
| 来源 | URL 与读取日期；原帖写发布时间（注明时区） |
| 处理 | 裁剪、拼版、加框等改动 |

- 承重事实也记在同一份清单里：来源、发布时间、厂商口径 / 传言标注、未能核实的条目。
- 清单只给作者核对用；公开仓库、示例、模板里不写具体站点、账号或人名。

## 四、正文里的来源行

- 统一写「来源：」+ 出处 + 时间，例如「来源：某项目官方仓库，截至 10 月 15 日」；不复述图的内容（不写「增长曲线」「趋势图」）。
- 两种都行：每张图下面一行来源，或者每图不写、文末统一「参考来源」。
- 简单时间线只放图和来源；图里有值得点出的，图前加一句点出来；不写「如图所示」（`core-voice.md` V14、V15）。
- 短文正文不放来源行，链接和来源另发。

## 五、检查

- [ ] 每张图都能在 `素材来源.md` 找到一行来源
- [ ] 自制图都标了「自制」和数据来源
- [ ] 图紧跟它证明的那段文字；正文不复述图里的数字，来源行不描述图的内容
- [ ] 嵌入后逐张核对图序（HTML 解码比对，或打开预览逐张看）
