# 措辞与口吻：场景经验索引

本库默认写得清楚自然，但没有唯一正确的声音。用户当前要求、作者样本、读者和体裁决定具体写法。[creative-practice.md](creative-practice.md) 有同素材不同方向的完整样张，可先看成品，再选择写法。

V 编号保留用于旧脚本定位；它们是经验索引，不是逐条合规清单。一个词、句式或标点本身不能证明质量好坏。

## 选择一种贴合内容的声音

- 新闻可以简洁直给，也可以从使用场景进入；必要归因留在正文。
- 评论可以鲜明、有情绪，也可以谨慎推演；强度由证据支撑。
- 教程可以直接给操作，也可以解释原因；取决于读者是否需要。
- 随笔与故事可保留铺垫、重复、意象和长句，观察它们有没有推进体验。
- 段子可干脆也可铺垫，对话、动作、问句、emoji 都可承担节奏。
- 改稿先理解作者要实现什么，再决定删、加、换结构还是保留。

## 场景索引 V01–V40

| 编号 | 经验与可选写法 | 判断时留意 |
|---|---|---|
| V01 标题 | 直陈、问句、场景、反思、系列名都可 | 主题可辨、定性准确、期待与正文相符 |
| V02 副标题 | 补范围、读者收益或与主标题不同的层次 | 是否增加理解，而非换句话重复 |
| V03 封面文字 | 主题词、判断、情绪短语或大数字 | 看实际缩略图和文章主题，不强迫每次直给名词 |
| V04 摘要 | 概括主张、关键事实、一个问题 | 让读者知道值不值得读 |
| V05 开头 | 事实、场景、真实疑问、情绪或故事 | 入口能否带读者进入当前内容；不设统一字数 |
| V06 小标题 | 结论式、问题式、叙事式、编号或不编号 | 读序清楚，编号一致不重号 |
| V07 过渡 | 直接进入下一节，或用过渡接住因果 | 有些转折需要解释，有些只是重复 |
| V08 观点句 | “我认为”、直接判断、带程度的推测都可 | 是作者立场还是事实；依据与语气是否相称 |
| V09 对照与排比 | 可用于区分概念、强调节奏 | 内容有差别时保留，空泛时补具体事实 |
| V10 收尾 | 停在事实、判断、动作、问题或邀请上 | 是否完成当前目的，不固定成省略号 |
| V11 对比 | 表格、分行、小段、对照图 | 多维比较是否清楚，不要求只有一种形式 |
| V12 数字 | 精确值、近似值、区间均按来源 | 保留“约”和误差；对象可为上一版或竞品，选择有意义的基线 |
| V13 引语 | 原文逐字照录；转述、翻译标清性质 | “考虑”不变“宣布”；“某某说”是正常归因 |
| V14 来源 | 文内点明、图注、文末或另列 | 读者能查到、辨别口径；时点在需要时注明 |
| V15 图文 | 文字可解释，也可为无障碍阅读概述图 | 解释读者需要知道的，不为省字删掉关键数字 |
| V16 链接 | 文末、正文、首条评论或交付附注 | 下载、证据、引用路径是否可用 |
| V17 段长 | 短段便于扫读，长段可完整展开推理 | 实际设备与阅读节奏；110 字只是旧提醒线 |
| V18 概念 | 简定义、全称、直接使用术语 | 读者已有背景和准确性 |
| V19 梗 | 熟悉昵称、圈内语言、反差 | 当前读者懂不懂，有没有喧宾夺主 |
| V20 力度 | 热情、平实、批评、谨慎 | “首发”本身不证明“重磅”，以真实分量定语气 |
| V21 厂商评论 | 对任何地区或规模的厂商用同样证据标准 | 可以批评、比较或认可，分开可证事实与主观评价 |
| V22 未确认信息 | 明确“据谁”“尚未确认”“计划 / 灰度” | 问号或“？！”不能代替状态说明 |
| V23 推介 | 直接建议、使用体验、适用条件 | 真实依据、利益关系和限制 |
| V24 教程 | 命令直给、按步讲解、原理穿插 | 读者是否能够照做；必要前提不可省 |
| V25 列表 | ·、1）、-、1.、emoji、无符号都可 | 普通帖原样显示符号；选择读得清楚的样式 |
| V26 emoji | 可以不用，也可表达情绪、判断或结构 | 保留作者有含义的符号，不设品牌白名单 |
| V27 标签 | 无标签、少量主题标签、活动所需标签 | 服务发现与语境，数量不是普遍平台限制 |
| V28 发版说明 | 功能变化、修复 bug、真实投入、限制 | 准确表达变化，日常用语可正常使用 |
| V29 回复 | 态度、补充、追问、解释或反驳 | 接住对方意图，长度跟交流目标走 |
| V30 转发点评 | 可以短态度，也可展开新的角度 | 让读者知道推荐或异议的理由 |
| V31 段子 | 对话、预期反转、荒诞、动作、细节 | 笑点是否成立，虚构是否会被误认成事实 |
| V32 自然 | 口语和书面语各有场合 | 精简后仍顺畅，不机械压缩双音词 |
| V33 具体 | 细节给判断落点，概括建立关系 | 替换产品名仍成立的句子也可能是有效总结 |
| V34 问句 | 真困惑、修辞设问、互动邀请 | 是否推进理解或交流，别只按末尾问号判断 |
| V35 情绪 | 感叹、沉默、戏剧化留白 | 有无真实语境，是否贴作者声音 |
| V36 立场 | 单边、折中、条件判断都可 | 根据证据选择，不为互动硬造对立 |
| V37 回复节奏 | 一词、一行、多段都可 | 当前需要的是共鸣还是解释；25 字不是上限 |
| V38 术语 | 中文、英文专名、圈内小词按读者选 | 精确与自然比统一中文替换重要 |
| V39 信息密度 | 省略查证过程，保留影响理解的归因与限定 | 厂商自测、估读、样本范围不能藏进作者附注 |
| V40 发布状态 | 预告、计划、灰度、文档变化、全量发布分别写 | 标题动词与证据一致 |

## 看脚本提示时

W 是值得留意的模式，H/I 是额外线索；都要回上下文确认是否构成实际问题。无需每一处写保留说明，也不为清零改掉作者声音。自评分数、字数下降、未命中词表都不能独立证明稿件改善。
