# 示例（虚构）

| 文件 | 内容 |
|---|---|
| `01-长文-改前.md` / `01-长文-改后.md` | 一段长文改稿：删假强调和复述图片的句子、对比给出对象、未来判断加「预计」 |
| `02-短文-改前.txt` / `02-短文-改后.txt` | 短文：首行去「重磅」、列表改「·」、删收尾句 |

自己试一遍：

```bash
python3 ../scripts/de_ai_lint.py 01-长文-改前.md
python3 ../scripts/revise_check.py 01-长文-改前.md 01-长文-改后.md
python3 ../scripts/lint_x_post.py 02-短文-改后.txt
```
