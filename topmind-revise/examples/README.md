# topmind-revise 原创示例（去 AI 味与事实保真改稿对照）

两组「改前 → 改后」对比（项目名与数字均为教学虚构），直观演示如何破除 **AI 味四大生成机制** 并保持承重数字 100% 保真：

| 文件 | 示范重点 |
|---|---|
| [`01-长文-改前.md`](./01-长文-改前.md) → [`01-长文-改后.md`](./01-长文-改后.md) | 破除「温室湿度过渡词」（首先/此外/因此/总而言之）、「伪情绪设问」（你有没有想过…答案很简单）、「复述配图废话」（从下图可以看出）与「段末拔高升华」（不仅…更是…未来可期）；同时对未发生的趋势补上「预计」，并完整保留 `2 万`、`6 万`、`3.2 秒`、`1.4 秒`、`10 月 15 日` 全部事实数字。 |
| [`02-短文-改前.txt`](./02-短文-改前.txt) → [`02-短文-改后.txt`](./02-短文-改后.txt) | 去掉首行廉价震惊体（「🚨 重磅突发！…新纪元」）与结尾机器式求互动（「家人们觉得香不香？欢迎留言讨论」），保留 `800ms`、`220ms`、`8B`、`40 个` 等硬核信息并梳理为清爽的 `·` 列表。 |

可在 `examples/` 目录下直接运行脚本验证：

```bash
python3 ../scripts/de_ai_lint.py 01-长文-改前.md
python3 ../scripts/revise_check.py 01-长文-改前.md 01-长文-改后.md
python3 ../scripts/lint_x_post.py 02-短文-改后.txt
```
