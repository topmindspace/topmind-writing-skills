# X Article 粘贴格式规则

X Article 编辑器对 markdown 支持弱且不稳定。`md2x.py` 按以下规则转纯文本，
转完人工通读一遍是硬性步骤。输入是 `<文章名>/<文章名>.md`，产物缺省写到 `<文章名>/out/X发布稿.txt`（`--out` 可改）。

| Markdown | 转后 |
|----------|------|
| `#` ~ `######` 标题 | 纯文本行，前后各一空行；标题内的加粗/链接等标记同样剥离 |
| `标题` + 下一行 `===`（Setext 一级标题） | 同上，转纯文本标题行 |
| `**加粗**` / `*斜体*` / `***粗斜体***` / `~~删除线~~` / `` `行内代码` `` | 去标记留文字（语气靠文字本身） |
| `[文字](url)` | `文字（url）`；url 里可含括号，`[文字](url "title")` 的 title 丢弃 |
| `[文字][ref]` / `[文字][]` / `[文字]`（引用式，有 `[ref]: url` 定义） | `文字（url）`；定义行不进正文 |
| `![alt](url)` / `![alt][ref]` | `[图N]`，文末附"配图清单"（`[图N] alt`；alt 为空记 `（未写图注）`） |
| `-` / `*` / `+` 无序列表 | 默认（`plain`）转 `· `（嵌套转缩进两格的 `· `，最多两层，更深的压成二级）；任务列表 `- [ ]` / `- [x]` 去勾选框同样转 `· `（完成状态不保留） |
| `1.` / `1)` 有序列表 | 默认转 `1）`、`2）`…；嵌套同样最多两层 |
| `--list-style emoji` | 无序转 `🔹` / `▫️`，有序转 `1️⃣`…`9️⃣`、`🔟`，11–20 用 `⑪`–`⑳`，更大的用 `21）`（可选，不强制） |
| `--list-style keep` | 保留 `- ` / `1.` 原符号（含嵌套缩进），用于确认 X 编辑器会原生识别列表的场景 |
| `>` 引用 | 去掉所有层级的 `>` 留文字；引用内的标题照转 |
| 表格（行首以 `|` 开头的标准写法；不带前导 `|` 的表格暂不转换） | 逐行转"项：值"列表（单元格内标记同样剥离）；分隔行丢弃，复杂表请手动拆成段落 |
| `---` / `***` / `___` 分割线（允许空格，如 `* * *`） | 空行 |
| 代码块（``` 围栏；`~~~` 围栏暂不支持） | 去围栏，内容缩进 4 格；块内行原样保留（块内的 `---` 不再误判分割线） |
| `\` 转义（如 `\*`） | 去反斜杠留字符 |
| frontmatter | 整块丢弃（块内非空行须都含 `:` 才认定，文首的 `---` 分割线不会被误吞） |

## 列表为什么要改写

X 的纯文本帖不渲染 Markdown，`- ` 和 `1.` 会原样显示。`X发布稿.txt` 是纯文本兜底稿，所以默认改成「· 」「1）」：
同一层级用同一个符号、每条一行、层级最多两层；emoji 项目符号可选（`--list-style emoji`），不强制。符号集、缩进和数量规则见 [x-post-format.md](x-post-format.md)。
代码块内的 `- ` 不改写；`-5%` 这类不带空格的写法不会被当成列表。

对照（原创示例）：

```text
原稿：                       X发布稿.txt（默认 plain）：
- 响应时间：降到 1.1 秒       · 响应时间：降到 1.1 秒
- 价格：下调 30%              · 价格：下调 30%
  - 仅限新用户                  · 仅限新用户
1. 先装工具                  1）先装工具
2. 再登录                    2）再登录
```

## 写作时就按 X 想

- 段落短：手机阅读每段 ≤4 行
- 小标题就是一句话，不依赖加粗撑结构
- 数字、专有名词第一次出现就写全（剥离标记后无高亮可依靠）
- 需要强调的词：换说法前置，不要靠 `**`
