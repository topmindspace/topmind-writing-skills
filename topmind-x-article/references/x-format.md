# X Article 粘贴格式规则

X Article 编辑器对 markdown 支持弱且不稳定。`md2x.py` 按以下规则转纯文本，
转完人工通读一遍是硬性步骤。

| Markdown | 转后 |
|----------|------|
| `#` ~ `######` 标题 | 纯文本行，前后各一空行；标题内的加粗/链接等标记同样剥离 |
| `标题` + 下一行 `===`（Setext 一级标题） | 同上，转纯文本标题行 |
| `**加粗**` / `*斜体*` / `***粗斜体***` / `~~删除线~~` / `` `行内代码` `` | 去标记留文字（语气靠文字本身） |
| `[文字](url)` | `文字（url）`；url 里可含括号，`[文字](url "title")` 的 title 丢弃 |
| `[文字][ref]` / `[文字][]` / `[文字]`（引用式，有 `[ref]: url` 定义） | `文字（url）`；定义行不进正文 |
| `![alt](url)` / `![alt][ref]` | `[图N]`，文末附"配图清单"（`[图N] alt`；alt 为空记 `（未写图注）`） |
| `-` / `1.` 列表 | 保留原符号（含嵌套缩进）；`- [ ]` / `- [x]` 任务列表都去勾选框留 `-`（完成状态不保留） |
| `>` 引用 | 去掉所有层级的 `>` 留文字；引用内的标题照转 |
| 表格（行首以 `|` 开头的标准写法；不带前导 `|` 的表格暂不转换） | 逐行转"项：值"列表（单元格内标记同样剥离）；分隔行丢弃，复杂表请手动拆成段落 |
| `---` / `***` / `___` 分割线（允许空格，如 `* * *`） | 空行 |
| 代码块（``` 围栏；`~~~` 围栏暂不支持） | 去围栏，内容缩进 4 格；块内行原样保留（块内的 `---` 不再误判分割线） |
| `\` 转义（如 `\*`） | 去反斜杠留字符 |
| frontmatter | 整块丢弃（块内非空行须都含 `:` 才认定，文首的 `---` 分割线不会被误吞） |

## 写作时就按 X 想

- 段落短：手机阅读每段 ≤4 行
- 小标题就是一句话，不依赖加粗撑结构
- 数字、专有名词第一次出现就写全（剥离标记后无高亮可依靠）
- 需要强调的词：换说法前置，不要靠 `**`
