# X 长文发布清单

发布前逐项打勾，发布后填时间与链接归档。

## 写稿前 / 改稿时

- [ ] 原图先找齐：官方 > 原帖 > 第三方 > 自制（兜底）；每张图在发布包私有 `素材来源.md` 里有来源和读取日期（见 `image-sourcing.md`）
- [ ] 自制图图注写了「自制」和数据来源（`lint_x_post.py 公众号稿.md --md` 不报 W18）
- [ ] 改稿已过一遍（`topmind-revise`，没装就按 `revision-workflow.md`）：事实 → 逻辑 → 删冗余 → 去 AI 味 → 核心经验对照 → 排版 → 保真审计；本轮已备份，记下改前 / 改后字数（`count_words.py`）
- [ ] 去 AI 味已按 `de-ai-rules.md` 过完：`de_ai_lint.py` 的 W 每条有结论（改掉或写保留理由），H 只供判断

## 发布前

- [ ] `X长文.html` 浏览器打开一遍：「一键复制全文」按钮可用、配图按序显示（张数与 `[图N]` 一致）、
      每个提示词块右上角「复制提示词」可用、封面预览 + 下载正常
- [ ] `X发布稿.txt` 通读一遍：断句顺、无 markdown 残留标记，列表已是 emoji 项目符号（HTML 复制异常时的兜底；可跑 `scripts/lint_x_post.py --long` 检查）
- [ ] 标题 ≤140 字符、写清讲什么；开头用具体事实（`core-voice.md` V01、V05）
- [ ] 承重数字与原稿一致（转格式不改数字）
- [ ] 封面图 1500×600 已备好，标题字无错别字
- [ ] 配图按 `[图N]` 顺序排好，清单与文件一一对应
- [ ] 话题标签想好（放文末，不超过 3 个）
- [ ] 提示词密集型文章：规划好哪些提示词块要在 X 里转原生代码块
      （Insert → Code，读者侧一键复制的唯一链路；纯展示、无需取用的可跳过）

## 发布时

- [ ] 一键复制全文 → X 文章编辑器粘贴 → 封面单独上传 → 配图按 `[图N]` 编号插入
      （全文复制不带图片，正文里留 `[图N]` 占位：逐个在占位处粘贴该图「复制图片」，
      或「下载图片」后上传，然后删掉占位行）
- [ ] （提示词类文章推荐）提示词引用块逐块转 X 原生代码块，得读者侧一键复制：
      HTML 里点该块「复制提示词」→ X 编辑器对应位置 Insert → Code → 粘贴 → 删除原引用块
- [ ] 预览一遍：图序、段落、标题

## 发布后

- [ ] 首条评论补信息（邀请码 / 链接 / 补充说明），置顶
- [ ] 记录：发布时间、文章链接
- [ ] 全文抓回核对一遍（标题、数字、图序），有误用评论勘误
- [ ] `发布清单.md` 归档进包
