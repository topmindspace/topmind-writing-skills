# X 长文发布清单

按当前交付范围使用；这是作者操作参考，不授予技能发布、评论或置顶权限。

## 源稿与内容

- [ ] 目标源稿明确，实质修改有可恢复版本；沿用已有目录，不为检查器迁移文件。
- [ ] 承重事实、数字、引用和不确定性已核对；转格式没有改变原意。
- [ ] 原图与自制图按信息价值选择，来源、许可与处理方式清楚；不强制配图配额。
- [ ] 通读事实、逻辑和文字；lint 提示按语境判断，不要求清零或逐条写报告。
- [ ] 使用本仓文章包协议时运行 `scripts/check_article.py`；简单聊天稿不强制建包。

## 导出与封面

- [ ] 需要发布包时，从同一源稿运行 `md2x-html.py` / `md2x.py`，修改源稿后重新派生，不手改 `out/`。
- [ ] 实际打开 HTML 或预览，检查图序、段落、表格和提示词；纯文本兜底没有非预期格式残留，列表、链接和标签按作者需求安排。
- [ ] 标题与文章内容相符，长度按当前编辑器提示；不把旧经验写成全平台固定字符数。
- [ ] 封面逐字正确、与内容相关；1500×600 是本包预设。按 [平台封面参考](platform-cover-specs.md) 核对当前裁切，不与账号主页 banner 混用。
- [ ] 图片文件与 `[图N]` 一一对应；封面单独上传，不进入正文图编号。
- [ ] 复制按钮与图片上传路径实际可用；缺少浏览器或平台访问时记录未验证范围。

## 作者在编辑器中操作

- [ ] 复制正文到 X Article 编辑器，标题填标题栏，封面另传；检查正文没有重复标题。
- [ ] 全文复制不承诺带图；按 `[图N]` 占位上传或粘贴对应图片，再删除占位行。
- [ ] 表格和提示词按实际能力处理；需要读者侧复制代码时在编辑器使用原生代码功能，并核验效果。
- [ ] 在实际发布预览核对文字、图序、裁切、链接与可读性；由作者决定发布。

## 真实发布后

- [ ] 获得真实结果后记录时间与链接，再更新发布状态；生成发布包不算发布完成。
- [ ] 按需核对已发布页面。评论、置顶、补发和其他对外操作仅在用户另有授权时执行。
