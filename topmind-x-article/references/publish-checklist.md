# X 长文发布清单

发布前逐项打勾，发布后填时间与链接归档。

## 发布前

- [ ] `X长文.html` 浏览器打开一遍：「一键复制全文」按钮可用、配图 11 张按序显示、
      每个提示词块右上角「复制提示词」可用、封面预览 + 下载正常
- [ ] `X发布稿.txt` 通读一遍：断句顺、无 markdown 残留标记（HTML 复制异常时的兜底）
- [ ] 标题 ≤140 字符；首段 3 行内出钩子
- [ ] 承重数字与原稿一致（转格式不改数字）
- [ ] 封面图 1500×600 已备好，标题字无错别字
- [ ] 配图按 `[图N]` 顺序排好，清单与文件一一对应
- [ ] 话题标签想好（放文末，不超过 3 个）
- [ ] 提示词密集型文章：规划好哪些提示词块要在 X 里转原生代码块
      （Insert → Code，读者侧一键复制的唯一链路；纯展示、无需取用的可跳过）

## 发布时

- [ ] 一键复制全文 → X 文章编辑器粘贴 → 封面单独上传 → 配图按 `[图N]` 编号插入
      （图片若随粘贴带入则跳过上传；带不入则用图下「下载图片」按编号下载再上传）
- [ ] （提示词类文章推荐）提示词引用块逐块转 X 原生代码块，得读者侧一键复制：
      HTML 里点该块「复制提示词」→ X 编辑器对应位置 Insert → Code → 粘贴 → 删除原引用块
- [ ] 预览一遍：图序、段落、标题

## 发布后

- [ ] 首条评论补信息（邀请码 / 链接 / 补充说明），置顶
- [ ] 记录：发布时间、文章链接
- [ ] 全文抓回核对一遍（标题、数字、图序），有误用评论勘误
- [ ] `发布清单.md` 归档进包
