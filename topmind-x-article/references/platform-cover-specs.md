# 平台封面与图文适配

资料核验：2026-10-27。依据公开页面和官方搜索索引；未登录各平台后台实测。页面不可读、不同入口或版本不一致时，只采用可确认结论，交付时写清未验证项。

## 先确定发布形态

同个平台的图文、视频、商品主图、商城内容和账号主页横幅可能使用不同规则。先按用户需求确定用途；发布入口已明确时直接做，只有形态差异会改变结果且无法推断时才问。

以下尺寸是本包制作与导出预设，不是平台统一的强制上传规格。用户尺寸、当前发布页要求与实际裁切优先；图片格式和大小上限也以对应入口为准，不把素材 API、广告或商品主图限制套给普通内容。

| 用途 | 本包预设 | 依据与范围 | 发布前看什么 |
|---|---|---|---|
| 小红书图文笔记 | 1080×1440，3:4 | 官方电商课程建议相关商品笔记采用 3:4；像素数为本包选择 [1] | 封面选择、信息流及主页缩略图、整组图片一致性 |
| 抖音普通图文 | 1080×1440，3:4 | 本包竖版起点；尚未核实官方统一比例、像素和固定安全区 | 按实际入口确认比例，检查浏览画面、封面缩略图与操作层遮挡 |
| 抖店图文 | 按发布页与素材确定 | 官方指南支持排序、设置封面；AI 图文流程默认第一张为封面 [2] | 图片顺序、封面选择、商品关联是否真实 |

## 场景约束与设计判断

- **小红书**：[1] 的生活化商品笔记课程建议用真实场景、图片尺寸一致，并不建议在该类封面额外加文案。这不能扩大成所有笔记禁止加字、禁止白底或必须发固定张数。知识、观点、清单封面可根据内容排字，不承诺某种字体、颜色或版式必然带来高互动。
- **抖音**：普通创作者图文、抖店发布和商城准入分别判断。[3] 当前与旧公开入口的版本、条文存在差异；旧商城公告涉及纯文字等低质封面，不能写成当前全抖音统一禁令。商品与功效、品牌、价格等表述要真实；商城任务需核对适用的最新条款。不要把商品主图的 3:4、商城横图或直播封面比例互相代用。
- **公众号**：普通文章的封面、正文头图与图片消息分开设计；宽图和方图应各自成立，不承诺固定中心裁切或某个分享场景永远使用同一比例。后台粘贴和 API 上传是不同通道，限制分别核验。
- **跨平台**：同一选题可以复用色彩、字体与真实素材；横图和竖图通常需要重新布局。先保住主题、标题与主体，再决定能否裁切。密集正文可拆成多张可读图片，长图不能直接充当每个平台的封面。

## 制作与裁切

先按目标画幅设计；需要横竖多版时，分别安排标题与主体。四周留出余量、检查小尺寸可读性是设计判断，不设置没有证据的统一百分比安全区。不要声称小红书“占屏大 40%”、底部必被遮挡、抖音固定保留某个像素区域或 X 头图在所有入口全显示。

安装了 `topmind-cover` 时，可在该技能的 `scripts` 目录使用：

```bash
python3 crop-cover.py 横版主图.png --out-dir 输出目录
python3 crop-cover.py X短帖主图.png --preset x-post --out-dir 输出目录
python3 crop-cover.py 竖版主图.png --preset xiaohongshu --out-dir 输出目录
python3 crop-cover.py 竖版主图.png --preset douyin --out-dir 输出目录
python3 crop-cover.py 原图.png --preset wechat --out-dir 输出目录
python3 crop-cover.py 原图.png --preset wechat --anchor left --out-dir 输出目录
```

其他技能独立安装时不假定这个脚本存在，可用当前环境的等比裁切工具。`article` 保留既有双横图命名；`wechat` 另给宽图与方图。每张直接从原图等比裁切，`--anchor` 可选 center / left / right / top / bottom，不能恢复原图里没有的内容。方图标题被切时重新排版，禁止拉伸凑比例。脚本仅保证输出尺寸，不证明平台已验收或画面合格。

## 交付前核对

核对标题、数字、logo 与实际内容；看完整输出和目标缩略图。能访问发布页时再检查各入口裁切、角标与操作层遮挡；没有后台访问就交付文件和待预览项，不宣称完成平台实测。预设输出 PNG 是工具约定，不代表各平台只收 PNG；按实际入口需要转换并复查清晰度。

## 来源与维护

1. [小红书电商学习中心：商品笔记运营课程](https://school.xiaohongshu.com/lesson/normal/af0fe7e97bb0433fac9da5d1df52b07f)（官方建议；公开索引可读，页面直接访问可能受限）。3:4 与生活化商品场景建议，不是全平台上传规范。
2. [抖店图文发布—商家操作指南](https://school.jinritemai.com/doudian/web/articlev0/aHt5ad18FPgj)（官方操作指南，页面日期 2026-06-04）。封面可选、图片可排序，AI 图文默认第一顺序图为封面；不代表所有抖音客户端。
3. [抖音商城管理规范](https://school.jinritemai.com/doudian/web/article/aHRK3WaAk7AN)（官方规则；公开索引有 2026-07-30 更新页面，也有旧入口内容，直接页面可能只返回空壳）。须按实际版本、适用范围核实，不根据搜索片段判断某个旧条款仍生效。
4. [Canva 可画：微信公众号尺寸](https://www.canva.cn/sizes/wechat-official-account/)（第三方设计指南）。列有 900×383 与方形小图；其中其他上传限制未获微信官方现行资料验证，本包不引用为硬规则。
5. [X 官方帮助：About Articles](https://help.x.com/en/using-x/articles)（官方帮助）。头图应贴题；该页不提供 1500×600 的硬性规格，账号主页 banner 也不是 Article 封面。

平台资料发生冲突时回到当前发布入口与官方适用条款；新增证据时更新核验日期、场景和来源。未验证的参数保留为本包选项或待实测项，不补成“官方规定”。
